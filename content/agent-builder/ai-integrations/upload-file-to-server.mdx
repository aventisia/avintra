# Upload File to Server

The **Upload File to Server** node allows you to send a file from your local system to a web service by uploading it via an API endpoint. This is particularly useful for integrating document submission processes, such as submitting reports, forms, or images to a server for storage or further processing.

For example:

- Uploading a PDF document to a content management system.
- Sending an image file to a server for image recognition processing.
- Supplying a data file to a server for aggregation or transformation.

## Configuration Options

| Field Name          | Description                                                                   | Input Type | Required? | Default Value |
| ------------------- | ----------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **File Path**       | Full path to the file that you want to upload (e.g., `C:\temp\document.pdf`). | Text       | Yes       | _(empty)_     |
| **API Endpoint URL**| URL of the API where the file will be uploaded (e.g. `https://api.example.com/upload`). | Text       | Yes       | _(empty)_     |
| **Bearer Token**    | Authentication token required to authorize the upload.                        | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output provides confirmation details after the upload:

- **Uploaded File Id**: A unique identifier assigned by the server to the uploaded file.
- **Response Code**: The HTTP status code indicating the result of the upload (e.g., `200` for success).
- **Response Message**: Any message returned by the server about the upload operation.

## Step-by-Step Guide

<Steps>

### Step 1

Add the **Upload File to Server** node into your workflow.

### Step 2

In the **File Path** field, input the full path of the file you want to upload from your local machine. Ensure the file path is correct and accessible by the system running this process.

### Step 3

In the **API Endpoint URL**, enter the URL where the file should be uploaded. This should be the endpoint provided by the service you are working with.

### Step 4

In the **Bearer Token** field, provide the authentication token (JWT) required for accessing the API. Obtain this token from your service provider or through an authentication process.

### Step 5

After setting up, execute the node to initiate the file upload. Once uploaded, the file's unique ID and the response details (code and message) will be displayed.

</Steps>

<Callout type="info" title="Note">
  Ensure that your API URL and Bearer Token are correct and valid; incorrect values will prevent successful uploads.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                                         | Solution                                                                                                                                     |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **File not found or inaccessible**                              | Verify the file path is correct and the file is accessible. Check permission settings if necessary.                                          |
| **Invalid or incorrect API Endpoint URL**                       | Double-check the API URL for any mistakes, such as missing segments or incorrect protocol (e.g., HTTP instead of HTTPS).                      |
| **Authentication fails due to invalid Bearer Token**            | Ensure your Bearer Token is still valid and has not expired. Obtain a new token if necessary.                                                 |
| **Unexpected response or upload failure**                       | Check the server response message for insight into possible issues. Ensure network connectivity and server availability.                      |
