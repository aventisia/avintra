# Ollama Connector

The **Ollama Connector** node integrates with Ollama models through a local REST API to generate text responses. You can use this node to interact with various models in Generate or Chat modes, making it ideal for applications like automated customer service, content generation, and interactive chat experiences.

## Configuration Options

| Field Name     | Description                                                                                 | Input Type | Required? | Default Value         |
| -------------- | ------------------------------------------------------------------------------------------- | ---------- | --------- | --------------------- |
| **Base URL**   | The Ollama server base address. Typically, it's `http://localhost:11434`, but it may differ if customized. | Text       | Yes       | http://localhost:11434 |
| **Model**      | The target Ollama model (e.g., `llama2`, `mistral`, `codellama`). Ensure the model is already available in Ollama. | Text       | Yes       | _(empty)_             |
| **Prompt**     | The text prompt for use in Generate mode or an additional user message in Chat mode.        | Text       | No        | _(empty)_             |
| **Mode**       | Choose between Generate for single response or Chat for conversation mode.                  | Select     | No        | Generate              |
| **Chat Messages** | Optional messages in Chat mode, formatted as `role:content` (e.g., `user:hello`).        | Text       | No        | _(empty)_             |
| **Headers**    | Additional HTTP headers for your requests.                                                  | Text       | No        | _(empty)_             |
| **Content Type** | Specify content type for the request.                                                     | Text       | No        | application/json      |
| **Accept Header** | Define the expected return format of your request.                                       | Text       | No        | application/json      |

## Expected Output Format

The node outputs are primarily text-based:

- **Ollama Result**: The text response generated by the Ollama model.
- **Response Code**: HTTP status code to confirm request success or diagnose errors.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Ollama Connector** node to your workflow.

### Step 2

Enter the **Base URL** of your Ollama server, typically set to `http://localhost:11434`.

### Step 3

Fill in the **Model** field with the name of the Ollama model you plan to use.

### Step 4

If you intend to use Generate mode, enter the prompt in the **Prompt** field. This field is optional if you select Chat mode.

### Step 5

Select the desired **Mode** from the dropdown list. Choose either "Generate" for single text responses, or "Chat" for conversational flow.

### Step 6

If you selected Chat mode, optionally add entries in **Chat Messages** following the format `role:content`.

### Step 7

If necessary, add any extra HTTP headers in the **Headers** field.

### Step 8

Specify **Content Type** and **Accept Header** settings if they differ from `application/json`.

</Steps>

<Callout type="info" title="Note">
  Ensure the chosen model is available on your local Ollama before invoking it through this node.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                              | Solution                                                                                      |
| ------------------------------------ | --------------------------------------------------------------------------------------------- |
| **Invalid Model Name**               | Make sure the model name is correct and is available in Ollama.                               |
| **Server Not Found**                 | Check the **Base URL** and ensure the Ollama server is running.                               |
| **Incorrect HTTP Headers**           | Verify that the headers are formatted correctly; use common formats like `application/json`.  |
| **Unexpected Response Code**         | Confirm model availability and API endpoint accuracy, alongside checking network settings.    |

## Real-World Use Cases

- **Customer Service Bots**: Deploy quick-response models in chat mode for efficient customer interactions.
- **Content Generation**: Use Generate mode to assist in content creation by responding to prompts with creative text.
- **Data Analysis and Reports**: Leverage models to summarize and analyze large text blocks, generating quick insights.
