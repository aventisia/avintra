# Invoke Inference Model Web Service

The **Invoke Inference Model Web Service** node interacts with an artificial intelligence (AI) model's web service to send input text and retrieve the AI's response. This is useful for tasks where you want to automate AI-driven text processing, such as generating content, answering questions, or analyzing text data.

For example:
- Sending a text prompt to an AI model and receiving a generated response.
- Getting predictions or inferences from a model for your input text.

## Configuration Options

| Field Name       | Description                                                                 | Input Type | Required? | Default Value       |
| ---------------- | --------------------------------------------------------------------------- | ---------- | --------- | ------------------- |
| **Select Model** | The name or identifier of the model to invoke (e.g., gpt-3.5-turbo).        | Text       | Yes       | _(empty)_           |
| **Input Text**   | The input text or prompt to send to the model.                              | Text       | Yes       | _(empty)_           |
| **Model API Key**| The API key required to authenticate with the model service.                | Text       | No        | _(empty)_           |
| **Endpoint URL** | The URL of the web service endpoint (e.g., https://api.example.com/v1/completions).| Text       | Yes       | _(empty)_           |
| **HTTP Method**  | The HTTP method to use. Commonly POST for model inference.                  | Select     | Yes       | POST                |
| **Request Body** | The request body to send in POST requests. Use `{SelectModel}` and `{InputText}` as placeholders. | Text       | No        | _(empty)_           |
| **Content Type** | Specifies the content type for the request body.                            | Text       | No        | application/json    |
| **Accept Header**| Specifies the content type expected in the response.                        | Text       | No        | application/json    |
| **Headers**      | Custom HTTP headers to include in the request (e.g., specific model service headers).| Text    | No        | _(empty)_           |

## Expected Output Format

The output of this node consists of two parts:
1. **AIModelResult**: Returns the raw response from the web service as a string.
2. **ResponseCode**: Returns the HTTP status code from the web service.

These outputs are valuable for processing the AI's response and assessing the service's request status.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Invoke Inference Model Web Service** node into your flow.

### Step 2

In the **Select Model** field, enter the model's identifier you intend to use (e.g., `gpt-3.5-turbo`).

### Step 3

In the **Input Text** field, provide the text or prompt you wish to send to the model.

### Step 4

(Optional) Enter your **Model API Key** if required by the service to authenticate your request.

### Step 5

Enter the **Endpoint URL** for the web service you are accessing.

### Step 6

Choose the **HTTP Method** from the dropdown. Usually, **POST** is used for model inference tasks.

### Step 7

(Optional) Fill out the **Request Body** if additional JSON data is required in the post request. Use placeholders if applicable.

### Step 8

(Optional) Adjust the **Content Type** and **Accept Header** fields if you want to specify custom content types for your request and expected response.

### Step 9

(Optional) Specify any additional **Headers** needed for your model service.

### Step 10

The result and response code will be available as **AIModelResult** and **ResponseCode** for further use in your automation flow.

</Steps>

<Callout type="info" title="Note">
  Ensure that your endpoint URL is correct and the model service is accessible from your network or application environment.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                       | Solution                                                                                                                                  |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **HTTP 401 Unauthorized**                     | Verify that your API key is correct and that you have permission to access the service.                                                    |
| **HTTP 404 Not Found**                        | Ensure the endpoint URL is accurate, and check if there are any typos in the URL.                                                          |
| **Unexpected Response Format**                | Double-check the **Accept Header** and **Content Type** settings. The expected formats should match what the web service provides.          |
| **Invalid Request**                           | Review your request body structure and ensure you're using the correct HTTP method for your intended action (e.g., POST for submissions). |
