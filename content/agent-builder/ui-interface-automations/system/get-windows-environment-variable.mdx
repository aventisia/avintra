# Get Windows Environment Variable

The **Get Windows Environment Variable** node is designed to retrieve the value of a specified environment variable from your Windows operating system. This can be particularly useful when you need to use system-specific information, like user names or system paths, within your automation tasks.

For example, you can:
- Fetch the current user's username.
- Retrieve system paths for scripts and applications.
- Obtain processor details for system diagnostics.

## Configuration Options

| Field Name                        | Description                                                                                  | Input Type | Required? | Default Value   |
| --------------------------------- | -------------------------------------------------------------------------------------------- | ---------- | --------- | --------------- |
| **Environment variable name**     | Select the name of the environment variable you wish to retrieve.                            | Select     | Yes       | USERNAME        |
| **Search for variable only in scope** | Toggle whether to search for the variable exclusively within the defined scope.                | Switch     | No        | _(empty)_       |
| **Scope**                         | Specify whether to search in the User or System environment variables. _Visible if the scope search is enabled._ | Select     | No        | User            |

## Expected Output Format

The expected output from this node is a **string value** representing the content of the selected environment variable.

- Example output: `C:\Users\UserName` for the `USERNAME` variable.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Get Windows Environment Variable** node into your flow.

### Step 2

From the **Environment variable name** dropdown, select the variable whose value you want to retrieve.

### Step 3

Optionally, if you wish to limit the search to a specific scope, enable the **Search for variable only in scope** switch.

### Step 4

If the scope is limited, choose the appropriate **Scope** (User or System) to specify where to look for the variable.

### Step 5

The retrieved value will be available as **EnvironmentVariableValue** for use in further nodes.
</Steps>

<Callout type="info" title="Tip">
  The **Scope** option appears only when the **Search for variable only in scope** is turned on.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                                    | Solution                                                                                                                          |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Variable value not found**                               | Ensure you have selected the correct environment variable name.                                                                   |
| **Scope options not visible**                              | Check if the **Search for variable only in scope** switch is enabled; otherwise, the **Scope** field won't be displayed.           |
| **Unexpected output or empty value**                       | Confirm that the selected environment variable and scope (if used) actually have values on the current machine configuration.     |

## Real-World Use Cases

- **Automating User-Specific Tasks**: Retrieve the current username for personalizing scripts or outputs.
- **Configuring Application Paths**: Use system path variables to direct applications or scripts dynamically.
- **System Diagnostics**: Collect environment information like OS type or processor details as part of a diagnostic tool.
