# Set Windows Environment Variable

The **Set Windows Environment Variable** node allows you to modify or establish environment variables within your Windows operating system. This functionality is useful for configuring system settings or user-specific preferences that applications or the operating system uses to manage processes. When you want your changes to take immediate effect without needing a system restart, this node is particularly beneficial.

For example:

- Modifying the system PATH to include new directories for executables.
- Setting user-specific variables for a project or software settings.
- Configuring system-wide settings applicable to all users on the machine.

## Configuration Options

| Field Name                         | Description                                                                                      | Input Type | Required? | Default Value |
| ---------------------------------- | ------------------------------------------------------------------------------------------------ | ---------- | --------- | ------------- |
| **Environment Variable Name**      | The name of the environment variable to set.                                                     | Select     | Yes       | _(empty)_     |
| **New Environment Variable Value** | The new value to set for the chosen environment variable.                                        | Text       | Yes       | _(empty)_     |
| **Type**                           | Specifies whether to set the environment variable at the User or System level.                   | Select     | No        | User          |

## Expected Output Format

When this node executes successfully, the output is a **status message** indicating the success or failure of setting the environment variable.

- The output message is a simple text status such as "Environment variable set successfully" or "Failed to set environment variable".

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Set Windows Environment Variable** node to your workflow.

### Step 2

In the **Environment Variable Name** dropdown, select the environment variable you wish to modify.

### Step 3

Enter the value you want to assign to this environment variable in the **New Environment Variable Value** field.

### Step 4

Choose the **Type** of environment variable - either User (for current user-specific settings) or System (for system-wide settings). If you don't select anything, it defaults to "User".

### Step 5

Once configured, run or save your workflow to apply the changes. The outcome will be displayed as a **status message**.

</Steps>

<Callout type="info" title="Note">
  Changing system-level environment variables may require administrator privileges. Ensure you have the necessary permissions when setting System variables.
</Callout>

## Input/Output Examples

| Environment Variable Name | New Value        | Type  | Output Message                          |
| ------------------------- | ---------------- | ----- | --------------------------------------- |
| PATH                      | `C:\New\Path`    | User  | Status message displayed upon success.  |
| TEMP                      | `D:\Temp`        | System| Status message displayed upon success.  |

## Common Mistakes & Troubleshooting

| Problem                                              | Solution                                                                                                    |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Variable not appearing in dropdown**               | Ensure that you are selecting from the list of predefined variables. Custom variables are not listed here.  |
| **Permission Denied on System Variables**            | Check for necessary administrator privileges as changing system variables may not be allowed for all users. |
| **No Status Message Displayed**                      | Verify if the node configuration is correct and if the workflow was run successfully.                       |

## Real-World Use Cases

- **Software Development**: Easily adjust the system PATH for new builds or command-line tools needed during development.
- **Custom User Configurations**: Setup personalized environment variables for scripts or applications specific to your workflow.
- **System Administration**: Configure system-wide settings that all users and processes can access without manual edits on multiple user profiles.
