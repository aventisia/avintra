# Get Table Names

The **Get Table Names** node enables you to retrieve all the table names from an Excel workbook stored in OneDrive or SharePoint. This node is particularly useful when you want to identify and work with specific tables within a workbook without manually searching through the file. You can seamlessly automate processes that involve selecting or referencing specific table data in your workflows.

## Configuration Options

| Field Name     | Description                                   | Input Type | Required? | Default Value |
|----------------|-----------------------------------------------|------------|-----------|---------------|
| **Tenant ID**  | Azure Active Directory (AD) Tenant ID         | Text       | Yes       | _(empty)_     |
| **Client ID**  | Azure AD Client ID                            | Text       | Yes       | _(empty)_     |
| **Client Secret** | Azure AD Client Secret                      | Text       | Yes       | _(empty)_     |
| **Drive ID**   | OneDrive or SharePoint Drive ID               | Text       | Yes       | _(empty)_     |
| **Item ID**    | Unique identifier for the Excel file          | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of the **Get Table Names** node is a list containing the names of all tables found within the specified Excel workbook. The output is labeled as **TableNames**.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Get Table Names** node to your automation workflow.

### Step 2

Enter your **Azure AD Tenant ID** in the **Tenant ID** field. This is necessary to authenticate your request.

### Step 3

Input your **Azure AD Client ID** in the **Client ID** field. It identifies your application during the authentication process.

### Step 4

Provide your **Azure AD Client Secret** in the **Client Secret** field. This is a confidential key shared between your application and Azure to authenticate securely.

### Step 5

Enter the **Drive ID** for your OneDrive or SharePoint location in the **Drive ID** field. This specifies where your workbook is stored.

### Step 6

Input the **Item ID** in the **Item ID** field, which uniquely identifies your Excel file within the specified drive.

### Step 7

The node processes the input and retrieves all the table names, making them available as **TableNames** for further use in your automation flow.

</Steps>

<Callout type="info" title="Note">
Ensure all IDs and secrets are entered correctly to avoid authentication errors or failure in retrieving table names.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                     | Solution                                                                                |
|-----------------------------|-----------------------------------------------------------------------------------------|
| **Authentication Error**    | Verify your Tenant ID, Client ID, and Client Secret. Ensure all credentials are correct. |
| **Table Names Not Retrieved | Check Drive ID and Item ID for accuracy. Make sure the Excel file is accessible.         |
| **Output is Empty**         | Ensure the specified Excel file contains tables.                                        |

## Real-World Use Cases

- **Data Migration**: Automatically identify and retrieve table names to aid in data migration tasks.
- **Automated Reporting**: Quickly access table names to dynamically generate reports from Excel workbooks.
- **Data Analysis**: Fetch tables to feed into data analysis tools or scripts without manual entry.
