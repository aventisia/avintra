# Sort Table or Range

The **Sort Table or Range** node organizes data within a specified table or range in your Excel sheet located on OneDrive or SharePoint. A perfect tool for managing large datasets, it enables you to sort rows by any column, either in ascending or descending order.

Use this node when you need to:

- Organize your data by specific criteria, such as dates, names, or numbers.
- Prepare data for analysis by ensuring consistent order.
- Simplify data interpretation by grouping entries logically.

## Configuration Options

| Field Name         | Description                                          | Input Type | Required? | Default Value |
| ------------------ | ---------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**      | Azure AD Tenant ID, an identifier for your AD account | Text       | Yes       | _(empty)_     |
| **Client ID**      | Azure AD Client ID, an identifier for your app       | Text       | Yes       | _(empty)_     |
| **Client Secret**  | Secret key to authenticate your app                  | Text       | Yes       | _(empty)_     |
| **Drive ID**       | ID of the OneDrive or SharePoint drive               | Text       | Yes       | _(empty)_     |
| **Item ID**        | ID of the Excel file to sort                         | Text       | Yes       | _(empty)_     |
| **Range or Table** | Specifies the range address or table name            | Text       | Yes       | _(empty)_     |
| **Sort Field**     | Column name or index to determine the sort criterion | Text       | Yes       | _(empty)_     |
| **Sort Order**     | Defines sort direction - "Ascending" or "Descending" | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **sorted range or table** in Excel. The original file is updated to reflect the new order based on your sort criteria.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Sort Table or Range** node into your flow.

### Step 2

Input your Azure credentials: **Tenant ID**, **Client ID**, and **Client Secret**. These are required for authentication and access.

### Step 3

Specify the **Drive ID** and **Item ID** to target the correct Excel file on OneDrive or SharePoint.

### Step 4

Enter the **Range or Table** defining which data set you wish to sort. This could be a named table or a cell range like "Sheet1!A1:D10".

### Step 5

Decide on the **Sort Field** either a header name or a column index by which you wish to organize the data.

### Step 6

Set the **Sort Order** to either "Ascending" or "Descending" to finalize the sorting criteria.

</Steps>

<Callout type="info" title="Important">
  Ensure all IDs and secrets are correctly entered to avoid authentication errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                      | Solution                                                                                                                                  |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Incorrect Range or Table specified**       | Always double-check the spelling of table names and range addresses.                                                                      |
| **Authentication errors**                    | Verify all Azure AD credentials are correctly entered. An incorrect **Tenant ID, Client ID,** or **Client Secret** can cause access issues. |
| **Unexpected Sort Order**                    | Ensure that the **Sort Order** field is set to either "Ascending" or "Descending" accurately.                                              |

## Real-World Use Cases

- **Sales Data**: Sort sales figures monthly to identify trends.
- **Employee Records**: Alphabetize employee names for easy lookup.
- **Inventory Lists**: Arrange items by quantity to quickly flag low-stock items.
