# Get Named Range Names

The **Get Named Range Names** node retrieves all the named ranges from a specified Excel workbook. Named ranges are useful for identifying specific areas or cells in Excel sheets by a specific name, making them easier to reference and work with. This node facilitates the integration of Excel data into your automated processes by providing easy access to these named references.

For example:

- Accessing specific data areas in an Excel file without needing cell references.
- Automating reports by using previously defined names.

## Configuration Options

| Field Name      | Description                              | Input Type | Required? | Default Value |
| --------------- | ---------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**   | Azure AD Tenant ID                       | Text       | Yes       | _(empty)_     |
| **Client ID**   | Azure AD Client ID                       | Text       | Yes       | _(empty)_     |
| **Client Secret**| Azure AD Client Secret                  | Text       | Yes       | _(empty)_     |
| **Drive ID**    | OneDrive or SharePoint Drive ID          | Text       | Yes       | _(empty)_     |
| **Item ID**     | Excel file Item ID                       | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **list of named ranges** (in plain text format), which are the names defined in the specified Excel workbook.

- Example: `["SalesData", "AnnualBudget", "EmployeeList"]`

## Step-by-Step Guide

<Steps>
### Step 1

Add **Get Named Range Names** node into your flow.

### Step 2

In the **Tenant ID** field, enter your Azure AD Tenant ID. This is used to authenticate your connection to Azure.

### Step 3

In the **Client ID** field, enter your Azure AD Client ID. This is required to identify your application.

### Step 4

In the **Client Secret** field, enter your Azure AD Client Secret. Ensure this is kept secure, as it's crucial for authentication.

### Step 5

In the **Drive ID** field, input the OneDrive or SharePoint Drive ID where your Excel file is stored.

### Step 6

Enter the **Item ID** which refers to your specific Excel file in OneDrive/SharePoint.

### Step 7

After inputting all required fields, the node will retrieve all named ranges in the specified Excel workbook as **NamedRanges** for use in subsequent nodes.

</Steps>

<Callout type="info" title="Tip">
  Make sure all IDs and secrets are correctly entered and correspond to your current Azure and OneDrive or SharePoint setup to avoid errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                      | Solution                                                                                                         |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------|
| **Authentication Error**                     | Ensure the Tenant ID, Client ID, and Client Secret are correctly entered and valid.                              |
| **Empty Named Ranges Output**                | Confirm that the Excel file contains named ranges. Also, verify that the correct Item ID has been provided.      |
| **Invalid Drive or Item ID**                 | Double-check the Drive ID and Item ID to ensure they correspond accurately to your OneDrive/SharePoint settings. |

## Real-World Use Cases

- **Automated Data Updates**: Quickly access specific data sections in an Excel file for regular updates or processing.
- **Data Transfer**: Import data from specified named ranges into other applications or reports seamlessly.
- **Data Validation**: Track changes in specific named sections of a spreadsheet over time.
