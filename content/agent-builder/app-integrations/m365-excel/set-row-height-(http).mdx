# Set Row Height (HTTP)

The **Set Row Height (HTTP)** node allows you to adjust the height of a specific row in an Excel worksheet stored on OneDrive or SharePoint. This can be particularly useful when you need to increase space for content visibility or format reports for consistency and readability.

For example:

- Increasing a row's height to accommodate larger text or multiple lines of information.
- Adjusting row height for better visual alignment in Excel reports.

## Configuration Options

| Field Name        | Description                                                                                             | Input Type | Required? | Default Value |
| ----------------- | ------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**     | The Azure AD tenant identifier (e.g., 'contoso.onmicrosoft.com' or a GUID). Used to authenticate with Microsoft 365. | Text       | Yes       | _(empty)_     |
| **Client ID**     | The Application (Client) ID of the Azure AD app registered to access Microsoft Graph.                   | Text       | Yes       | _(empty)_     |
| **Client Secret** | The client secret of the Azure AD application. Ensure it has the necessary permissions.                  | Text       | Yes       | _(empty)_     |
| **Drive ID**      | The unique ID of the OneDrive or SharePoint document library drive where the Excel file is stored.       | Text       | Yes       | _(empty)_     |
| **File Path**     | The relative path to the Excel file in the drive (e.g., 'Reports/Dashboard.xlsx').                      | Text       | Yes       | _(empty)_     |
| **Worksheet Name**| The name of the worksheet containing the row to adjust (e.g., 'Summary').                               | Text       | Yes       | _(empty)_     |
| **Row Index**     | The 1-based index of the row to resize (e.g., 1 for the first row).                                     | Text       | Yes       | _(empty)_     |
| **Height**        | The new row height in points (e.g., 20.0). Must be a positive number.                                   | Text       | Yes       | _(empty)_     |

## Expected Output Format

There is no direct output from this node, as its role is to perform an action (set row height) within an existing Excel file.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Set Row Height (HTTP)** node into your flow.

### Step 2

Enter your **Tenant ID** to authenticate access to Microsoft 365.

### Step 3

Enter your **Client ID** and **Client Secret** for the registered Azure AD application.

### Step 4

Provide the **Drive ID** to specify where the Excel file is stored.

### Step 5

Fill in the **File Path** with the relative path of your Excel file.

### Step 6

Type in the **Worksheet Name** where the row height needs adjustment.

### Step 7

In the **Row Index** field, specify the row number that requires resizing.

### Step 8

Finally, enter the desired **Height** (in points) for the specified row.

### Step 9

Execute the flow to apply the new row height in your target Excel worksheet.

</Steps>

<Callout type="warning" title="Note">
  Ensure all fields are filled correctly to avoid authentication errors or fail in setting the row height.
</Callout>

## Input/Output Examples

Since the node is action-oriented without outputs, here is an example of the expected use:

- **Row to Adjust**: Row 1 in 'Summary' worksheet.
- **Height Set To**: 25.0 points for better readability.

## Common Mistakes & Troubleshooting

| Problem                                        | Solution                                                                                      |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **Authentication errors**                      | Double-check Tenant ID, Client ID, and Client Secret to ensure credentials are correct.       |
| **Invalid Drive ID or File Path**              | Verify the drive and file path for accuracy when referencing the location of the Excel file.  |
| **Non-positive numbers in Height**             | Ensure the Height field contains a positive numeric value.                                    |
| **Incorrect Row Index**                        | Use a valid 1-based index. The row index should refer to an actual row in the worksheet.      |

## Real-World Use Cases

- **Report Formatting**: Automatically adjust row heights in financial or project reports for optimal presentation.
- **Data Visualisation**: Modify rows to better fit data visualisation needs, such as charts or graphs embedded within cells.
- **Automated Template Adjustments**: Apply standard row height settings across report templates for consistency.
