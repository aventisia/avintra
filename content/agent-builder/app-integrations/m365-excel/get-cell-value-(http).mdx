# Get Cell Value (HTTP)

The **Get Cell Value (HTTP)** node enables you to retrieve the value of a single cell from an Excel file stored in OneDrive or SharePoint using Microsoft Graph HTTP GET. It is useful for accessing specific data points from your spreadsheets for further processing or analysis.

For example:

- Extracting a specific data entry for report generation.
- Accessing key metrics or values from a financial spreadsheet.
- Retrieving text, number, or calculated formula results directly from Excel.

## Configuration Options

| Field Name      | Description                                                                                         | Input Type | Required? | Default Value |
| --------------- | --------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**   | The Azure Active Directory (Azure AD) Tenant ID.                                                    | Text       | Yes       | _(empty)_     |
| **Client ID**   | The Azure Active Directory (Azure AD) Client ID.                                                    | Text       | Yes       | _(empty)_     |
| **Client Secret** | The Azure Active Directory (Azure AD) Client Secret.                                               | Text       | Yes       | _(empty)_     |
| **Drive ID**    | ID for your OneDrive or SharePoint drive where the Excel file is stored.                            | Text       | Yes       | _(empty)_     |
| **File Path**   | The path to the Excel file within the specified drive (e.g., 'Reports/Data.xlsx').                  | Text       | Yes       | _(empty)_     |
| **Worksheet Name** | Name of the Excel worksheet containing the cell you want to read (e.g., 'Sheet1').               | Text       | Yes       | _(empty)_     |
| **Cell Address**   | Address of the specific cell you wish to read, using A1-style notation (e.g., 'B5', 'Z100').     | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is the **value contained within the specified Excel cell**. This value can be a number, text, or the result of a formula provided as text representation.

## Step-by-Step Guide

<Steps>
### Step 1

Add a **Get Cell Value (HTTP)** node to your process flow.

### Step 2

Enter your **Tenant ID** in the configuration panel. This is the ID for your Azure AD account.

### Step 3

In the **Client ID** field, input your Azure AD Client ID.

### Step 4

Enter your **Client Secret**. Ensure this is kept confidential as it is used for authentication.

### Step 5

In **Drive ID**, provide the ID associated with your OneDrive or SharePoint drive where the Excel file is located.

### Step 6

Specify the **File Path** to indicate where the Excel file resides within your drive (e.g., 'Reports/Data.xlsx').

### Step 7

Input the **Worksheet Name** for the specific sheet you wish to access, such as 'Sheet1'.

### Step 8

Enter the **Cell Address** using A1 notation to specify the exact cell to retrieve (e.g., 'B5').

### Step 9

After processing, the fetched cell value will be available to use as **CellValue** in subsequent nodes.
</Steps>

<Callout type="warning" title="Important">
  Ensure all input fields are filled accurately. Incorrect Tenant ID, Client ID, or File Path may cause errors while accessing the cell value.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                                | Solution                                                                                                                                                         |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Connection Errors**                                  | Double-check your Tenant ID, Client ID, and Client Secret entries. Ensure network connection is stable.                                                          |
| **Incorrect File Path or Worksheet Name**              | Verify the File Path and Worksheet Name are correct and match the exact names used in your OneDrive or SharePoint directories.                                    |
| **Invalid Cell Address**                               | Make sure the Cell Address uses A1-style notation. Incorrect formats or non-existent cells will lead to errors.                                                  |
| **Unauthorized Access**                                | Check your Azure credentials and permissions. Ensure your Azure account has the necessary permissions to access the specified files.                              |

## Real-World Use Cases

- **Dynamic Reporting and Dashboards**: Automatically fill dashboards with real-time data by pulling specific values from source spreadsheets.
- **Data Validation**: Fetch exact values for auditing entries in spreadsheets.
- **Finance and Budgeting**: Read specific budget metrics or financial data points directly from a central financial repository Excel file for analysis.
