# Filter Table or Range

The **Filter Table or Range** node allows you to apply specific filter conditions to designated tables or cell ranges within your Excel workbooks. This is particularly useful for business users who need to focus on specific subsets of data, such as filtering for certain departments, sales figures above a threshold, or records belonging to a particular category.

For example, you can:

- Filter data in an Excel file to show rows where sales were above $100.
- Highlight only the marketing department information from a large dataset.
- Extract records starting with a specific name or value.

## Configuration Options

| Field Name        | Description                                                                                      | Input Type | Required? | Default Value |
| ----------------- | ------------------------------------------------------------------------------------------------ | ---------- | --------- | ------------- |
| **Tenant ID**     | The Azure Active Directory tenant ID (e.g., `contoso.onmicrosoft.com`).                           | Text       | Yes       | _(empty)_     |
| **Client ID**     | The Azure AD application ID registered in your tenant.                                           | Text       | Yes       | _(empty)_     |
| **Client Secret** | The client secret (password) of the Azure AD application for authentication.                      | Password   | Yes       | _(empty)_     |
| **Drive ID**      | The unique identifier of the OneDrive or SharePoint document library drive.                       | Text       | Yes       | _(empty)_     |
| **Item ID**       | The unique identifier of the Excel file within the drive.                                        | Text       | Yes       | _(empty)_     |
| **Table or Range**| The name of an Excel table (e.g., 'Table1') or a cell range address (e.g., 'A1:D100').           | Text       | Yes       | _(empty)_     |
| **Filter Column** | The column name or letter/number to filter by (e.g., 'Department' or 'B').                      | Text       | Yes       | _(empty)_     |
| **Filter Criteria**| The value or condition to apply as the filter (e.g., 'Sales', '>=100', or 'John*').            | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output from the Filter Table or Range node is a filtered version of your Excel table or range. The data structure will remain as a table or range, but it will only include rows that match your specified criteria.

## Step-by-Step Guide

<Steps>

### Step 1

Add **Filter Table or Range** node into your flow.

### Step 2

Enter your **Tenant ID**. This should be your Azure directory identifier, such as `contoso.onmicrosoft.com`.

### Step 3

Provide the **Client ID** associated with your Azure AD application.

### Step 4

Enter the **Client Secret** for the Azure AD application to allow authentication.

### Step 5

Specify the **Drive ID** for the OneDrive or SharePoint library where your Excel file is located.

### Step 6

Input the **Item ID** of the Excel file you plan to filter.

### Step 7

Define the **Table or Range** by entering the Excel table name or the cell range (e.g., `Table1` or `A1:D100`).

### Step 8

Indicate the **Filter Column** you wish to filter, such as 'Department' for tables or 'B' for ranges.

### Step 9

Set the **Filter Criteria** that needs to be met for a row to be displayed (e.g., `Sales`, `>=100`, or `John*`).

</Steps>

<Callout type="warning" title="Important Note">
  Ensure all fields are filled accurately, especially IDs and authentication data, to avoid errors in fetching and filtering your Excel data.
</Callout>

## Input/Output Examples

| Table/Range      | Filter Column | Filter Criteria | Output Description                                  |
| ---------------- | ------------- | --------------- | --------------------------------------------------- |
| 'Table1'         | 'Department'  | 'Sales'         | Displays rows where the Department is "Sales".      |
| 'A1:D100'        | 'B'           | '>=100'         | Filters rows where column B has values 100 or higher.|
| 'Table2'         | 'Name'        | 'John*'         | Shows rows where the Name starts with "John".       |

## Common Mistakes & Troubleshooting

| Problem                              | Solution                                                                                                   |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| **Authentication Failure**           | Double-check your **Tenant ID**, **Client ID**, and **Client Secret** to ensure they are correctly entered.|
| **Data Not Filtering as Expected**   | Verify that the **Filter Column** and **Filter Criteria** are specified correctly according to your table or range. |
| **No Data Returned**                 | Make sure that the data and criteria match; otherwise, it might return an empty result if no rows meet the condition.|

## Real-World Use Cases

- **Marketing Data Analysis**: Quickly filter marketing data to target campaigns based on several conditions.
- **Financial Reporting**: Extract financial data that meets certain thresholds for a report.
- **Inventory Management**: View only products that need reordering by filtering on stock levels.
