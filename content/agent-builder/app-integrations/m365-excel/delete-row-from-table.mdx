# Delete Row from Table

The **Delete Row from Table** node is designed to remove a specific row from a table in an Excel file stored in OneDrive or SharePoint. This function is particularly useful for automating the maintenance of your Excel files by removing outdated or unnecessary data efficiently.

Common use cases include:

- Cleaning datasets by removing obsolete records.
- Automating routine data management tasks for reports.
- Simplifying data handling in larger tables.

## Configuration Options

| Field Name       | Description                                                   | Input Type | Required? | Default Value |
|------------------|---------------------------------------------------------------|------------|-----------|---------------|
| **Tenant ID**    | The Azure AD Tenant ID for authentication.                    | Text       | Yes       | _(empty)_     |
| **Client ID**    | The Azure AD Client ID for authentication.                    | Text       | Yes       | _(empty)_     |
| **Client Secret**| The Azure AD Client Secret for secure access.                 | Text       | Yes       | _(empty)_     |
| **Drive ID**     | The ID of the OneDrive or SharePoint drive holding the file.  | Text       | Yes       | _(empty)_     |
| **Item ID**      | The ID of the Excel file where the table is located.          | Text       | Yes       | _(empty)_     |
| **Table Name**   | The name of the table from which you wish to delete a row.    | Text       | Yes       | _(empty)_     |
| **Row Index**    | The 0-based index of the row you want to remove from the table.| Text      | Yes       | _(empty)_     |

## Expected Output Format

The output of this node does not produce a visible value but performs the action of removing the specified row from your Excel table. You can verify the deletion by retrieving the updated table data.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Delete Row from Table** node into your flow.

### Step 2

In the **Tenant ID** field, input your Azure Active Directory Tenant ID needed for access permission.

### Step 3

Enter your **Client ID** and **Client Secret** in their respective fields to authenticate and authorize access to your Microsoft account.

### Step 4

Specify the **Drive ID** to identify the OneDrive or SharePoint drive containing your file.

### Step 5

In the **Item ID** field, provide the unique identifier for the Excel file holding the table.

### Step 6

Enter the **Table Name** from which you want the row to be deleted.

### Step 7

Provide the **Row Index** value, indicating which row to delete, starting from 0.

### Step 8

Verify the row removal by checking the updated data in your Excel file.
</Steps>

<Callout type="info" title="Tip">
  Make sure you accurately enter the Row Index as it's 0-based, meaning the first row is index 0. Misidentifying could lead to deleting the wrong row.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                         | Solution                                                                                           |
|-------------------------------------------------|----------------------------------------------------------------------------------------------------|
| **Incorrect Tenant/Client ID**                  | Double-check your Azure AD credentials for accuracy.                                                |
| **Invalid Drive or Item ID**                    | Ensure Drive and Item IDs are obtained correctly from your OneDrive or SharePoint environment.      |
| **Empty Table Name or Row Index**               | Ensure that you fill all required fields, especially the specific Table Name and Row Index.         |
| **Unauthorized Access**                         | Check that you have the right permissions and have input the correct Client Secret.                 |

## Real-World Use Cases

- **Sales Data Updating**: Remove outdated entries in sales logs to keep only current records.
- **Inventory Management**: Delete entries for sold-out products to streamline current inventory.
- **Project Reporting**: Automate the removal of finished tasks to keep project files clean and updated.
