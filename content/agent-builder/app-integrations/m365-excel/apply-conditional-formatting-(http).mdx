# Apply Conditional Formatting (HTTP)

The **Apply Conditional Formatting (HTTP)** node enables you to dynamically modify the appearance of a specific range of cells in an Excel worksheet hosted on OneDrive or SharePoint. With this node, you can highlight important data, identify trends, and emphasize deviations all without manually editing the spreadsheet. This functionality is particularly useful for creating visually engaging reports and dashboards that automatically adapt to your data.

## Configuration Options

| Field Name                         | Description                                                                                                                                               | Input Type | Required? | Default Value |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**                      | Azure AD Tenant ID required to connect to your Microsoft services.                                                                                        | Text       | Yes       | _(empty)_     |
| **Client ID**                      | Azure AD Application Client ID for authentication purposes in accessing your Excel file.                                                                  | Text       | Yes       | _(empty)_     |
| **Client Secret**                  | Secret key used in combination with the Client ID to authenticate the Azure application.                                                                  | Text       | Yes       | _(empty)_     |
| **Drive ID**                       | Identifier of the OneDrive or SharePoint storage where your workbook is located.                                                                           | Text       | Yes       | _(empty)_     |
| **File Path**                      | Relative path to the Excel workbook within OneDrive or SharePoint (e.g., 'Reports/Dashboard.xlsx').                                                       | Text       | Yes       | _(empty)_     |
| **Worksheet Name**                 | Name of the worksheet that contains the range you want to format (e.g., 'SalesData').                                                                     | Text       | Yes       | _(empty)_     |
| **Range Address**                  | A1-style address of the cell range to which you wish to apply the formatting (e.g., 'B2:B100' or 'A1:D50').                                               | Text       | Yes       | _(empty)_     |
| **Conditional Formatting Rule (JSON)** | JSON string defining the conditional formatting rule, following the Microsoft Graph Excel conditional formatting schema. Example: `{"type":"cellIs","operator":"greaterThan","formula":["100"],"format":{"fill":{"color":"#FF0000"}}}`. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of the **Apply Conditional Formatting** node is a boolean value indicating the success (`true`) or failure (`false`) of the operation.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Apply Conditional Formatting (HTTP)** node into your flow.

### Step 2

Enter the **Tenant ID** relevant to your Azure environment for proper authorization.

### Step 3

Provide the **Client ID** of your Azure AD application to authenticate and access resources.

### Step 4

Add the **Client Secret** to securely authorize your application.

### Step 5

Input the **Drive ID** where your Excel workbook is stored, whether on OneDrive or SharePoint.

### Step 6

Specify the **File Path**, ensuring the relative path is accurate to locate your workbook.

### Step 7

Type the **Worksheet Name** to identify where the conditional formatting will be applied.

### Step 8

Define the **Range Address** in A1 notation to set the cell range subject to the formatting rule.

### Step 9

Provide a well-defined **Conditional Formatting Rule (JSON)** string to determine the formatting logic.

### Step 10

Execute the node to apply the formatting. A success message will confirm proper application.
</Steps>

<Callout type="warning" title="Important Note">
  Ensure that your JSON string for the Conditional Formatting Rule is correctly formatted and follows Microsoft's schema, or the formatting may not apply.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                                 | Solution                                                                                                                                                                            |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Authentication failures**                             | Ensure your Tenant ID, Client ID, and Client Secret are correct and have necessary permissions for the operation.                                                                    |
| **Invalid file paths**                                  | Double-check the File Path and Drive ID are correct and accessible.                                                                                                                 |
| **Improper JSON formatting**                            | Verify that your JSON string for the Conditional Formatting Rule adheres to the Microsoft schema. Use tools to validate JSON formatting if necessary.                                |
| **Incorrect Range Address**                             | Ensure the Range Address corresponds to an actual range in your worksheet.                                                                                                          |

## Real-World Use Cases

- **Financial Reporting**: Automatically highlight cells in financial statements that exceed budgeted amounts for quick identification.
- **Sales Dashboards**: Identify top-performing products or regions by applying color gradients in sales data sheets.
- **Project Management**: Emphasize overdue tasks or high-priority items within inventory or task lists.
- **Academic Records**: Differentiate student performance levels by applying color codes in gradebooks.
