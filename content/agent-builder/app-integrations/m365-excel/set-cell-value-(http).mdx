# Set Cell Value (HTTP)

The **Set Cell Value (HTTP)** node enables you to update the value of a specific cell within an Excel worksheet stored on OneDrive or SharePoint. By leveraging Microsoft Graph API, it allows seamless integration with Microsoft 365 services, making it ideal for scenarios where dynamic data updates in spreadsheets are required remotely.

For instance, you can:
- Automatically update sales figures in a report.
- Insert status updates in a project tracking sheet.
- Record data entries from various sources directly into Excel.

## Configuration Options

| Field Name        | Description                                                                                     | Input Type | Required? | Default Value |
| ----------------- | ----------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**     | The Azure AD tenant identifier (e.g., 'contoso.onmicrosoft.com' or a GUID).                      | Text       | Yes       | _(empty)_     |
| **Client ID**     | The Application (Client) ID of the Azure AD app registered to access Microsoft Graph.            | Text       | Yes       | _(empty)_     |
| **Client Secret** | The client secret of the Azure AD application with necessary permissions (e.g., Files.ReadWrite.All). | Text       | Yes       | _(empty)_     |
| **Drive ID**      | The unique ID of the OneDrive or SharePoint document library drive where the Excel file is stored. | Text       | Yes       | _(empty)_     |
| **File Path**     | The relative path to the Excel file in the drive (e.g., 'Reports/Summary.xlsx').                 | Text       | Yes       | _(empty)_     |
| **Worksheet Name**| The name of the worksheet containing the target cell (e.g., 'Sheet1').                           | Text       | Yes       | _(empty)_     |
| **Cell Address**  | The address of the cell to update, in A1-style notation (e.g., 'B5', 'Z100').                    | Text       | Yes       | _(empty)_     |
| **Cell Value**    | The value to write into the cell. Accepts numbers, text, or formulas (e.g., '123', 'Hello', '=SUM(A1:A10)'). | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is **confirmation of value update** in the desired cell. It does not return a data value but verifies that the HTTP request to set the cell value was processed successfully.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Set Cell Value (HTTP)** node into your flow.

### Step 2

Provide your Azure AD **Tenant ID** to authenticate the connection with Microsoft 365.

### Step 3

Enter the **Client ID** of your Azure AD application that you've registered for Graph API access.

### Step 4

Add the **Client Secret** to authorize API requests needed to access and modify Excel files.

### Step 5

Specify the **Drive ID** where your target Excel file is located. This could be a OneDrive or SharePoint document library.

### Step 6

Input the **File Path** representing the location of your Excel file within the selected drive.

### Step 7

Set the **Worksheet Name** where the target cell exists that you wish to modify.

### Step 8

Define the **Cell Address** using A1-style notation indicating exactly which cell to update.

### Step 9

Enter the **Cell Value** that you want to assign to the specified cell.

### Step 10

Confirm the setup and run the node to update the Excel cell with the provided value.

</Steps>

<Callout type="info" title="Note">
Ensure all input fields are filled with the correct identifiers, credentials, and data paths to successfully execute the operation and update the worksheet.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                            | Solution                                                                                         |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Invalid credentials or expired tokens**          | Check your Azure credentials for accuracy and refresh the token if necessary.                    |
| **Incorrect Drive or File Path specified**         | Verify the Drive ID and File Path to ensure they point to the correct location.                  |
| **Cell not updating or throwing errors**           | Ensure the Cell Address is formatted correctly and the worksheet is named accurately.            |
| **Permissions error when writing to file**         | Double-check that your app has the required permissions to access and modify the file contents.  |
