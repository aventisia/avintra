# Refresh PivotTable or Query

The **Refresh PivotTable or Query** node is designed to update a PivotTable or Power Query in a Microsoft Excel workbook that is stored in OneDrive or SharePoint. Use this node when you need to ensure your data remains current and reflects any new updates or calculations without manually refreshing in Excel.

This is especially useful for:

- Automatically updating dashboards.
- Ensuring reports always use the latest data.
- Keeping linked data sources up-to-date in shared environments.

## Configuration Options

| Field Name                     | Description                                                                                   | Input Type | Required? | Default Value |
| ------------------------------ | --------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**                  | The Azure Active Directory tenant ID (e.g., 'contoso.onmicrosoft.com' or a GUID).             | Text       | Yes       | _(empty)_     |
| **Client ID**                  | The Application (Client) ID of the Azure AD registered app used for authentication.           | Text       | Yes       | _(empty)_     |
| **Client Secret**              | The client secret (password) for authentication with Azure AD.                                | Text       | Yes       | _(empty)_     |
| **Drive ID**                   | The unique identifier for the OneDrive or SharePoint location where the Excel file is stored. | Text       | Yes       | _(empty)_     |
| **Item ID**                    | The unique identifier for the Excel workbook file within the drive.                           | Text       | Yes       | _(empty)_     |
| **PivotTable or Query Name**   | The name of the PivotTable or Query within the Excel workbook that you want to refresh.       | Text       | Yes       | _(empty)_     |

## Expected Output Format

There is no direct data output from this node. The action taken by this node is to refresh the specified PivotTable or Query within an Excel workbook.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Refresh PivotTable or Query** node into your automation flow.

### Step 2

In the **Tenant ID** field, enter the Azure Active Directory tenant ID associated with your organization (e.g., `contoso.onmicrosoft.com`).

### Step 3

Enter your **Client ID** in the corresponding field. This ID is the Application (Client) ID of your registered Azure AD app.

### Step 4

Fill in the **Client Secret** field with the appropriate secret (password) for Azure AD authentication. Ensure this is kept secure.

### Step 5

Input the **Drive ID**, which is the unique identifier for where your Excel file is stored on OneDrive or SharePoint.

### Step 6

Specify the **Item ID**, representing the specific Excel workbook file you want to update.

### Step 7

Finally, enter the exact **PivotTable or Query Name** you wish to refresh within that Excel workbook.

</Steps>

<Callout type="info" title="Tip">
  Ensure all identifiers (Tenant, Client, Drive, and Item IDs) are correctly input to avoid authentication errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                          | Solution                                                                                                             |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **Authentication Failure**                       | Double-check your Tenant ID, Client ID, and Client Secret for accuracy. Ensure they match those in your Azure setup. |
| **Incorrect Drive or Item ID**                   | Verify that the IDs correspond to the correct OneDrive or SharePoint paths and files.                                |
| **Named PivotTable or Query not found**          | Ensure the name of the PivotTable or Query matches exactly what is in the Excel file, including any case sensitivity.|

## Real-World Use Cases

- **Financial Forecasting Models**: Refresh linked data tables to ensure projections incorporate the latest figures.
- **Sales Reports**: Automatically update sales dashboards with refreshed queries showing real-time metrics.
- **Operational Dashboards**: Keep KPIs reflective of the most current data without manual refresh, increasing efficiency and accuracy.
