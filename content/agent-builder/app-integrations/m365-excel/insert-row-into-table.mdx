# Insert Row into Table

The **Insert Row into Table** node helps you automate the process of adding new data rows to tables in Excel spreadsheets stored on OneDrive or SharePoint. This node is essential when you need to update your Excel databases regularly without manually adding rows one at a time. With this node, you effortlessly integrate data from other sources by specifying the table and row values directly within the platform.

## Configuration Options

| Field Name       | Description                                                                 | Input Type | Required? | Default Value |
| ---------------- | --------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**    | Azure AD Tenant ID used for authentication.                                 | Text       | Yes       | _(empty)_     |
| **Client ID**    | Azure AD Client ID, identifies your application in Azure AD.                | Text       | Yes       | _(empty)_     |
| **Client Secret**| Azure AD Client Secret, used together with Tenant ID and Client ID.         | Text       | Yes       | _(empty)_     |
| **Drive ID**     | ID of the OneDrive or SharePoint drive where the Excel file is stored.      | Text       | Yes       | _(empty)_     |
| **Item ID**      | ID of the Excel file (Item ID) within OneDrive or SharePoint.               | Text       | Yes       | _(empty)_     |
| **Table Name**   | Name of the target table where the new row should be inserted.              | Text       | Yes       | _(empty)_     |
| **Row Values JSON**| A JSON array specifying new row values, e.g., [["value1", "value2"]].      | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **confirmation message** indicating that a new row has been successfully inserted into the specified table.

- Example Output: `"Row successfully inserted"`.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Insert Row into Table** node into your flow.

### Step 2

In the **Tenant ID** field, enter your Azure Active Directory Tenant ID.

### Step 3

Enter your Azure Active Directory **Client ID** to identify your application.

### Step 4

Input your **Client Secret**. Ensure this is kept secure and private.

### Step 5

In the **Drive ID** field, provide the ID of the drive containing your target Excel file. This could be a OneDrive or SharePoint drive ID.

### Step 6

Enter the **Item ID** of your Excel file. This ID locates the specific file within the selected drive.

### Step 7

In the **Table Name** field, specify the name of the table where the new data row needs to be inserted.

### Step 8

Enter the **Row Values JSON**, a JSON formatted array of arrays representing your data row values. Example: `[["value1", "value2"]]`.

### Step 9

Execute the flow. A confirmation message will be displayed upon success, indicating the insertion of the row.
</Steps>

<Callout type="warning" title="Note">
  Ensure all IDs and JSON inputs are correct to avoid authentication errors and incorrect data entries.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                                   | Solution                                                                                       |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **Authentication failed**                                 | Verify that Tenant ID, Client ID, and Client Secret are entered correctly and remain unexpired.|
| **Invalid JSON format in Row Values JSON**                | Ensure JSON structure follows the format of arrays within arrays, e.g., `[["value1", "value2"]]`.|
| **Table not found error**                                 | Confirm the table name matches exactly with what's in the Excel file, including case sensitivity.|
