# Merge Cells (HTTP)

The **Merge Cells (HTTP)** node helps you combine a range of Excel cells into a single merged cell using Microsoft Graph API. This is particularly useful when standardizing content presentation in spreadsheets, as it allows you to create headings or formatted areas in Excel files stored on OneDrive or SharePoint. 

## Configuration Options

| Field Name        | Description                                                                                                                                             | Input Type | Required? | Default Value |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**     | The Azure AD tenant identifier. Use your company's ID or domain (e.g., `contoso.onmicrosoft.com` or a GUID). It's needed to authenticate with Microsoft 365. | Text       | Yes       | _(empty)_     |
| **Client ID**     | The Application (Client) ID of your Azure AD app that accesses Microsoft Graph.                                                                         | Text       | Yes       | _(empty)_     |
| **Client Secret** | The client secret of your Azure AD application, with permissions like `Files.ReadWrite.All`. Keep this value secure.                                     | Text       | Yes       | _(empty)_     |
| **Drive ID**      | Unique ID of the drive in OneDrive or SharePoint where the Excel file exists.                                                                           | Text       | Yes       | _(empty)_     |
| **File Path**     | Path to the Excel file, relative to the drive's root (e.g., `Reports/Dashboard.xlsx`).                                                                  | Text       | Yes       | _(empty)_     |
| **Worksheet Name**| The name of the worksheet where the cell range you wish to merge is located.                                                                            | Text       | Yes       | _(empty)_     |
| **Range Address** | A1-style address of the range to merge (e.g., `A1:D1`). Must be rectangular and not overlap with any currently merged cells.                             | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output from the **Merge Cells (HTTP)** node does not return any value directly in the automation flow. Instead, it performs an action on the specified Excel file by merging the cells within the specified range.

## Step-by-Step Guide

<Steps>

### Step 1

Add the **Merge Cells (HTTP)** node into your automation flow.

### Step 2

Enter your **Tenant ID**. This identifies your Azure Active Directory tenancy.

### Step 3

Provide the **Client ID** linked to your Azure application that can access Microsoft Graph.

### Step 4

Input the **Client Secret** for your application to authenticate and authorize access securely.

### Step 5

Specify the **Drive ID** where your Excel file is located. This will be the drive on OneDrive or SharePoint.

### Step 6

In the **File Path** field, type the path to your Excel file, starting from the drive's root. Example: `Reports/Dashboard.xlsx`.

### Step 7

Enter the **Worksheet Name** that contains the cells you want to merge.

### Step 8

Define the **Range Address** for the cells you want to merge, using an A1-style range (e.g., `A1:D1`).

</Steps>

<Callout type="warning" title="Important Note">
  Make sure to have the correct permissions set in your Azure AD application used for authentication, such as `Files.ReadWrite.All`, to allow editing of files.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                                           | Solution                                                                                                                                                           |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Invalid Tenant or Client ID**                                   | Verify that you have entered the correct IDs for your Azure AD tenant and application.                                                                              |
| **Unauthorized Error**                                            | Check that the **Client Secret** is correct and that the application has necessary permissions in Azure AD.                                                         |
| **Incorrect Range Address**                                       | Ensure the **Range Address** is not overlapping with any existing merged cells and adheres to the A1-style notation.                                                |
| **File Access Issues**                                            | Double-check the **File Path** and **Drive ID** to confirm they point to the right file and location.                                                              |

## Real-World Use Cases

- **Report Formatting**: Combine header cells in automated report generation for a standardized appearance.
- **Data Presentation**: Organize Excel workbooks in SharePoint for easy reading by merging titles or sections.
- **Collaborative Worksheets**: Ensure consistency across shared documents by programmatically merging cells as part of an update process.
