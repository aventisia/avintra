# Update Table Row

The **Update Table Row** node is designed to modify an existing row in a table within an Excel workbook stored on OneDrive or SharePoint. This node is beneficial for automating data updates efficiently, ensuring your Excel tables are always current without manual intervention.

## Configuration Options

| Field Name           | Description                                                     | Input Type | Required? | Default Value |
| -------------------- | --------------------------------------------------------------- | ---------- | --------- | -------------- |
| **Tenant ID**        | Azure AD Tenant ID for authentication.                           | Text       | Yes       | _(empty)_      |
| **Client ID**        | Azure AD Client ID used for accessing your resources.            | Text       | Yes       | _(empty)_      |
| **Client Secret**    | Azure AD Client Secret associated with your application.         | Text       | Yes       | _(empty)_      |
| **Drive ID**         | Specifies the ID of the OneDrive or SharePoint drive.            | Text       | Yes       | _(empty)_      |
| **Item ID**          | The unique ID of the Excel file you are updating.                | Text       | Yes       | _(empty)_      |
| **Table Name**       | The specific name of the table within the Excel file.            | Text       | Yes       | _(empty)_      |
| **Row Index**        | The zero-based index indicating the particular row to update.    | Text       | Yes       | _(empty)_      |
| **Values (JSON Array)** | A JSON array consisting of new values to update for that row. | Text       | Yes       | _(empty)_      |

## Expected Output Format

After executing this node, the output does not generate a visible result within the node itself. Instead, it ensures the specified row in the Excel table is updated according to the input values provided.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Update Table Row** node to your automation flow.

### Step 2

Enter the **Tenant ID** to authenticate with Azure Active Directory.

### Step 3

Provide the **Client ID** associated with your Azure resources.

### Step 4

Input the **Client Secret** for secure access to your application.

### Step 5

Specify the **Drive ID** where the Excel file is stored (OneDrive or SharePoint).

### Step 6

Enter the **Item ID** to identify the exact Excel file you intend to update.

### Step 7

Specify the **Table Name** within the Excel workbook that contains the row.

### Step 8

Indicate the **Row Index** for the row you wish to update (starting from `0`).

### Step 9

Input the **Values (JSON Array)** containing new data for the specified row. Ensure that the JSON structure matches the table's column order.

</Steps>

<Callout type="info" title="Tip">
  Confirm that your JSON structure within **Values (JSON Array)** aligns correctly with the table's columns to prevent update errors.
</Callout>

## Input/Output Examples

- Example Input for **Values (JSON Array)**: `["John Doe", "30", "Engineer", "New York"]` 
  - Given that the table columns are [Name, Age, Job Title, Location].
- Updated Row Output: The row in the table changes accordingly, but you will not directly see an output in the interface.

## Common Mistakes & Troubleshooting

| Problem                   | Solution                                                            |
| ------------------------- | ------------------------------------------------------------------- |
| **Authentication Errors** | Double-check your Azure AD credentials: Tenant ID, Client ID, and Client Secret. |
| **Incorrect Table or Row**| Verify the **Table Name** and the **Row Index** to ensure accurate targeting. |
| **JSON Format Errors**    | Make sure your **Values (JSON Array)** is correctly formatted as a JSON array. |

## Real-World Use Cases

- **Employee Records Update**: Modify specific details such as job title or location for employee records stored in Excel.
- **Inventory Management**: Automatically adjust inventory counts or product details based on sales or stock updates.
- **Dynamic Reporting**: Update data for reports in real-time as new information becomes available.
