# Delete Table (HTTP)

The **Delete Table (HTTP)** node enables you to remove a specific table from an Excel workbook stored in OneDrive or SharePoint. This is particularly useful when you need to clear outdated or unnecessary table data from a workbook without manually opening and editing the file.

For example:

- Automating cleanup tasks by removing tables with past data.
- Managing space in workbooks by deleting obsolete tables.
- Streamlining workbook updates without manual intervention.

## Configuration Options

| Field Name       | Description                                                                                | Input Type | Required? | Default Value |
| ---------------- | ------------------------------------------------------------------------------------------ | ---------- | --------- | ------------- |
| **Tenant ID**    | The Azure Active Directory (AD) Tenant ID you are working with.                             | Text       | Yes       | _(empty)_     |
| **Client ID**    | The Azure AD application Client ID needed for authentication.                               | Text       | Yes       | _(empty)_     |
| **Client Secret**| The Azure AD application Client Secret for secure access authentication.                    | Text       | Yes       | _(empty)_     |
| **Drive ID**     | The ID of the OneDrive or SharePoint Drive where the Excel file is stored.                  | Text       | Yes       | _(empty)_     |
| **Item ID**      | The Item ID representing the specific Excel file containing the table to be deleted.        | Text       | Yes       | _(empty)_     |
| **Table Name**   | The exact name of the Excel table you wish to delete (such as 'Table1'). Ensure it matches an existing table in your workbook. | Text       | Yes       | _(empty)_     |

## Expected Output Format

There is no direct output value from this node. The successful operation will be the deletion of the specified table from the Excel workbook.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Delete Table (HTTP)** node into your flow.

### Step 2

Fill in the **Tenant ID** with your Azure AD tenant's ID.

### Step 3

Enter your Azure AD application **Client ID**.

### Step 4

Provide the **Client Secret** for your Azure AD application.

### Step 5

Specify the **Drive ID** where your Excel file is located in OneDrive or SharePoint.

### Step 6

Input the **Item ID** of the Excel workbook that contains the table you wish to delete.

### Step 7

Type the **Table Name** exactly as it appears in your Excel workbook. This is the table you intend to remove.

### Step 8

Execute the flow. Upon successful completion, the specified table will be removed from your Excel workbook.

</Steps>

<Callout type="warning" title="Important">
  Ensure that all IDs and the table name are entered accurately to avoid errors in execution. An incorrect table name or ID will prevent the node from performing the deletion.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                              | Solution                                                                                   |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **Unauthorized Access Error**                        | Verify that the Tenant ID, Client ID, and Client Secret are correctly filled and authorized.|
| **Table Not Found**                                  | Double-check the Table Name for spelling errors or inaccuracies. Ensure the table exists.   |
| **Incorrect Drive or Item ID**                       | Confirm that the IDs for Drive and Item reflect the actual storage paths of the Excel file. |

## Real-World Use Cases

- **Monthly Report Management**: Automatically delete the previous month's table after generating a new set of data to keep workbooks updated.
- **Data Cleanup**: Regularly clean old tables that are no longer in use to optimize storage and performance.
- **Workflow Transition**: Remove obsolete data tables when transitioning to new data models or reporting systems.
