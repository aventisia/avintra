# Unmerge Cells (HTTP)

The **Unmerge Cells (HTTP)** node is designed to simplify document management in Excel files stored on OneDrive or SharePoint. It allows you to unmerge previously merged cells within a specific range of a worksheet. This function is helpful when you need to individually manipulate or format data that was previously grouped together in an Excel document.

For example:

- Reverting merged header cells in a report to edit individually.
- Modifying shared data in cells that were combined for presentation.
- Preparing data for analysis by separating combined data entries.

## Configuration Options

| Field Name         | Description                                                                                     | Input Type | Required? | Default Value |
| ------------------ | ----------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**      | The Azure AD tenant identifier (e.g., 'contoso.onmicrosoft.com' or a GUID) for Microsoft 365.   | Text       | Yes       | _(empty)_     |
| **Client ID**      | The Application (Client) ID of the Azure AD app registered to access Microsoft Graph.           | Text       | Yes       | _(empty)_     |
| **Client Secret**  | The client secret of the Azure AD application, with required permissions (e.g., Files.ReadWrite.All). | Text       | Yes       | _(empty)_     |
| **Drive ID**       | The unique ID of the OneDrive or SharePoint document library drive where the file is stored.    | Text       | Yes       | _(empty)_     |
| **File Path**      | The relative path to the Excel file within the drive (e.g., 'Reports/Financials.xlsx').        | Text       | Yes       | _(empty)_     |
| **Worksheet Name** | The name of the worksheet containing the merged cells to unmerge (e.g., 'Summary').            | Text       | Yes       | _(empty)_     |
| **Range Address**  | The address of the merged cell range to unmerge, in A1 notation (e.g., 'A1:D1').               | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node reflects the successful completion of unmerging operations. The response confirms that the specified merged cell range has been unmerged. The type of output is a confirmation message in plain text format.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Unmerge Cells (HTTP)** node into your flow.

### Step 2

Enter your Azure AD **Tenant ID**. This is used for authentication with Microsoft 365.

### Step 3

Input the **Client ID** of your Azure AD application registered with Microsoft Graph.

### Step 4

Provide the **Client Secret** associated with the Azure AD application that has appropriate permissions.

### Step 5

Specify the **Drive ID** where the OneDrive or SharePoint file is stored.

### Step 6

Input the **File Path** to the Excel file, noting its relative path within the drive.

### Step 7

Enter the **Worksheet Name** where the merged cells are located.

### Step 8

Provide the **Range Address** of the merged cells you wish to unmerge in A1 notation.

### Step 9

Execute the node to perform the unmerge operation. A message confirming the unmerge will be displayed.

</Steps>

<Callout type="info" title="Important Note">
  Ensure your Azure AD application has the necessary permissions such as Files.ReadWrite.All to modify files.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                       | Solution                                                                                                                                       |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Invalid Tenant ID error**                   | Ensure the Tenant ID entered is correct and follows the format (e.g., 'contoso.onmicrosoft.com' or GUID).                                      |
| **Permission Denied**                         | Check that the Azure AD application has appropriate permissions such as Files.ReadWrite.All.                                                   |
| **Incorrect Range Address**                   | Verify the Range Address matches exactly with an existing merged range in the worksheet.                                                       |
| **File Not Found**                            | Confirm that the File Path specified is correct and the file exists in the mentioned drive.                                                    |
