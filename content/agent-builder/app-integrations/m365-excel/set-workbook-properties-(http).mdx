# Set Workbook Properties (HTTP)

The **Set Workbook Properties (HTTP)** node allows you to assign or modify metadata for an Excel workbook stored in OneDrive or SharePoint. This functionality is helpful for keeping your documents organized and easily searchable through meaningful metadata like Title, Author, and Keywords.

For example:

- Setting the title for identification in a shared document library.
- Adding an author's name for clarity about document ownership.
- Including keywords for improved searchability in a large archive.

## Configuration Options

| Field Name           | Description                                                                                     | Input Type | Required? | Default Value |
| -------------------- | ----------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**        | The Azure AD tenant identifier (e.g., 'contoso.onmicrosoft.com' or a GUID).                      | Text       | Yes       | _(empty)_     |
| **Client ID**        | The Application (Client) ID of the Azure AD app registered for Microsoft Graph access.           | Text       | Yes       | _(empty)_     |
| **Client Secret**    | The client secret of the Azure AD app, with the needed permissions for document modifications.   | Text       | Yes       | _(empty)_     |
| **Drive ID**         | The unique ID of the OneDrive or SharePoint drive where the workbook is located.                 | Text       | Yes       | _(empty)_     |
| **File Path**        | The path to the Excel file within the drive (e.g., 'Reports/AnnualReport.xlsx').                | Text       | Yes       | _(empty)_     |
| **Title**            | The document title to assign in the workbook's metadata (e.g., 'Q3 Financial Summary').         | Text       | No        | _(empty)_     |
| **Author**           | The author's name to include in the workbook's properties (e.g., 'Finance Team').               | Text       | No        | _(empty)_     |
| **Keywords**         | Keywords for indexing and searching the document (e.g., 'finance, quarterly, 2024').            | Text       | No        | _(empty)_     |

## Expected Output Format

This node does not produce a visible output value. Instead, it updates the metadata of the specified Excel workbook. No direct numerical or text data is output, but changes are reflected in the document properties.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Set Workbook Properties (HTTP)** node into your flow.

### Step 2

In the **Tenant ID** field, input your Azure AD tenant identifier. It could be a domain like `contoso.onmicrosoft.com` or a GUID.

### Step 3

Provide the **Client ID** from your registered Azure AD application intended for Microsoft Graph.

### Step 4

Enter the **Client Secret** related to your Azure AD application. Ensure it has permissions like `Files.ReadWrite.All`.

### Step 5

Fill in the **Drive ID** with the unique identifier of the OneDrive or SharePoint drive storing the workbook.

### Step 6

Input the **File Path** to specify the document's exact location within the drive.

### Step 7

(Optional) Specify a **Title** for the document if you wish to set or update it.

### Step 8

(Optional) Provide an **Author** name to associate with the document.

### Step 9

(Optional) Add any **Keywords** to improve searchability.

### Step 10

Confirm settings and run the flow to update the workbook's properties.
</Steps>

<Callout type="info" title="Important">
  Ensure that the Azure AD app permissions are correctly set to access and modify the workbook's properties.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                                  | Solution                                                                                                                      |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **Authentication errors**                                | Verify that your Tenant ID, Client ID, and Client Secret are correctly entered and have the required permissions.              |
| **Invalid Drive ID or File Path**                        | Double-check the Drive ID and File Path for typos or inaccuracies. Make sure the file path is relative to the root of the drive.|
| **Metadata not updating**                                | Ensure that all required fields are filled correctly, and the app has appropriate permissions to make changes.                |

## Real-World Use Cases

- **Document Libraries**: Manage metadata for numerous reports stored on collaborative platforms like SharePoint.
- **Corporate Archives**: Keep large collections of documents well-indexed and easily retrievable with meaningful metadata.
- **Team Workspaces**: Assign document ownership and ensure accurate document metadata in shared team folders.
