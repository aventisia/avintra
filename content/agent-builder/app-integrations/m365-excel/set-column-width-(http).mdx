# Set Column Width (HTTP)

The **Set Column Width (HTTP)** node allows you to adjust the width of a specific column in an Excel worksheet stored in OneDrive or SharePoint. This is useful when you need to standardize column widths for better readability or presentation in reports and data sheets.

For example:

- Setting the width of a "Date" column to fit date formats without truncation.
- Adjusting the width of a "Description" column to avoid cut-off text.
- Ensuring uniform column widths across multiple sheets for consistency.

## Configuration Options

| Field Name           | Description                                                                                          | Input Type | Required? | Default Value |
| -------------------- | ---------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**        | The Azure AD tenant identifier (e.g., 'contoso.onmicrosoft.com' or a GUID). Used for authentication. | Text       | Yes       | _(empty)_     |
| **Client ID**        | The Application (Client) ID of the Azure AD app registered to access Microsoft Graph.                  | Text       | Yes       | _(empty)_     |
| **Client Secret**    | The client secret of the Azure AD application.                                                        | Text       | Yes       | _(empty)_     |
| **Drive ID**         | The unique ID of the OneDrive or SharePoint drive where the Excel file is stored.                     | Text       | Yes       | _(empty)_     |
| **File Path**        | The relative path to the Excel file in the drive (e.g., 'Reports/Dashboard.xlsx').                    | Text       | Yes       | _(empty)_     |
| **Worksheet Name**   | The name of the worksheet that contains the column you wish to adjust.                                | Text       | Yes       | _(empty)_     |
| **Column Index**     | The 1-based index of the column to resize (e.g., 1 for column A, 2 for B).                            | Text       | Yes       | _(empty)_     |
| **Width**            | The new column width in characters. Must be a positive number.                                        | Text       | Yes       | _(empty)_     |

## Expected Output Format

This node does not produce a visible output in data format but performs an action on the specified Excel file by adjusting the column width as configured.

## Step-by-Step Guide

<Steps>

### Step 1

Add the **Set Column Width (HTTP)** node into your flow.

### Step 2

In the **Tenant ID** field, enter your Azure AD tenant identifier for authentication.

### Step 3

Enter your registered Azure application's **Client ID**.

### Step 4

Provide the **Client Secret** of your Azure AD application. Ensure it has the necessary permissions.

### Step 5

Enter the **Drive ID** for the location where your Excel file is stored.

### Step 6

In **File Path**, specify the path to your Excel file relative to the drive (e.g., 'Reports/Dashboard.xlsx').

### Step 7

Specify the **Worksheet Name** where the column you want to resize is located.

### Step 8

Enter the **Column Index** of the column whose width you want to change (e.g., 1 for column A).

### Step 9

Set the desired **Width** for the column in terms of character count. Ensure this is a positive number.

</Steps>

<Callout type="info" title="Important Note">
  Ensure your Azure credentials (Tenant ID, Client ID, Client Secret) are correct and have the necessary privileges to modify files.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                          | Solution                                                                                                  |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| **Authentication Failures**                      | Verify the Tenant ID, Client ID, and Client Secret, ensuring correct values and necessary permissions.     |
| **Invalid Column Index**                         | Check that the Column Index is a valid number, starting from 1 for the first column in the worksheet.      |
| **File Not Found**                               | Ensure the File Path and Drive ID are accurate and point to the correct file stored in OneDrive or SharePoint.|

## Real-World Use Cases

- **Report Formatting**: Standardizing column widths in monthly reports so they print clearly.
- **Data Sheets**: Adjusting widths of data columns to ensure all content is visible without extra scrolling.
- **Team Coordination**: Setting uniform column widths across team files for consistency in presentations.
