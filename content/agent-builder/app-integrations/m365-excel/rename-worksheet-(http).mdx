# Rename Worksheet (HTTP)

The **Rename Worksheet (HTTP)** node is used to change the name of an existing worksheet within an Excel workbook stored in OneDrive or SharePoint. This can be useful for organizing documents, making worksheet titles more descriptive, or adhering to naming conventions. 

Use this node when you want to update a worksheet's name without directly accessing the Excel file manually, saving you time and ensuring automation consistency.

## Configuration Options

| Field Name          | Description                                                                                                                                                    | Input Type | Required? | Default Value |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**       | The Azure AD tenant identifier (e.g., 'contoso.onmicrosoft.com' or a GUID). Used to authenticate with Microsoft 365.                                           | Text       | Yes       | _(empty)_     |
| **Client ID**       | The Application (Client) ID of the Azure AD app registered to access Microsoft Graph.                                                                           | Text       | Yes       | _(empty)_     |
| **Client Secret**   | The client secret of the Azure AD application. Ensure it has the necessary permissions (e.g., Files.ReadWrite.All).                                             | Text       | Yes       | _(empty)_     |
| **Drive ID**        | The unique ID of the OneDrive or SharePoint document library drive where the workbook is stored.                                                               | Text       | Yes       | _(empty)_     |
| **File Path**       | The relative path to the Excel file in the drive (e.g., 'Reports/Analysis.xlsx').                                                                             | Text       | Yes       | _(empty)_     |
| **Worksheet ID**    | The unique Microsoft Graph ID of the worksheet to rename. This is not the worksheet name.                                                                       | Text       | Yes       | _(empty)_     |
| **New Worksheet Name** | The new name for the worksheet (e.g., 'Q3_Summary'). Must be unique within the workbook and not contain invalid characters like \ / ? * [ ].                | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is the confirmation message indicating the success or failure of the worksheet renaming operation. This message remains in a simple text format.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Rename Worksheet (HTTP)** node into your flow.

### Step 2

In the **Tenant ID** field, enter your Azure AD tenant identifier. This could be in the form of 'contoso.onmicrosoft.com' or as a unique GUID.

### Step 3

Enter the necessary **Client ID** of your registered Azure AD app that will access Microsoft Graph in the corresponding field.

### Step 4

In the **Client Secret** field, provide the secret for the Azure AD application. Ensure it has been granted the proper permissions like Files.ReadWrite.All.

### Step 5

Type the **Drive ID**, which is the unique ID for the OneDrive or SharePoint drive holding your workbook.

### Step 6

Input the **File Path** to the Excel workbook you wish to edit, such as 'Reports/Analysis.xlsx'.

### Step 7

Enter the **Worksheet ID** of the worksheet you want to rename. Remember, this differs from its current name.

### Step 8

In the **New Worksheet Name** field, provide the new name for your worksheet. Ensure it is unique within the workbook and free from special characters like \ / ? * [ ].

### Step 9

Once all necessary fields are filled out, the operation will rename the worksheet as specified.

</Steps>

<Callout type="info" title="Note">
  Ensure all necessary permissions are set for the Azure AD app to avoid authentication errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                                       | Solution                                                                                                                                   |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Authentication failed**                                   | Verify that the Azure AD tenant, client ID, and secret are accurate, and the app has proper permissions.                                     |
| **Invalid New Worksheet Name**                               | Ensure the new name is unique within the workbook and does not include invalid characters (\ / ? * [ ]).                                     |
| **Incorrect File Path**                                      | Double-check the file path in the field to ensure it correctly points to the file location in OneDrive or SharePoint.                        |
| **Incorrect ID Inputs**                                      | Confirm that the Drive ID and Worksheet ID are accurate and match those provided by Microsoft Graph.                                        |

## Real-World Use Cases

- **Monthly Reporting**: Automatically update worksheet titles based on monthly report changes, e.g., from 'March_Sales' to 'April_Sales'.

- **Team Collaboration**: Rename worksheets in shared documents for clearer communication and easier reference by team members.

- **Document Organization**: Maintain uniform naming conventions across different workbooks for organized document retrieval and management.
