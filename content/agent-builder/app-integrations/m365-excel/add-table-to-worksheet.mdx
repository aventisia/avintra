# Add Table to Worksheet

The **Add Table to Worksheet** node is designed to facilitate the addition of a data table into a specified worksheet in an Excel file stored on OneDrive or SharePoint. This is particularly useful for business users needing to organize and tabulate data dynamically in Excel without manually entering it into each cell.

Common scenarios for using this node include:

- Automating the addition of sales data into a monthly report.
- Inserting data dynamically into Excel templates for reporting purposes.
- Streamlining data preparation processes for analysis.

## Configuration Options

| Field Name        | Description                                                          | Input Type | Required? | Default Value |
| ----------------- | -------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Tenant ID**     | Azure Active Directory tenant ID.                                    | Text       | Yes       | _(empty)_     |
| **Client ID**     | Azure Active Directory client ID.                                    | Text       | Yes       | _(empty)_     |
| **Client Secret** | Azure Active Directory client secret key.                            | Text       | Yes       | _(empty)_     |
| **Drive ID**      | The ID of the OneDrive or SharePoint drive where the Excel file is located. | Text  | Yes       | _(empty)_     |
| **Item ID**       | The ID of the Excel file to which a table will be added.             | Text       | Yes       | _(empty)_     |
| **Worksheet Name**| The name of the worksheet where the table should be inserted.        | Text       | Yes       | _(empty)_     |
| **Address**       | The cell range that defines where the table will be positioned (e.g., 'A1:C10').| Text | Yes       | _(empty)_     |
| **Has Headers**   | Indicates whether the provided data table includes header information.| Switch    | Yes       | _(empty)_     |

## Expected Output Format

This node does not produce a visible output result but executes an action to modify an Excel worksheet. Upon successful execution, a table is added to the specified worksheet in the Excel file with optional headers, structured per the specified address range.

## Step-by-Step Guide

<Steps>

### Step 1

Add the **Add Table to Worksheet** node to your automation flow.

### Step 2

Enter your **Tenant ID** into the corresponding field. This is part of your Azure AD information.

### Step 3

Fill in the **Client ID** and **Client Secret** fields with your Azure AD application identifiers.

### Step 4

Specify the **Drive ID** for the OneDrive or SharePoint location where your Excel file resides.

### Step 5

Enter the **Item ID**, which identifies the specific Excel file you want to modify.

### Step 6

Type in the **Worksheet Name** to specify which worksheet within the file should contain the table.

### Step 7

Input the **Address** by defining a cell range (e.g., 'A1:C10') where the table will be placed.

### Step 8

Toggle the **Has Headers** switch to indicate whether your data table includes headers.

</Steps>

<Callout type="info" title="Important">
Ensure all fields are correctly filled to avoid connection or data errors when adding a table.
</Callout>

## Input/Output Examples

While there is no direct output to observe, an example input setup might look like:

- **Tenant ID**: `your-tenant-id`
- **Client ID**: `your-client-id`
- **Client Secret**: `your-client-secret`
- **Drive ID**: `your-drive-id`
- **Item ID**: `your-item-id`
- **Worksheet Name**: `SalesData`
- **Address**: `A1:C10`
- **Has Headers**: `true` (switch enabled)

Expected result: A table is added to the 'SalesData' worksheet in the specified Excel file at range A1 to C10.

## Common Mistakes & Troubleshooting

| Problem                                                | Solution                                                                                          |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| **Incorrect Azure credentials**                         | Verify that the Tenant ID, Client ID, and Client Secret are correct and match your Azure AD setup.|
| **File or Drive ID not found**                          | Ensure Drive ID and Item ID correspond exactly to the respective OneDrive or SharePoint entries.  |
| **Table not appearing in Excel**                        | Double-check that the Worksheet Name matches an existing sheet in your Excel file.                |
| **Has Headers not set correctly**                       | Confirm the Has Headers toggle matches the data format you're inputting.                          |
