# Spaces

The **Spaces** page (under Tenant Admin) lets you organize users and resources into spaces. Spaces group related work so you can manage access and resources more easily.

## Purpose

Use spaces to segment your tenant. For example, you might create separate spaces for different teams or projects, each with its own users and resources.

## The table

The page shows a table of spaces with columns such as:

- **Name** — the space's name.
- **Description** — what the space is for.
- **Members** — how many users belong to the space.

## Row actions (the three dots)

Each row has a **⋮** menu with actions such as:

- **Edit** — change the space's name or description.
- **Delete** — remove the space.

## Creating a space

Click the **Create Space** button. Fill in:

- **Name** — a unique, descriptive name.
- **Description** — optional, but recommended.

After creating the space, add members and assign resources to it.
