# Tenants

The **Tenants** page (under Super Admin) lets you view and manage all tenants in the deployment. This is a platform-level view.

## Purpose

Use this page to oversee all tenants, review their plans and usage, and manage them from a central place.

## The table

The page shows a table of tenants with columns such as:

- **Name** — the tenant's name.
- **Plan** — the tenant's subscription plan.
- **Status** — whether the tenant is active.
- **Usage** — the tenant's resource consumption.

## Row actions (the three dots)

Each row has a **⋮** menu with actions such as:

- **View** — open the tenant's details.
- **Edit** — change the tenant's plan or details.
- **Delete** — remove the tenant.

## Tips

- Review tenants regularly to spot inactive or over-consuming accounts.
- Use the filters to narrow the list by plan or date range.
