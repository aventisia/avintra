
The **Library** is a collection of reusable templates and components you can use to start new agents quickly. Templates encapsulate proven patterns so you don't have to build common workflows from scratch.

## Purpose

Instead of building every agent from an empty canvas, browse the Library for a starting point. You can use a template as-is or customize it in the **Agents** editor.

## How to use the Library

1. Browse or search the available templates.
2. Use the category filters (**All templates**, **Automation Agent**, **Chat Agent**, **Block**, **Prompt**) to narrow down the list.
3. Click a template to preview it and see a rendered summary of what it does.
4. Click **Clone this template** to create a new agent based on it.
5. Customize the resulting agent in the **Agents** page, then publish it.

## Tips

- Templates are grouped by purpose; use the search box to filter.
- You can save your own frequently used agents as templates for your team.
