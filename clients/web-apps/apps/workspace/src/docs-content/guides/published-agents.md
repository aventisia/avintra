The **Published Agents** page shows the agents that are live in production. Once you publish an agent from the **Agents** editor, it appears here and can be executed.

## Purpose

This page is the command center for your live agents. From here you can see which agents are published, assign them to machines and share them with users, configure them, and monitor their status.

## The table

The page shows a table of published agents with columns such as:

- **Name** — the agent's name.
- **Type** — whether the agent is an **Automation Agent** or a **Chat Agent**.
- **Machine Count** — the number of machines the agent is assigned to run on.
- **Supported Platform** — where the agent can run.
- **Status** — whether the agent is **Published**, **Deployed**, or **Disabled**.
- **Created By** — who published the agent.
- **Created On** — when the agent was published.

## Row actions (the three dots)

Each row has a **⋮** menu with actions such as:

- **Assign Machine** — choose which machines can run the agent (or **Share** for chat agents).
- **Config** — open the agent's configuration.
- **Enable / Disable** — start or stop the agent.

## Tips

- Ensure at least one machine is online and assigned to the agent before executing it.
- Use the search box to filter the list by agent name.
