
The **Published Agents** page (under Orchestrator) shows the agents that are live in production. Once you publish an agent from the **Agents** editor, it appears here and can be executed.

## Purpose

This page is the command center for your live agents. From here you can see which agents are published, assign them to machines and users, configure them, and monitor their status.

## The table

The page shows a table of published agents with columns such as:

- **Name** — the agent's name.
- **Status** — whether the agent is enabled or disabled.
- **Machines** — which machines the agent is assigned to run on.
- **Users** — which users can access the agent.

## Row actions (the three dots)

Each row has a **⋮** menu with actions such as:

- **Edit** — open the agent's configuration.
- **Assign Machines** — choose which machines can run the agent.
- **Assign Users** — choose which users can access the agent.
- **Disable / Enable** — stop or start the agent.
- **Delete** — remove the published agent.

## Tips

- Ensure at least one machine is online and assigned to the agent before executing it.
- Use the search box to filter the list by agent name.
