# On-prem Tenants

The **On-prem Tenants** page (under Global Admin) lets you view and manage on-premises tenant instances and their data.

## Purpose

Use this page to manage the tenant instances running in on-premises deployments. Open a tenant to view its configuration and underlying data.

## The table

The page shows a table of on-prem tenants with columns such as:

- **Name** — the tenant's name.
- **Status** — whether the tenant instance is active.
- **Instance** — the tenant instance details.

## Row actions (the three dots)

Each row has a **⋮** menu with actions such as:

- **View** — open the tenant instance to see its details and data.
- **Edit** — change the tenant's details.
- **Delete** — remove the tenant.

## Tips

- Open a tenant instance to inspect its configuration and data.
- Monitor tenant status to spot issues.
