# Conversations

The **Conversations** page lets you review the interactions your agents have with end users. Each conversation is a chat session between a user and an agent.

## Purpose

Use this page to monitor and review how your agents interact with users. See what users asked, how agents responded, and identify any issues or improvements.

## The table

The page shows a table of conversations with columns such as:

- **User** — the user who had the conversation.
- **Agent** — which agent was involved.
- **Last Message** — a preview of the most recent message.
- **Timestamp** — when the conversation last had activity.

## Row actions

Click a conversation to open its full transcript. From the details you can review the messages exchanged between the user and the agent.

## Tips

- Review conversations regularly to spot agent quality issues.
- Use the search box to filter conversations by user or agent.
