Welcome to your new tenant! This **Get Started** guide walks you through the five steps to set up your workspace and build your first agent. Follow them in order.

> **Tip:** A tenant admin sees this checklist each time they sign in until they mark it complete or choose **Don't show again**; **Remind me later** hides it for a week. Reopen it any time by searching **Get started** (**Ctrl K** or **⌘K**).

## Step 1 — Invite users

The only way for someone to join your tenant is for you (the Tenant Admin) to invite them. There is no self-sign-up for tenant members.

- Go to **Tenant Admin → Users**.
- Click the **Invite** button, enter the person's name and email, and assign a role.
- Invited users appear in the users table and receive access based on their role.

→ See the [Users guide](#) for full details.

## Step 2 — Define Spaces

Spaces let you organize users and resources into logical groups (for example, by team or project). Define spaces to match how you want to segment your work.

- Go to **Tenant Admin → Spaces**.
- Click **Create Space**, give it a name and optional description, then add members and assign resources.

> **Note:** Use the **ⓘ** information button on each page to learn what that feature is for and how to set it up.

→ See the [Spaces guide](#) for full details.

## Step 3 — Save your credentials in the Vault

Store the credentials for the applications you want to use in the **Vault**. Secrets are encrypted at rest and access is audited.

- Go to **Configure → Vault**.
- Click **Add Credential**, enter a unique name, username, and password, plus an optional description.
- Reference these credentials from your agents when they connect to external systems.

→ See the [Vault guide](#) for full details.

## Step 4 — Enable Models

Connect and enable the AI models your agents will use.

- Go to **Tenant Admin → Models**.
- On each provider card, click **Setup**, follow the steps to connect the provider, set its API key, and enable the models you want.
- Ensure at least one model provider is configured and active before you build an agent.

→ See the [Models guide](#) for full details.

## Step 5 — Create your first agent in Build

Once users, spaces, credentials, and models are ready, you can build your first agent.

- Go to **Build → Agents**.
- Click **Create Agent**, give it a name, choose a type (**Automation Agent** or **Chat Agent**), and add an optional description.
- Open the agent to build out its workflow by chaining nodes, then test and publish it.

→ See the [Agents guide](#) for full details.

## You're all set

That's it — you've completed the core setup. You can now invite more users, extend your spaces, add more credentials and models, and continue building agents.
