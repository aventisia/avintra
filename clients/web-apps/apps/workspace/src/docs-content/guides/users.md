The **Users** page lets you invite, manage, and remove users, and assign roles and permissions.

## Purpose

Use this page to control who has access to your tenant and what they can do. Assign roles to grant the right level of access to each user.

## The table

The page shows a table of users with columns such as:

- **First Name** — the user's first name.
- **Last Name** — the user's last name.
- **Email** — the user's email address.
- **Role** — the user's role and permissions.
- **Spaces** — which spaces the user belongs to.
- **Created On** — when the user was added.

## Row actions (the three dots)

Each row has a **⋮** menu with actions such as:

- **View** — see the user's details.
- **Edit** — change the user's role or details.
- **Delete** — remove the user.

## Inviting a user

Click the **Invite** button. Fill in:

- **Name** — the user's name.
- **Email** — the user's email address.
- **Role** — the role to assign (determines permissions).

## Tips

- Assign the least-privilege role that still lets the user do their job.
- Disable rather than delete users who are temporarily away.
