The **Queues** page shows all the Queues you have access to and the work items in those queues. Process each item, view its details and timeline, and complete or escalate it as needed.

## Purpose

This page is where you handle the work that has been routed to you. Each item represents a task that needs your attention.

## The layout

The page opens with an overview of your queues shown as cards. Select a queue to open its work items.

The work items are shown in a table. Use the **Current** and **History** tabs to switch between active items and items that have been completed, failed, or closed.

## How to use it

1. Select a queue from the overview.
2. Open a work item to see its details and timeline.
3. Process the item (e.g. review, respond, or complete it).
4. Escalate or reassign items that need someone else's attention.

## Tips

- Work through items in priority order.
- Use the timeline to understand the item's history.
- Use the **History** tab to review items that have already been processed.
