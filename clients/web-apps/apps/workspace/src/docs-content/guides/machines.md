
The **Machines** page lets you monitor the machines (runners) that execute your agents. A machine is a computer running the Avintra runner that picks up and executes jobs.

## Purpose

Machines are the compute that runs your automations. This page lets you see the machines registered with the platform, monitor their health, and assign them to agents so your jobs have somewhere to run.

## How machines are registered

Machines are **not created manually on this page**. A machine registers itself automatically when you install and run the Avintra runner app on a computer. Once the runner connects, the machine appears here.

## The table

The page shows a table of machines with columns such as:

- **Name** — the machine's name.
- **Status** — whether the machine is online or offline.
- **Flow Version Count** — the number of agent versions assigned to this machine.
- **Last Checked In** — when the machine last reported in.

## Row actions (the three dots)

Each row has a **⋮** menu with actions such as:

- **View** — open the machine details.
- **Edit** — update the machine's name or details.
- **Delete** — remove the machine from the platform.

## Tips

- Keep machines healthy and online to avoid execution failures.
- Monitor the **Status** column to spot offline machines.
- Install and run the Avintra runner on a computer to add a new machine.
