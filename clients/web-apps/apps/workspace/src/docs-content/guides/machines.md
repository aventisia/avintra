
The **Machines** page lets you register and monitor the machines (runners) that execute your agents. A machine is a computer running the Avintra runner that picks up and executes jobs.

## Purpose

Machines are the compute that runs your automations. Register machines here, monitor their health, and assign them to agents so your jobs have somewhere to run.

## The table

The page shows a table of machines with columns such as:

- **Name** — the machine's name.
- **Status** — whether the machine is online or offline.
- **OS** — the operating system the machine runs.
- **Last Seen** — when the machine last reported in.

## Row actions (the three dots)

Each row has a **⋮** menu with actions such as:

- **Edit** — change the machine's name or details.
- **Delete** — remove the machine.

## Creating a machine

Click the **Create Machine** button. Fill in:

- **Name** — a unique, descriptive name.
- **OS** — the operating system of the machine.

After creating the machine, install and run the Avintra runner on it so it can execute jobs. Then assign it to agents from the **Published Agents** page.

## Tips

- Keep machines healthy and online to avoid execution failures.
- Monitor the **Status** column to spot offline machines.
