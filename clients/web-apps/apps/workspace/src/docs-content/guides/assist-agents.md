The **Agents** page lists the agents you can execute as an end user. 

## Purpose

This is the everyday user's entry point to the platform. From here you can see the agents available to you and exceute them whenever required.

## The table

The page shows a list of agents with columns such as:

- **Name** — the agent's name.
- **Description** — what the agent does.

## How to use it

1. Find the agent you want to work with.
2. Click on the **Green play** button to execute the agent
