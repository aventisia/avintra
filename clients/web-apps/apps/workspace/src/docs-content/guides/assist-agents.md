
The **Agents** page under **Assist** lists the agents you can interact with as an end user. Open one to start a conversation or run it directly.

## Purpose

This is the everyday user's entry point to the platform. From here you can see the agents available to you and start working with them.

## The table

The page shows a list of agents with columns such as:

- **Name** — the agent's name.
- **Description** — what the agent does.

## How to use it

1. Find the agent you want to work with.
2. Click it to start a chat or run it.
3. Track your open work in **Assist → Queues**.
4. Review past interactions in **Assist → Chats**.
