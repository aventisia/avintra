The **Agents** page lists the agents you can execute as an end user.

## Purpose

This is the everyday user's entry point to the platform. From here you can see the agents available to you and execute them whenever required.

## The list

Agents are shown as **list items** (not a table). Each item shows:

- **Name** — the agent's name.
- **Version** — the agent's version number.

## How to use it

1. Find the agent you want to work with.
2. Click the **Execute** button to run the agent.
