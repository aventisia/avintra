The **Time Triggers** page lets you create and manage triggers that run an agent automatically on a schedule.

## Purpose

A time trigger starts the configured agent at regular intervals (e.g. every day at a specific time) or on a recurring schedule. Use it when you want an agent to run on a timed cadence.

## The layout

The page has **Personal** and **Shared** tabs. Your own triggers appear under **Personal**; triggers shared with you appear under **Shared**. The **Create** button is only available on the **Personal** tab.

## The table

The page shows a table of time triggers with columns such as:

- **Name** — the trigger's name.
- **Frequency** — how often the trigger runs.
- **Last Triggered Time** — when the trigger last ran.
- **Next Trigger Time** — when the trigger will run next.
- **Agents** — which agents the trigger starts.
- **Timezone** — the timezone the schedule uses.
- **Effective Date** — when the trigger begins.
- **Created By / Created On** — who created the trigger and when.

## Row actions (the three dots)

Each row has a **⋮** menu with actions such as:

- **View** — see the trigger's details.
- **Edit** — change the trigger's schedule.
- **Share** — manage who can access the trigger.
- **Delete** — remove the trigger.

## Creating a time trigger

Click the **Create** button. Fill in:

- **Unique Name** — *Required.* A unique name for the trigger.
- **Frequency** — *Required.* How frequently the trigger runs or repeats.
- **Effective Date & Time** — *Required.* When the trigger will begin.
- **Ends on** — *Optional.* When the trigger should stop.
- **Exception Hours** — *Optional.* Specific hours to skip.
- **Exception Weekdays** — *Optional.* Weekdays to skip (e.g. weekends).

After creating, the trigger runs the configured agent on the schedule.
