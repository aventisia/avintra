# Update Work Item

The **Update Work Item** node enables you to modify the fields or status of an existing work item. This is especially useful when you need to change the state of a task within a workflow or update its associated data with new information.

This feature can be used for:

- Changing the status of a work item, like marking it as "Completed".
- Adding notes or remarks to record contextual information.
- Updating data associated with a work item, like modifying its payload in JSON format.

## Configuration Options

| Field Name               | Description                                                                                    | Input Type  | Required? | Default Value |
| ------------------------ | ---------------------------------------------------------------------------------------------- | ----------- | --------- | ------------- |
| **WorkItem ID**          | Enter the unique identifier of the work item you want to update.                               | Text        | Yes       | _(empty)_     |
| **Status**               | Select the new status to assign to the work item.                                              | Select      | No        | Pending       |
| **Remark**               | Enter the remark for the work item.                                                            | Text        | No        | _(empty)_     |
| **Update WorkItem Data** | Enable this option if you also want to update the data payload of the work item.               | Switch      | No        | False         |
| **Work Item Data**       | Provide the updated work item data in JSON format (only if 'Update WorkItem Data' is enabled). | JSON Editor | Yes       | _(empty)_     |

## Expected Output Format

The output is an **Updated WorkItem** object that reflects the changes made to the work item, such as status updates, remarks, or data payload adjustments.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Update Work Item** node into your flow.

### Step 2

In the **WorkItem ID** field, enter the unique ID for the work item you want to modify.

### Step 3

Choose the new status for the work item from the **Status** dropdown menu. Options include:

- **Pending**: Work item is not yet started.
- **In Progress**: Work item is being processed.
- **Completed**: Work item has been successfully completed.
- **Failed**: Processing of the work item failed.

### Step 4

(Optional) Enter any relevant remarks in the **Remark** field to provide additional context or notes.

### Step 5

(Optional) To update the work item's data payload, toggle **Update WorkItem Data** on.

### Step 6

If you enabled **Update WorkItem Data**, enter the updated JSON data into the **Work Item Data** field.

### Step 7

The updated state of the work item will be available as **UpdatedWorkItem** for subsequent nodes in your workflow.

</Steps>

<Callout type="info" title="Note">
  If you do not enable "Update WorkItem Data", the "Work Item Data" field will
  not appear. Ensure the JSON data provided in the "Work Item Data" field is
  properly formatted.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                            | Solution                                                                                                   |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Missing Work Item ID**           | Ensure you enter a valid `WorkItem ID` as it is required to identify the work item you wish to update.     |
| **Invalid JSON in Work Item Data** | Double-check your JSON syntax in **Work Item Data**; malformed JSON will prevent the update from applying. |
| **Work Item Data not visible**     | Make sure **Update WorkItem Data** is enabled, as this field only appears when data updates are desired.   |
| **Status not changing**            | Recheck if you have selected the desired status from the dropdown under **Status**.                        |

## Real-World Use Cases

- **Task Management**: Update tasks in a project management system to reflect their current status, such as marking "In Progress" to "Completed".
- **Customer Support Tickets**: Modify the status of a customer ticket to "Resolved" once the issue has been addressed.
- **Inventory Systems**: Adjust inventory items' data payloads to reflect changes in quantity or attributes dynamically.
