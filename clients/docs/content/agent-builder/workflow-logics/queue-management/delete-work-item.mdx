# Delete Work Item

The **Delete Work Item** node is used to permanently remove a specific work item from a queue. This functionality is crucial when you want to maintain an accurate and up-to-date queue by removing items that are no longer needed. This can help in ensuring that the system is processing only active and relevant tasks.

## Configuration Options

| Field Name          | Description                                                                  | Input Type | Required? | Default Value   |
| ------------------- | ---------------------------------------------------------------------------- | ---------- | --------- | --------------- |
| **WorkItem ID**     | Enter the unique identifier of the work item you want to permanently delete. | Text       | Yes       | _(empty)_       |
| **WorkItemDeleted** | Returns true if the work item was successfully deleted.                      | Output     | No        | WorkItemDeleted |

## Expected Output Format

The output of this node is a **boolean value** (true/false).

- If the work item is deleted successfully: the output will be `true`.
- If there is an error or the ID is incorrect, the task completion status will not be `true`.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Delete Work Item** node into your flow.

### Step 2

In the **WorkItem ID** field, enter the ID of the work item you wish to delete. Ensure this ID is correct as it identifies the specific item in the queue.

### Step 3

Execute the flow to perform the deletion.

### Step 4

Check the output value of **WorkItemDeleted** to confirm the deletion was successful. The output will be `true` if the work item has been deleted.

</Steps>

<Callout type="warning" title="Caution">
  Deleting a work item is permanent and cannot be undone. Make sure you have
  backup or confirmation before proceeding.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                     | Solution                                                                                               |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Incorrect WorkItem ID entered**           | Double-check the ID for typos. Ensure the ID corresponds to an existing item in the queue.             |
| **Deletion not reflected in output**        | Verify connection to the queue and ensure the node is correctly set up in the flow.                    |
| **Unexpected errors during flow execution** | Review error logs for details and ensure system permissions and connections are suitable for deletion. |

## Real-World Use Cases

- **Cleaning Unwanted Tasks**: Regularly clean the queue by deleting obsolete or duplicate work items.
- **Data Consistency**: Ensure only relevant tasks are processed by removing items with errors.
- **Queue Management**: Manage workload efficiently by removing completed or cancelled tasks from the queue.
