# Send Email Through SendGrid

The **Send Email Through SendGrid** node allows you to send email messages using the SendGrid service. This node is useful when you want to automate email communications within your processes, whether for notifications, newsletters, autoresponders, or other email activities.

You can define sender and recipient details, compose your subject and body, and even include attachments. The node uses your SendGrid API credentials to authenticate and send emails securely.

## Configuration Options

| Field Name              | Description                                                                    | Input Type         | Required? | Default Value |
| ----------------------- | ------------------------------------------------------------------------------ | ------------------ | --------- | ------------- |
| **SendGrid Credential** | The SendGrid credential containing a valid API key for authentication.         | Credentials Select | Yes       | _(empty)_     |
| **From**                | The sender's email address.                                                    | Text               | Yes       | _(empty)_     |
| **To**                  | The recipient's email address(es), separated by commas for multiple addresses. | Text               | Yes       | _(empty)_     |
| **CC**                  | The email addresses to send carbon copies, comma-separated.                    | Text               | No        | _(empty)_     |
| **BCC**                 | The email addresses to send blind carbon copies, comma-separated.              | Text               | No        | _(empty)_     |
| **Subject**             | The subject line of the email.                                                 | Text               | Yes       | _(empty)_     |
| **Body**                | The main content of the email message.                                         | Text               | Yes       | _(empty)_     |
| **Body Format**         | Choose between plain text or HTML format for the body content.                 | Select             | Yes       | Text          |
| **Attachments**         | Paths to any files to be sent as attachments, separated by commas.             | Text               | No        | _(empty)_     |

## Expected Output Format

The output from this node is the **Result** which includes the response data from SendGrid, confirming that your email has been processed.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Send Email Through SendGrid** node into your flow.

### Step 2

Select your **SendGrid Credential** from the credential list. Ensure this contains a valid API key for email dispatch.

### Step 3

Enter the **From** email address. This will be the sender address appearing in the email.

### Step 4

Add recipient addresses in the **To** field. Use commas to separate multiple addresses if needed.

### Step 5

(Optional) Enter email addresses in **CC** and **BCC** to send copies of the email to additional recipients.

### Step 6

Fill in the **Subject** field with your email's subject line.

### Step 7

Compose the main body of the email in the **Body** field. Choose **Body Format** to either Plain or HTML.

### Step 8

(Optional) If you wish to include files, list their paths in **Attachments**.

### Step 9

The result after sending will be accessible as **Result**, showing SendGrid's response data.

</Steps>

<Callout type="warning" title="Important">
  Ensure that all email addresses are correctly formatted and valid to avoid
  email delivery errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                              | Solution                                                                                        |
| ------------------------------------ | ----------------------------------------------------------------------------------------------- |
| **Missing SendGrid Credential**      | Ensure you've selected a valid credential with your SendGrid API key.                           |
| **Invalid recipient address format** | Double-check all email addresses for correct syntax.                                            |
| **Email not sent**                   | Verify API key validity and check any error messages in the SendGrid response for more details. |
