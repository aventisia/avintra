# Download Attachments

The **Download Attachments** node enables you to automatically download all attachments from a specific email message using the Microsoft Graph API. This is particularly useful for organizing and saving relevant email data without manually handling each attachment.

You might use this node to:

- Retrieve important documents sent via email.
- Automate the organization of downloadable content from business correspondence.
- Streamline processes that require attachment retrieval for record-keeping or further analysis.

## Configuration Options

| Field Name        | Description                                                     | Input Type | Required? | Default Value |
| ----------------- | --------------------------------------------------------------- | ---------- | --------- | ------------- |
| **User Email**    | The email address of the mailbox owner.                         | Text       | Yes       | _(empty)_     |
| **Tenant ID**     | The Azure Active Directory tenant (directory) ID.               | Text       | Yes       | _(empty)_     |
| **Client ID**     | The Azure AD application (client) ID.                           | Text       | Yes       | _(empty)_     |
| **Client Secret** | The Azure AD application client secret.                         | Text       | Yes       | _(empty)_     |
| **Message ID**    | The ID of the email message from which to download attachments. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **JSON object** containing the list of attachments. This format facilitates easy processing and integration with other systems or nodes.

- Output Field: **Attachments JSON**
- Output Value: A list of attachments in JSON format (e.g., `{"attachment1": "file.pdf", "attachment2": "image.jpg"}`).

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Download Attachments** node to your flow.

### Step 2

In the **User Email** field, enter the email address associated with the mailbox from which you want to download attachments.

### Step 3

Enter your **Tenant ID** in the corresponding field. This ID is specific to your Azure Active Directory.

### Step 4

Provide the **Client ID** linked to your Azure AD application.

### Step 5

Input the **Client Secret** to authenticate your application with Azure AD.

### Step 6

Enter the **Message ID** of the email whose attachments you wish to download.

### Step 7

Once the node executes, the attachments will be listed in the **Attachments JSON** output field for further use.

</Steps>

<Callout type="info" title="Note">
  Ensure that all IDs and secrets are correctly entered to enable proper
  authentication and downloading of attachments.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                         | Solution                                                                                                   |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Incorrect Tenant ID/Client ID/Client Secret** | Double-check all Azure credentials for accuracy. Incorrect details will prevent successful authentication. |
| **Invalid or Empty Message ID**                 | Verify that the Message ID is correct and corresponds to an existing email with attachments.               |
| **No Attachments Found in Output**              | Confirm that the specified email contains attachments and that the correct Message ID is provided.         |
