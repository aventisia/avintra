# Move Email To Folder

The **Move Email To Folder** node facilitates the organization of your emails by moving an email message to a specified folder in your mailbox using the Microsoft Graph API. It's particularly useful for managing large volumes of emails effectively and ensuring important messages are properly categorized and stored.

For example:

- Move an email to a "Project Updates" folder for better project organization.
- Sort incoming emails into specific folders based on workflow requirements.
- Relocate outdated emails to an archive folder for decluttered inbox management.

## Configuration Options

| Field Name        | Description                                         | Input Type | Required? | Default Value |
| ----------------- | --------------------------------------------------- | ---------- | --------- | ------------- |
| **User Email**    | The email address of the mailbox owner.             | Text       | Yes       | _(empty)_     |
| **Message ID**    | The ID of the email message to move.                | Text       | Yes       | _(empty)_     |
| **Folder ID**     | The destination folder ID to move the message into. | Text       | Yes       | _(empty)_     |
| **Tenant ID**     | Azure Active Directory tenant (directory) ID.       | Text       | Yes       | _(empty)_     |
| **Client ID**     | Azure AD application (client) ID.                   | Text       | Yes       | _(empty)_     |
| **Client Secret** | Azure AD application client secret.                 | Text       | Yes       | _(empty)_     |

## Expected Output Format

This node does not produce an output directly in the flow. Once successfully configured and executed, it will move the specified email to the desired folder. This change is reflected in your email system (e.g., Outlook).

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Move Email To Folder** node to your workflow.

### Step 2

In the **User Email** field, enter the email address of the account where the email is stored.

### Step 3

Provide the **Message ID** of the email you want to move. This is typically available from your email system's interface.

### Step 4

Enter the **Folder ID** of the target folder. If you're unsure of the Folder ID, refer to your email system's folder settings or documentation.

### Step 5

Fill in the following Azure Active Directory details required for authentication:

- **Tenant ID**
- **Client ID**
- **Client Secret**

### Step 6

Verify that all required fields are correctly filled, then execute the workflow to move the email to the specified folder.

</Steps>

<Callout type="warning" title="Warning">
  Be cautious while entering authentication details such as **Tenant ID**,
  **Client ID**, and **Client Secret**. Ensure they are correct to avoid
  authentication issues.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                        | Solution                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------ |
| **Invalid Email or Folder ID** | Ensure you're using the correct IDs as referenced from your email system.                        |
| **Authentication Failure**     | Double-check the **Tenant ID**, **Client ID**, and **Client Secret** are correct and up to date. |
| **Empty Required Fields**      | All fields marked as required must be filled before the node can execute properly.               |

## Real-World Use Cases

- **Customer Support**: Automatically move emails from customers to a dedicated support folder.
- **Project Management**: Organize project-related emails into specific project folders for easy access.
- **Email Cleanup**: Automatically archive older emails to clear up the main inbox and enhance performance.
