# Process Exchange Email Messages

The **Process Exchange Email Messages** node allows you to efficiently manage your email messages on an Exchange server. With it, you can move, delete, or mark one or multiple emails as unread, making it easier to keep your mailbox organized. This node is especially helpful for sorting through large volumes of emails or automating routine email tasks.

## Configuration Options

| Field Name                      | Description                                                                              | Input Type | Required? | Default Value |
| ------------------------------- | ---------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Exchange Connection**         | The Exchange service object representing the connection to the Exchange server.          | Text       | Yes       | _(empty)_     |
| **Operation**                   | The action to perform (e.g., Move, Delete, MarkAsUnread).                                | Select     | Yes       | _(empty)_     |
| **Email Message(s) to Process** | The IDs of the email messages to process.                                                | Text       | Yes       | _(empty)_     |
| **Mailbox Type**                | Specifies whether the mailbox is personal or shared.                                     | Select     | No        | _(empty)_     |
| **Shared Mailbox Address**      | The email address of the shared mailbox (required if 'Mailbox Type' is 'Shared').        | Text       | No        | _(empty)_     |
| **Move to Custom Folder**       | If true, moves emails to a custom folder instead of predefined folders.                  | Switch     | No        | _(empty)_     |
| **Exchange Folder**             | The folder to move emails to (if not using a custom folder).                             | Select     | No        | _(empty)_     |
| **Custom Folder Name**          | The name of the custom folder to move emails to (if 'Move to Custom Folder' is enabled). | Text       | No        | _(empty)_     |

## Expected Output Format

The node does not produce an output in traditional sense. The output is the updated status of the email messages as per the operation executed (i.e., emails moved, deleted, or marked as unread) on the Exchange server.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Process Exchange Email Messages** node into your workflow.

### Step 2

In the **Exchange Connection** field, provide the connection string or object that links to your Exchange server.

### Step 3

In the **Operation** dropdown, select the action you would like to perform on the email messages:

- **Delete**: Deletes email messages from the server.
- **Mark as Unread**: Marks the selected email messages as unread.
- **Move to Mail Folder**: Moves messages to a specified mail folder.

### Step 4

Specify the IDs of the email messages you intend to process in **Email Message(s) to Process**.

### Step 5

If you are processing messages from a shared mailbox, select **Shared** under **Mailbox Type** and enter the email address in **Shared Mailbox Address**.

### Step 6

To move emails to a custom folder, toggle **Move to Custom Folder** to 'true' and provide the name of the custom folder in **Custom Folder Name**. If not, select a folder from the **Exchange Folder** dropdown.

</Steps>

<Callout type="info" title="Note">
  If you choose to move messages to a custom folder, ensure that **Exchange
  Folder** is left empty and focus on setting **Custom Folder Name** instead.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                          | Solution                                                                                                                                                  |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Exchange Connection not working**              | Double-check the connection settings and ensure the server is reachable and the credentials are correct.                                                  |
| **Unable to find Shared Mailbox Address**        | Confirm that the email entered is correct and that you have access privileges to this shared mailbox.                                                     |
| **Fields not appearing according to selections** | Ensure the dependencies, such as activating **Move to Custom Folder** to display **Custom Folder Name**, are met before expecting other fields to appear. |
| **Emails not moving to the right folder**        | Check both folder names (custom or selected) for typos or ensure the folder exists in the Exchange server.                                                |

## Real-World Use Cases

- **Email Management**: Automatically delete promotional emails or spam without manually checking every time.
- **Priority Inbox Setup**: Mark specific emails from clients or VIPs as unread to ensure they are not missed in the daily hustle.
- **Project Organization**: Move project-related emails to their designated folders daily to keep your inbox clean.
