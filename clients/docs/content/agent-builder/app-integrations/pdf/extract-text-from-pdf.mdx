# Extract Text from PDF

The **Extract Text from PDF** node is designed to help you easily pull text or images from a PDF file. This is particularly useful when you need to process information from documents, repurpose content, or analyze data within PDFs in your workflows.

For example:

- Extracting all text for use in a content analysis tool.
- Pulling out images for graphical reports or presentation materials.
- Selecting specific pages or sections to target detailed reviews.

## Configuration Options

| Field Name                       | Description                                                                                                       | Input Type | Required? | Default Value |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **PDF File**                     | The path to the source PDF file. Use this to specify which file's contents you want to extract.                   | Text       | Yes       | _(empty)_     |
| **Page Selection Mode**          | Determine which pages to extract from: all, a single page, or a range of pages.                                   | Select     | Yes       | All           |
| **Extraction Type**              | Decide if you want to extract text, images, or both from the PDF.                                                 | Select     | Yes       | Text          |
| **Page Number (for Single)**     | Specify the exact page number to extract when choosing a single page. Applies only if Page Selection is "Single". | Text       | No        | _(empty)_     |
| **From Page Number (for Range)** | Indicate the starting page number when extracting a range. Only used if Page Selection is "Range".                | Text       | No        | _(empty)_     |
| **To Page Number (for Range)**   | Identify the end page number for your page range extraction. Only used if Page Selection is "Range".              | Text       | No        | _(empty)_     |
| **Password**                     | If the PDF is password-protected, enter the password here. Leave empty if not needed.                             | Password   | No        | _(empty)_     |
| **Output Folder Path**           | Destination folder path for saved images. Only visible if the extraction includes images.                         | Text       | No        | _(empty)_     |

## Expected Output Format

The output from this node is either extracted text or text plus images, depending on your Extraction Type setting. For text extraction, the result is a **string** of text from the PDF. If images or both text and images are extracted, images are stored in the designated output folder.

Output Value: **ExtractedText**

## Step-by-Step Guide

<Steps>
### Step 1

Add **Extract Text from PDF** node into your workflow.

### Step 2

Enter the path to your PDF file in the **PDF File** field.

### Step 3

In the **Page Selection Mode** dropdown, choose:

- **All** to extract from every page.
- **Single** if you want to extract from one specific page only.
- **Range** to specify a range of pages.

### Step 4

Select the **Extraction Type**:

- **Text** for text only.
- **Images** for images only.
- **Both** for both text and images.

### Step 5

If you chose **Single** in Page Selection, fill in **Page Number (for Single)** with the exact page number. If you selected **Range**, complete **From Page Number** and **To Page Number** fields.

### Step 6

If your PDF is protected, enter the password in the **Password** field.

### Step 7

Make sure to specify the **Output Folder Path** if extracting images or both text and images.

### Step 8

The extracted content will be available under **ExtractedText** for further use in your workflow.

</Steps>

<Callout type="info" title="Tip">
  Ensure your PDF path is accurate, and folders specified for outputs are
  accessible to avoid errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                   | Solution                                                                                            |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Incorrect file path**                   | Verify that the PDF path you entered is correct and accessible.                                     |
| **Missing output images**                 | Ensure you've specified an output folder path and have extraction set to **Images** or **Both**.    |
| **Password-protected PDF not processing** | Double-check if a password is needed and has been accurately entered in the **Password** field.     |
| **No text extracted**                     | Confirm the PDF contains selectable text. Some PDFs are just images/scans without text recognition. |

## Real-World Use Cases

- **Competitor Analysis**: Extract text from competitors' reports to analyze market trends.
- **Data Entry Automation**: Quickly input information by extracting key data from standardized paper forms.
- **Graphic Designing**: Extract images for inclusion in broader graphic projects with existing visual material.
