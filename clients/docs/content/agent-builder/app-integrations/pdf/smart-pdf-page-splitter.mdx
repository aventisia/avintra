# Smart PDF Page Splitter

The **Smart PDF Page Splitter** node allows you to divide a PDF file into separate pages based on your chosen settings. You can split the PDF by all pages, odd pages, even pages, specific ranges, or into chunks of a predefined page size. This is perfect for organizing large documents or extracting specific content for easier management and distribution.

## Configuration Options

| Field Name           | Description                                                                                  | Input Type | Required? | Default Value |
| -------------------- | -------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **PDF File Path**    | Full path to the source PDF file that you wish to split (e.g., C:\docs\input.pdf).           | Text       | Yes       | _(empty)_     |
| **Output Directory** | Directory where the split pages will be saved (e.g., C:\output).                             | Text       | Yes       | _(empty)_     |
| **Selection Mode**   | Method for page selection: All, Odd, Even, Range, Specific Pages, or By Specified Page Size. | Select     | Yes       | All           |
| **Page Range**       | Specific pages if using 'Custom Range' mode (e.g., '1-3,5,7-9'). Ignored for other modes.    | Text       | No        | _(empty)_     |
| **Specific Pages**   | Pages to include in 'Specific Pages' mode (e.g., '10,20,30'). Ignored for other modes.       | Text       | No        | _(empty)_     |
| **Pages Per File**   | Number of pages per output file for 'By Pages Per File' or 'Specific Pages' mode.            | Text       | No        | _(empty)_     |
| **Page Prefix**      | Prefix to use for output filenames (e.g., 'page\_').                                         | Text       | No        | page\_        |

## Expected Output Format

The node produces a folder containing the split PDF files and returns two key pieces of information:

- **Saved Folder Path**: Path to the directory where split pages have been saved.
- **Page Count**: Total number of pages successfully split, excluding any padded blanks.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Smart PDF Page Splitter** node into your flow.

### Step 2

In the **PDF File Path** field, enter the full path to the PDF you want to split.

### Step 3

Provide the **Output Directory** where you want your split PDFs to be saved.

### Step 4

Select your preferred **Selection Mode** from the dropdown:

- **All Pages**: Splits every page into a separate file.
- **Odd Pages**: Splits only the odd-numbered pages.
- **Even Pages**: Splits only the even-numbered pages.
- **Custom Range**: Splits based on specified page ranges.
- **Specific Pages**: Choose specific pages to include.
- **Split Pages Per File**: Splits into sets of a specified number of pages per file.

### Step 5

If you chose a mode that requires detailed specifications, fill in the additional fields that appear:

- **Page Range** for 'Custom Range'.
- **Specific Pages** for 'Specific Pages'.
- **Pages Per File** for 'Split Pages Per File'.

### Step 6

Optionally, enter a **Page Prefix** to start each output file name.

### Step 7

The processed split PDFs will be saved in the specified output directory, and you will see feedback on the total pages split and where they are saved.

</Steps>

<Callout type="warning" title="Note">
  Make sure the PDF file path and output directory provided are accessible and
  have the necessary file permissions.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                | Solution                                                                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Invalid PDF File Path**              | Double-check the file path for typos, and ensure the file exists and is accessible.                                      |
| **Output Directory Not Writable**      | Ensure you have write permissions to the output directory or choose a different directory.                               |
| **Mode-Specific Fields Not Appearing** | Verify that you've selected a mode that requires additional parameters; appropriate fields will only show when needed.   |
| **Unexpected Page Counts**             | Confirm the **Selection Mode** and any additional settings are correct (e.g., Page Range format in 'Custom Range' mode). |
