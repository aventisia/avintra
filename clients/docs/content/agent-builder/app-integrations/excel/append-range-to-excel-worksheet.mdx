# Append Range to Excel Worksheet

The **Append Range to Excel Worksheet** node lets you add a range of data from a source, such as a DataTable, to an Excel worksheet. This is particularly useful when working with spreadsheets where you need to continuously update data without manually adjusting Excel files.

For example, you can use this node to:

- Append new sales data to an existing sales report worksheet.
- Add log data to a monitoring worksheet dynamically.
- Update performance metrics by appending new results to an existing worksheet.

## Configuration Options

| Field Name                | Description                                                                                        | Input Type | Required? | Default Value |
| ------------------------- | -------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Worksheet Instance**    | The Excel Worksheet where data will be appended. Defaults to the active worksheet if not set.      | Text       | Yes       | _(empty)_     |
| **Data Table**            | The DataTable containing the data that needs to be appended.                                       | Text       | Yes       | _(empty)_     |
| **Append Mode**           | Choose how to append the data: either to named cells or the active sheet.                          | Select     | No        | ToActiveSheet |
| **Name**                  | The name of the named range for data appending. Only required when "AppendMode" is "ToNamedCells". | Text       | No        | _(empty)_     |
| **First Row Has Headers** | Specifies if the first row of the DataTable contains headers, which should be skipped.             | Switch     | No        | _(empty)_     |
| **Starting Column**       | The column letter indicating where appending should begin (for active sheet appending only).       | Text       | No        | _(empty)_     |

## Expected Output Format

The output of this node is simply an action result indicating the successful appending of data to the specified Excel worksheet. There is no numerical or text-based output to handle.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Append Range to Excel Worksheet** node into your flow.

### Step 2

In the **Worksheet Instance** field, specify the Excel worksheet you're working with. If omitted, it defaults to the active worksheet.

### Step 3

Enter the **Data Table** that contains the data you want to append.

### Step 4

Select the **Append Mode** from the dropdown:

- **To Named Cells**: Assign data to a named range.
- **To Active Sheet**: Append data to the active worksheet.

### Step 5

If **Append Mode** is set to **To Named Cells**, specify the **Name** of the range where the data should go.

### Step 6

If your data table includes column headers, toggle the **First Row Has Headers** switch to indicate this.

### Step 7

For appending to the active sheet, specify the **Starting Column** letter where data appending should begin.

### Step 8

Once configured, execute the node to append data seamlessly to your Excel Worksheet.

</Steps>

<Callout type="info" title="Note">
  Ensure the Excel application is open and the specified worksheet or range
  exists to avoid errors.
</Callout>

## Input/Output Examples

| Field                 | Example Value                       | Comments                                      |
| --------------------- | ----------------------------------- | --------------------------------------------- |
| Worksheet Instance    | sales_report.xlsx                   | Use a valid Excel file name.                  |
| Data Table            | `{"salesData": [{"Product":... }]}` | Must be structured table data.                |
| Append Mode           | ToActiveSheet                       | Defaults to active sheet appending.           |
| Name                  | MonthlySalesData                    | Use with **AppendMode: To Named Cells**.      |
| First Row Has Headers | true                                | Select if using headers in data table.        |
| Starting Column       | A                                   | Specify the starting column for active sheet. |

## Common Mistakes & Troubleshooting

| Problem                                     | Solution                                                                                                  |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Appended data not visible**               | Ensure the worksheet is active or named ranges exist. Also, check the append starting point and validate. |
| **Error due to missing Worksheet Instance** | Ensure there is an active Excel worksheet open or provide the worksheet instance name.                    |
| **Incorrect data format**                   | Double-check the data table format to ensure it matches the worksheet's expected structure.               |

## Real-World Use Cases

- **Sales Reporting**: Automatically append daily sales data to a master sales tracking worksheet.
- **Data Aggregation**: Gather data logs from multiple sources and append them to a central analysis workbook.
- **Budget Management**: Append monthly expenditure reports to an existing financial spreadsheet for tracking year-long expenses.
