# Close Excel Application

The **Close Excel Application** node closes the Excel instance that your flow launched. This is particularly useful when you want to ensure the flow's Excel files are properly closed, including handling unsaved changes. This node can be configured to save changes or discard them before closing, providing flexibility based on your requirements.

Only the instance the flow launched is closed. An Excel you opened yourself stays open with its workbooks and any unsaved changes.

For example:

- Automatically close an Excel file after processing data.
- Ensure changes are saved or not saved depending on the situation.

## Configuration Options

| Field Name               | Description                                                                                                           | Input Type | Required? | Default Value |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Excel Application**    | The Excel Application object you want to close. This is the instance your flow launched, normally the **ExcelInstance** output of **Launch Excel Application**. | Text       | Yes       | _(empty)_     |
| **Before Closing Excel** | Decide if you want to save changes before closing Excel. Options include not saving, saving, or saving as a new file. | Select     | No        | SaveDocument  |
| **Save Path**            | The file path where you want to save the document if "Save Document As" is selected.                                  | Text       | No        | _(empty)_     |

## Expected Output Format

The output of this node is a confirmation status indicating that the Excel application has been closed, potentially including file-path information if saving or saving as was performed.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Close Excel Application** node to your workflow.

### Step 2

In the **Excel Application** field, specify the Excel instance your flow launched, usually the **ExcelInstance** output of the **Launch Excel Application** node.

### Step 3

In the **Before Closing Excel** dropdown, choose what action to take before closing:

- **Do not save document**: Closes Excel without saving any changes.
- **Save document**: Saves all changes before closing.
- **Save document as**: Saves the document to a new location before closing.

### Step 4

If you selected **Save document as**, enter the desired file path in the **Save Path** field where the document should be saved.

### Step 5

Execute the node to close the Excel application with your specified settings.

</Steps>

<Callout type="info" title="Tip">
  If you do not select "Save Document As" in the **Before Closing Excel**
  dropdown, the "Save Path" field will not appear.
</Callout>

## Input/Output Examples

| Option Selected      | Save Path            | Output                          | Output Type  |
| -------------------- | -------------------- | ------------------------------- | ------------ |
| Do not save document | _(empty)_            | Excel closed, no save           | Confirmation |
| Save document        | _(empty)_            | Excel closed, changes saved     | Confirmation |
| Save document as     | C:\Documents\Excel\  | Excel closed, file saved as new | Confirmation |

## Common Mistakes & Troubleshooting

| Problem                                 | Solution                                                                                 |
| --------------------------------------- | ---------------------------------------------------------------------------------------- |
| **Save Path not appearing**             | Ensure "Save Document As" is selected in the Before Closing Excel dropdown.              |
| **Invalid Excel Application reference** | Double-check that the Excel Application field properly references a live Excel instance. |
| **Invalid Save Path entered**           | Confirm the path is valid and the directory is accessible.                               |

## Real-World Use Cases

- **End-of-Day Tasks**: Automatically close the flow's Excel instance, saving final changes before shutting down your system.
- **Automated Report Delivery**: Save a report to a specific directory before closing Excel, ensuring reports are stored and updated.
- **Data Processing Completion**: After data manipulation, choose whether to save the workbook or discard changes.
