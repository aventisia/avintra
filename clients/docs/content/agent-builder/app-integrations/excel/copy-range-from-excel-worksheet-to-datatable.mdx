# Copy Range from Excel Worksheet to DataTable

The **Copy Range from Excel Worksheet to DataTable** node allows you to select and transfer a specific range of cells from an Excel worksheet into a DataTable within your automation process. This is particularly useful when you need to manipulate or analyze data extracted from spreadsheets without manually copying and pasting between Excel and your application.

Typical use cases include:

- Importing data for automated report generation.
- Transferring data as part of a larger data processing workflow.
- Extracting and processing sections of spreadsheets for analysis.

## Configuration Options

| Field Name            | Description                                                                     | Input Type | Required? | Default Value |
| --------------------- | ------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **WorksheetInstance** | The Excel Worksheet object from which the data will be copied.                  | Text       | Yes       | _(empty)_     |
| **Range to Copy**     | The specific range of cells in the worksheet you want to copy (e.g., 'A1:B10'). | Text       | Yes       | _(empty)_     |
| **Has Headers**       | Indicates if the first row in the range includes column headers.                | Switch     | No        | true          |

## Expected Output Format

The output from this node is a **DataTable** containing the data from the selected range. If the range includes headers, these are used as column names in the DataTable.

- Example: If the range is 'A1:B10' and headers are included, the DataTable will contain column names as specified in row 1.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Copy Range from Excel Worksheet to DataTable** node into your workflow.

### Step 2

In the **Worksheet Instance** field, enter the name or reference to the Excel Worksheet object you wish to copy data from.

### Step 3

In the **Range to Copy** field, specify the range of cells you want to include. Ensure it follows Excel's format (e.g., 'A1:B10').

### Step 4

If your selected range includes headers as the first row, toggle **Has Headers** to on.

### Step 5

The data from the specified range will be available as **CopiedData** for further processing within your automation.

</Steps>

<Callout type="info" title="Tip">
  Keep the **Has Headers** option checked if your data range includes column
  titles. This ensures that the DataTable's columns are named correctly.
</Callout>

## Input/Output Examples

| Range to Copy | Has Headers | Sample Input Value | Output DataTable                        |
| ------------- | ----------- | ------------------ | --------------------------------------- |
| 'A1:B10'      | Yes         | Name, Age in A1:B1 | DataTable with columns "Name" and "Age" |
| 'A2:B10'      | No          | Starting from A2   | DataTable without header metadata       |

## Common Mistakes & Troubleshooting

| Problem                            | Solution                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------- |
| **Invalid Worksheet Instance**     | Ensure the worksheet reference is correct and currently accessible.                      |
| **Incorrect Range Format**         | Verify that the range is entered using standard Excel range notation (e.g., 'A1:D20').   |
| **Unintended DataTable Structure** | Double-check your **Has Headers** setting if DataTable columns do not align as expected. |
