# Filter Cells in Excel Worksheet

The **Filter Cells in Excel Worksheet** node enables you to selectively view specific data in an Excel worksheet by applying filters based on your criteria. This node is particularly useful for managing large datasets where you need to isolate information relevant for reporting, analysis, or presentation without altering the actual data.

For example:

- Filtering a dataset to show only rows where the sales value exceeds a certain threshold.
- Displaying only specific categories of items, like a particular product type or status.
- Quickly finding and working with only the relevant information within a large Excel sheet.

## Configuration Options

| Field Name             | Description                                                                            | Input Type | Required? | Default Value |
| ---------------------- | -------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Worksheet Instance** | The Excel Worksheet object to apply the filter on.                                     | Text       | Yes       | _(empty)_     |
| **Filter Mode**        | Specifies how to filter cells: active sheet, specific range, named cells, or table.    | Select     | Yes       | ActiveSheet   |
| **Start Column**       | The starting column of the range to filter (required if 'Specific Range' is selected). | Text       | No        | _(empty)_     |
| **End Column**         | The ending column of the specified range (required if 'Specific Range' is selected).   | Text       | No        | _(empty)_     |
| **Start Row**          | The starting row of the range to filter (required if 'Specific Range' is selected).    | Text       | No        | _(empty)_     |
| **End Row**            | The ending row of the range (required if 'Specific Range' is selected).                | Text       | No        | _(empty)_     |
| **Named Cells**        | The name of the named range (required if 'NamedCells' is selected).                    | Text       | No        | _(empty)_     |
| **Table Name**         | The name of the table (required if 'Table' is selected).                               | Text       | No        | _(empty)_     |
| **Column To Filter**   | The column letter (e.g., 'A') or number (e.g., 1) to apply the filter on.              | Text       | Yes       | _(empty)_     |
| **Filter Criteria**    | The condition to apply as a filter (e.g., '=Apple', '≥10').                            | Text       | Yes       | _(empty)_     |

## Expected Output Format

There is no direct output from this node; instead, the specified rows in your Excel worksheet are filtered in place, displaying only the data that matches your criteria.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Filter Cells in Excel Worksheet** node into your flow.

### Step 2

In the **Worksheet Instance** field, enter the instance of the Excel worksheet you want to filter.

### Step 3

Select the **Filter Mode** from the dropdown:

- **Active Sheet**: Applies the filter to the active sheet.
- **Specific Range**: Filters a specified range; additional fields for start and end columns/rows will appear.
- **Named Cells**: Filters one of the named ranges; enter the name in **Named Cells**.
- **Table**: Filters an Excel table; enter the table name in **Table Name**.

### Step 4

If you selected **Specific Range** in the **Filter Mode**, fill in the following fields:

- **Start Column**, **End Column**: Define the range from where to start and end filtering columns.
- **Start Row**, **End Row**: Define the range for filtering rows.

### Step 5

Enter the column to be filtered in the **Column To Filter** field using the column letter (e.g., 'A') or number (e.g., 1).

### Step 6

In the **Filter Criteria** field, specify the condition for filtering, such as `>10`, `=Apple`, or `<>Complete`.

</Steps>

<Callout type="warning" title="Important!">
  Ensure you have access to the Excel file and the worksheet is not locked for
  editing. Double-check that you have entered correct filter criteria to avoid
  empty or incorrect results.
</Callout>

## Input/Output Examples

There are no numeric or text outputs to showcase for this node. The output is a filtered view of your worksheet based on the set criteria.

## Common Mistakes & Troubleshooting

| Problem                                   | Solution                                                                                            |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **No rows visible after filtering**       | Check if the filter criteria are set correctly and ensure the data actually meet those criteria.    |
| **Fields for Specific Range not showing** | Make sure that "Specific Range" is selected in the Filter Mode dropdown.                            |
| **Incorrect range results**               | Verify the columns and rows specified for the range. Ensure they are within the actual data bounds. |
| **Invalid named range or table name**     | Validate that the named range or table exists in the worksheet and that the spelling is correct.    |

## Real-World Use Cases

- **Sales Analysis**: Quickly identify high or low performing products by filtering sales figures.
- **Inventory Checks**: Isolate inventory items that are below reorder levels for quick reporting.
- **Customer Segmentation**: Filter out customer data to target specific demographics or customer types.
- **Data Cleaning**: Easily identify and exclude incomplete or erroneous data entries from datasets.
