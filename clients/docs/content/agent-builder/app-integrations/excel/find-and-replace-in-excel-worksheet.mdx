# Find and Replace in Excel Worksheet

The **Find and Replace in Excel Worksheet** node is designed to help you search for a specific piece of text within an Excel worksheet and replace it with different text if needed. This is particularly useful when updating data entries or correcting information across large datasets quickly and efficiently.

For example:

- Quickly correct spelling errors throughout an Excel worksheet.
- Update outdated terminology efficiently in all cells.
- Locate specific entries and replace them with updated values.

## Configuration Options

| Field Name                     | Description                                                          | Input Type | Required? | Default Value |
| ------------------------------ | -------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Worksheet Instance**         | The Excel Worksheet object where find and replace will be performed. | Text       | Yes       | _(empty)_     |
| **Search Mode**                | Choose between finding text only or finding and replacing text.      | Select     | Yes       | Find          |
| **Text To Find**               | The text or value to find in the worksheet.                          | Text       | No        | _(empty)_     |
| **Text To Replace With**       | The text or value to replace the found text with.                    | Text       | No        | _(empty)_     |
| **All Matches**                | If true, replaces all occurrences, not just the first one.           | Switch     | No        | _(empty)_     |
| **Match Case**                 | Enable this to perform a case-sensitive search.                      | Switch     | No        | _(empty)_     |
| **Match Entire Cell Contents** | Matches only cells that contain exactly the specified text.          | Switch     | No        | _(empty)_     |
| **Search By**                  | Choose whether to search by rows or by columns.                      | Select     | No        | Rows          |

## Expected Output Format

When this node runs, it generates:

- **Found Cells**: A list of all matched cell locations (if "All Matches" is enabled).
- **Found Column Index**: The column index of the matched cell (if "All Matches" is not enabled).
- **Found Row Index**: The row index of the matched cell (if "All Matches" is not enabled).

These outputs are useful for building further logic in your workflow.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Find and Replace in Excel Worksheet** node to your automation flow.

### Step 2

In the **Worksheet Instance** field, input the Excel worksheet object that will be used for the operation.

### Step 3

Select a **Search Mode**:

- **Find**: Locate text in the worksheet.
- **Find and Replace**: Find and replace specified text in the worksheet.

### Step 4

Enter the text you wish to search for in the **Text To Find** field.

### Step 5

If you selected **Find and Replace**, enter the text you wish to use as a replacement in the **Text To Replace With** field.

### Step 6

Use switches to customize your search:

- **All Matches**: Check if you wish to replace all instances of the found text.
- **Match Case**: Toggle for a case-sensitive search.
- **Match Entire Cell Contents**: Toggle to match cells that contain exactly the specified text.

### Step 7

Select **Search By** method to decide whether to search by rows or columns.

### Step 8

Run the node. Outputs will include the found cell information, depending on your configurations.

</Steps>

<Callout type="info" title="Note">
  The "Text To Replace With" field is required only when "Find and Replace" is
  selected in the **Search Mode**.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                            | Solution                                                                                            |
| ---------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Replacement text not appearing** | Ensure "Find and Replace" is selected in **Search Mode**, and "Text To Replace With" is filled out. |
| **No results found**               | Double-check your **Search By** settings and input for spelling or case sensitivity (if enabled).   |
| **Case-sensitive mismatch**        | Check if **Match Case** is toggled according to your search requirement.                            |
| **Unexpected cell matches**        | Verify if **Match Entire Cell Contents** is toggled to get a precise match for entire cells.        |

## Real-World Use Cases

- **Data Correction**: Automate the correction of frequent typos or outdated nomenclature in data sets.
- **Content Standardization**: Enforce consistent terms or names organization-wide by automatically replacing deprecated terms.
- **Dynamic Reporting**: Quickly adjust numerical or textual values in project reports, such as updating fiscal year references or product codes.
