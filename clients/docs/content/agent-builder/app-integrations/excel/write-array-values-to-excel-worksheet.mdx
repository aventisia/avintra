# Write Array Values to Excel Worksheet

The **Write Array Values to Excel Worksheet** node allows you to write data directly into an Excel worksheet from your flow. It can handle writing both single values and lists of values into a specified worksheet, which is useful for automating tasks like data entry, report generation, or maintaining project trackers in Excel.

## Configuration Options

| Field Name                | Description                                                                                              | Input Type | Required? | Default Value   |
| ------------------------- | -------------------------------------------------------------------------------------------------------- | ---------- | --------- | --------------- |
| **Worksheet Instance**    | The Excel worksheet object where the data will be written.                                               | Text       | Yes       | _(empty)_       |
| **Value(s) To Write**     | The value or array of values to be written across columns.                                               | Text       | Yes       | _(empty)_       |
| **Write Mode**            | Select how to target cells for writing: specified cell, current active cell, or named range.             | Select     | Yes       | OnSpecifiedCell |
| **Column**                | The letter of the starting column (e.g., 'A') if not providing a Column Index.                           | Text       | No        | _(empty)_       |
| **Column Index**          | The index number of the starting column (1 corresponds to 'A'). Takes precedence over Column if > 0.     | Text       | No        | _(empty)_       |
| **Row**                   | The row number where the data will be written.                                                           | Text       | No        | _(empty)_       |
| **Name**                  | The named range in the worksheet to write data into. Required only if choosing "On Named Cells" in mode. | Text       | No        | _(empty)_       |
| **Populate Entire Range** | Determines if the entire named range should be filled with the same value.                               | Switch     | No        | _(empty_)       |

## Expected Output Format

The output produced by this node does not generate new data but updates the specified Excel worksheet location with the provided values.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Write Array Values to Excel Worksheet** node into your flow.

### Step 2

In the **Worksheet Instance** field, specify the Excel worksheet you aim to write data to.

### Step 3

Fill in the **Value(s) To Write** field with either a single value or multiple values you wish to write.

### Step 4

Select the **Write Mode** from the dropdown to determine where your data will be entered:

- **On Specified Cell**: Write to a specific cell you define.
- **On Currently Active Cell**: Write to the currently active cell in the worksheet.
- **On Named Cells**: Use a named range to distribute your data.

### Step 5

If you selected "On Specified Cell," provide either **Column** or **Column Index**, and the **Row** for precise writing location.

### Step 6

If "On Named Cells" mode is chosen, you'll need to input the **Name** of the named range. Optionally, toggle **Populate Entire Range** if you want all cells in the range to have the same value.

### Step 7

Execute the flow to write the data into the designated Excel worksheet.

</Steps>

<Callout type="info" title="Note">
  If using "On Named Cells" mode, ensure the named range exists in your Excel
  worksheet before using this node.
</Callout>

<Callout type="warning" title="Caution">
  Ensure the worksheet is not in use or locked by another application during
  writing to avoid errors.
</Callout>

## Input/Output Examples

| Input Values       | Write Mode               | Expected Result                                         |
| ------------------ | ------------------------ | ------------------------------------------------------- |
| "Hello, World!"    | On Specified Cell        | Writes "Hello, World!" to specified cell in worksheet.  |
| ["Item1", "Item2"] | On Named Cells           | Fills the named range cells with "Item1" and "Item2".   |
| 123                | On Currently Active Cell | Writes "123" into whichever cell is currently in focus. |

## Common Mistakes & Troubleshooting

| Problem                                     | Solution                                                                                                            |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Invalid sheet name entered**              | Verify that the worksheet name is correct and that the worksheet is open and accessible.                            |
| **No output observed**                      | Check if the flow was executed successfully and ensure the worksheet was not read-only at the time of writing data. |
| **Data mismatch in worksheet**              | Re-confirm the **Value(s) To Write** and ensure they are in the correct format for the intended cells.              |
| **Write Mode dependent fields not visible** | Make sure to select the appropriate "Write Mode" option to reveal all necessary fields like Column, Row, or Name.   |

## Real-World Use Cases

- **Budget Sheets**: Automatically enter projected vs. actual expenses into pre-set cells in a monthly budget spreadsheet.
- **Inventory Updates**: Feed new inventory data into an existing Excel log as items are stocked or sold.
- **Sales Reporting**: Fill sales data across specific regions by using named ranges to target different sections of a master report spreadsheet.
