# Get Active Excel Worksheet

The **Get Active Excel Worksheet** node is designed to help you access the currently active worksheet in an Excel workbook. This is especially useful when working with dynamic Excel files where the active worksheet might change based on user interaction or automated processes.

For example, you can use it to:

- Identify the worksheet that a user last interacted with.
- Perform operations on the active worksheet without specifying its name manually.
- Retrieve details about the active worksheet such as its name and position within the workbook.

## Configuration Options

| Field Name                    | Description                                                            | Input Type | Required? | Default Value   |
| ----------------------------- | ---------------------------------------------------------------------- | ---------- | --------- | --------------- |
| **Workbook Instance**         | The Excel Workbook object from which to retrieve the active worksheet. | Text       | Yes       | _(empty)_       |
| **Sheet Name**                | Returns the name of the currently active worksheet.                    | Output     | No        | SheetName       |
| **Sheet Index**               | Returns the index of the currently active worksheet.                   | Output     | No        | SheetIndex      |
| **Active Worksheet Instance** | Returns the active worksheet instance.                                 | Output     | No        | ActiveWorksheet |

## Expected Output Format

The output includes three main pieces of data:

- **Sheet Name**: A string representing the name of the active worksheet (e.g., `"SalesData"`).
- **Sheet Index**: A numeric value representing the position of the worksheet in the workbook (e.g., `3`).
- **Active Worksheet Instance**: An object reference to the active worksheet for advanced operations.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Get Active Excel Worksheet** node into your flow.

### Step 2

In the **Workbook Instance** field, specify the Excel workbook you want to work with. This should be an Excel object that you have in your flow.

### Step 3

Once the node is added to your flow, it will automatically output the following:

- **Sheet Name**: The name of the currently active worksheet.
- **Sheet Index**: The index of the active worksheet relative to other sheets.
- **Active Worksheet Instance**: The instance of the active worksheet as an object for further automation tasks.

</Steps>

<Callout type="info" title="Tip">
  Ensure your workbook is open and accessible in your automation environment to
  retrieve accurate data from the active worksheet.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                       | Solution                                                                                       |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Workbook Instance not provided**            | Make sure to enter a valid Workbook Instance in the input field.                               |
| **Incorrect worksheet information retrieved** | Verify that the workbook is active and open, and the worksheet you intend to access is active. |
| **Field outputs not showing**                 | Double-check that the node has run and that the Excel workbook is correctly referenced.        |

## Real-World Use Cases

- **Financial Reporting**: Automatically get data from the current active sheet when generating reports.
- **Data Analysis**: Seamlessly connect to the active sheet for ongoing data analysis tasks.
- **Project Management**: Use the active worksheet data in a project dashboard for dynamic updates.
