# Select Cells in Excel Worksheet

The **Select Cells in Excel Worksheet** node allows you to specify a selection of cells within a spreadsheet document, either by using predefined names, specifying a range, or selecting cells relative to the current active cell. This functionality is helpful when you need to programmatically access, modify, or analyze specific areas of data within a larger Excel worksheet.

For example:

- Selecting a named range that consolidates frequently accessed data.
- Defining a custom cell range for operations like highlighting or formula application.
- Navigating relative to the current active position for dynamic cell range selections.

## Configuration Options

| Field Name             | Description                                                                                                      | Input Type | Required? | Default Value |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Worksheet Instance** | The Excel Worksheet object where the cell selection will be performed.                                           | Text       | Yes       | _(empty)_     |
| **Selection Mode**     | Specifies how to select the cells. Options are: Named Cells, Range of Cells, Relative to Active Cell.            | Select     | Yes       | NamedCells    |
| **Name**               | The name of the named range to select. _Only needed if Selection Mode is "Named Cells"._                         | Text       | No        | _(empty)_     |
| **Start Column**       | The starting column of the range to select. _Only needed if Selection Mode is "Range of Cells"._                 | Text       | No        | _(empty)_     |
| **End Column**         | The ending column of the range to select. _Only needed if Selection Mode is "Range of Cells"._                   | Text       | No        | _(empty)_     |
| **Start Row**          | The starting row of the range to select. _Only needed if Selection Mode is "Range of Cells"._                    | Text       | No        | _(empty)_     |
| **End Row**            | The ending row of the range to select. _Only needed if Selection Mode is "Range of Cells"._                      | Text       | No        | _(empty)_     |
| **X-Axis Direction**   | Direction along the X-axis for relative selection. _Only needed if Selection Mode is "Relative to Active Cell"._ | Select     | No        | Right         |
| **Y-Axis Direction**   | Direction along the Y-axis for relative selection. _Only needed if Selection Mode is "Relative to Active Cell"._ | Select     | No        | Above         |
| **X Offset**           | Number of columns to offset from the active cell. _Only needed if Selection Mode is "Relative to Active Cell"._  | Text       | No        | _(empty)_     |
| **Y Offset**           | Number of rows to offset from the active cell. _Only needed if Selection Mode is "Relative to Active Cell"._     | Text       | No        | _(empty)_     |

## Expected Output Format

This node does not have an explicit output value. It performs an action of selecting cells within the specified worksheet.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Select Cells in Excel Worksheet** node into your flow.

### Step 2

In the **Worksheet Instance** field, enter the name or reference of the worksheet where you want to select the cells.

### Step 3

Choose the **Selection Mode** depending on how you want to select the cells:

- **Named Cells**: Use if you have a predefined name for the cell range. Fill in the **Name** field.
- **Range of Cells**: Enter the **Start Column**, **End Column**, **Start Row**, and **End Row** to create a range.
- **Relative to Active Cell**: Specify directions and offsets with **X-Axis Direction**, **Y-Axis Direction**, **X Offset**, and **Y Offset**.

### Step 4

Upon completing the configuration, the cell selection will be enacted on the specified worksheet.

</Steps>

<Callout type="info" title="Note">
  Fields are conditional based on the selected **Selection Mode**. Ensure you
  choose the correct mode to reveal and fill the appropriate fields.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                  | Solution                                                                                                                                             |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Fields not appearing for selection**   | Ensure that you have chosen a **Selection Mode** to make relevant fields visible. Each mode has specific fields that will only appear when selected. |
| **Invalid Worksheet Instance**           | Make sure the **Worksheet Instance** field contains a valid Excel worksheet reference. Check for typos or incorrect references.                      |
| **Cells not being selected as expected** | Double-check the values in related fields. If using relative selection, confirm your offset and direction inputs are correct.                        |

## Real-World Use Cases

- **Routine Data Analysis**: Selecting specific rows for analysis in monthly reports.
- **Template Management**: Accessing and updating cells in standardized documents.
- **Dynamic Positioning**: Useful in macros where cell positions need determination relative to user interaction points.
