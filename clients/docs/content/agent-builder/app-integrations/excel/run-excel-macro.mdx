# Run Excel Macro

The **Run Excel Macro** node allows you to execute a specific VBA macro within an Excel workbook. This can be extremely useful when you need to automate tasks directly in Excel without manually opening the workbook or running the script. Use this node when you want to harness Excel's macro functionality as part of a larger automation process.

For example:

- Automating report generation
- Running complex calculations or data manipulations
- Formatting sheets based on specific criteria

## Configuration Options

| Field Name            | Description                                                  | Input Type | Required? | Default Value |
| --------------------- | ------------------------------------------------------------ | ---------- | --------- | ------------- |
| **Workbook Instance** | The Excel Workbook object containing the target macro.       | Text       | Yes       | _(empty)_     |
| **Macro Name**        | The name of the VBA macro to execute. Eg: `Module1.MyMacro`. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node will be the **value returned by the macro**, if the macro specifies a return value. This output is provided as `MacroReturnValue`.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Run Excel Macro** node to your flow.

### Step 2

In the **Workbook Instance** field, enter the Excel Workbook object that contains the target macro.

### Step 3

In the **Macro Name** field, type the exact name of the macro you want to run. Make sure to include the module and macro name (e.g., `Module1.MyMacro`).

### Step 4

Execute the node to run the macro in your Excel workbook. The result will be saved as `MacroReturnValue` for further use.

</Steps>

<Callout type="warning" title="Important">
  Ensure that the macro you intend to run is enabled in your Excel settings and
  that any security settings allow for macro executions.
</Callout>

<Callout type="note" title="Note">
  If the macro does not return a value, `MacroReturnValue` will be empty.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                       | Solution                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------------- |
| **Macro does not run**        | Check the macro name spelling and include the module name. Also, ensure macros are enabled. |
| **Empty `MacroReturnValue`**  | Verify that the macro includes logic to return a value.                                     |
| **Invalid Workbook Instance** | Ensure the workbook object is correctly specified and accessible.                           |

## Real-World Use Cases

- **Financial Reporting**: Automate the generation of monthly financial reports through pre-coded Excel macros.
- **Data Processing**: Run a macro to clean and standardize data in large spreadsheets.
- **Inventory Management**: Use macros to update stock levels based on sales data automatically imported into Excel.
- **Visual Styling**: Apply consistent visual formatting across multiple sheets using a macro.
