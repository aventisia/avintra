# Delete Excel Worksheet

The **Delete Excel Worksheet** node is designed to remove a specific worksheet from an Excel workbook. This is helpful if you need to manage or clean up Excel files by deleting unnecessary sheets.

For example:

- Streamlining files by removing outdated or irrelevant worksheets.
- Enabling efficient data management by removing extraneous data sheets.
- Automating the cleanup of temporary worksheets after processing data.

## Configuration Options

| Field Name             | Description                                                                           | Input Type | Required? | Default Value |
| ---------------------- | ------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Worksheet Instance** | The Excel Worksheet object to delete. This is optional if you're using Deletion Mode. | Text       | No        | _(empty)_     |
| **Deletion Mode**      | Specifies how to identify the worksheet to delete: by Name or Index.                  | Select     | Yes       | Name          |
| **Worksheet Name**     | The name of the worksheet to delete. Required if Deletion Mode is "Name".             | Text       | No        | _(empty)_     |
| **Worksheet Index**    | The index of the worksheet to delete. Required if Deletion Mode is "Index".           | Text       | No        | _(empty)_     |

## Expected Output Format

This node does not produce an output value. Instead, it updates the Excel workbook by deleting the specified worksheet.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Delete Excel Worksheet** node into your flow.

### Step 2

Determine the method for identifying the worksheet to delete. In the **Deletion Mode** dropdown, choose one of the following:

- **Name**: Use the worksheet's name.
- **Index**: Use the worksheet's index number.

### Step 3

- If you chose **Name** in the Deletion Mode, enter the worksheet's name in the **Worksheet Name** field.
- If you chose **Index**, enter the index number in the **Worksheet Index** field.

### Step 4

(Optional) If you have an advanced setup where you pass a Worksheet Instance object, fill in the **Worksheet Instance** field. You can skip this if Deletion Mode is properly configured.

### Step 5

Execute the node to remove the specified worksheet from the Excel workbook.

</Steps>

<Callout type="info" title="Note">
  Ensure your Excel workbook is saved after the deletion to retain changes.
</Callout>

## Input/Output Examples

| Deletion Mode | Worksheet Name | Worksheet Index | Action Taken                                  |
| ------------- | -------------- | --------------- | --------------------------------------------- |
| Name          | "Quarter1"     | _(n/a)_         | Deletes the sheet named "Quarter1"            |
| Index         | _(n/a)_        | 3               | Deletes the 4th worksheet (index starts at 0) |

## Common Mistakes & Troubleshooting

| Problem                                     | Solution                                                                                                |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Worksheet is not deleted**                | Verify that the worksheet name or index is correct, and ensure the correct Deletion Mode is selected.   |
| **Worksheet Name/Index fields not showing** | Make sure you select the appropriate Deletion Mode (Name or Index) so relevant fields appear for input. |
| **Excel workbook not updated**              | Confirm that you save the workbook after modification to apply and keep changes.                        |

## Real-World Use Cases

- **Data Consolidation**: Automatically remove temporary data sheets after merging data for reports.
- **File Clean-up**: Regularly delete worksheets containing outdated data to maintain organized spreadsheets.
- **Template Adjustment**: Modify templates by removing unnecessary sheets pre-processing.
