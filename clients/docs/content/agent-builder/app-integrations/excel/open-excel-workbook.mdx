# Open Excel Workbook

The **Open Excel Workbook** node allows you to open or access an existing Excel workbook within the Excel application instance you pass to it, normally the **ExcelInstance** output of **Launch Excel Application**. This is particularly useful when you need to perform operations on spreadsheets without manually opening each file. You can even choose to open the workbook in read-only mode for viewing purposes.

The node works inside the instance it is given: it does not start an Excel of its own and does not reach into another Excel that is already open.

## Configuration Options

| Field Name                   | Description                                                                                                   | Input Type | Required? | Default Value |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Excel Instance**           | The Excel application instance to work in, normally the **ExcelInstance** output of **Launch Excel Application**. | Text       | Yes       | _(empty)_     |
| **Workbook Name**            | The name of the Excel workbook you wish to open or access (e.g., Report.xlsx).                                | Text       | Yes       | _(empty)_     |
| **Open as ReadOnly**         | Set this to true if you want to open the workbook in read-only mode, preventing any changes from being saved. | Switch     | No        | _(empty)_     |
| **Read Protection Password** | If the workbook is read-protected, enter the password required to open it.                                    | Password   | No        | _(empty)_     |

## Expected Output Format

The output of this node is a **Workbook Instance**, which represents the opened or accessed Excel workbook. This can be used in further Excel-related activities in your workflow.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Open Excel Workbook** node into your flow.

### Step 2

In the **Excel Instance** field, specify the Excel application instance to work in, usually the **ExcelInstance** output of **Launch Excel Application**.

### Step 3

Enter the **Workbook Name** of the Excel file you wish to open.

### Step 4

(Optional) Toggle **Open as ReadOnly** if you want to open the file in read-only mode.

### Step 5

(Optional) Enter the **Read Protection Password** if the workbook is protected and requires a password to open.

### Step 6

The opened workbook will be available as **WorkbookInstance** for further use in other nodes.

</Steps>

<Callout type="info" title="Tip">
  Ensure that the workbook names are correctly spelled, including the file
  extension (e.g., '.xlsx').
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                              | Solution                                                                                                    |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Workbook does not open**                           | Verify that the **Workbook Name** is correct and the specified file exists in the directory being accessed. |
| **Read Protection Password is incorrect**            | Double-check the password and ensure it is accurate. Remember, passwords are case-sensitive.                |
| **Workbook opens in edit mode instead of read-only** | Ensure **Open as ReadOnly** is toggled on if you wish to prevent editing.                                   |

## Real-World Use Cases

- **Monthly Reports**: Quickly access and update data in a monthly report workbook without the manual hassle of opening each file.
- **Review Documents**: Open Excel workbooks in read-only mode to review key documents without accidentally modifying data.
- **Shared Resources**: Access shared Excel workbooks in environments where file integrity is critical by using read-only mode.
