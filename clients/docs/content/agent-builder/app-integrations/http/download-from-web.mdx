# Download from Web

The **Download from Web** node enables you to fetch content from the internet using a URL. This node is useful when you need to download text, HTML, JSON, PDFs, or other data from web sources for further processing or analysis. You can choose to either store this downloaded content in memory or save it directly to a file on your local system.

## Configuration Options

| Field Name          | Description                                                                                     | Input Type | Required? | Default Value |
| ------------------- | ----------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **URL**             | The URL of the resource you want to download (e.g., text, HTML, JSON, PDF).                     | Text       | Yes       | _(empty)_     |
| **Save To File**    | If selected, downloads the content to a local file instead of returning it as string.           | Switch     | No        | _(empty)_     |
| **File Path**       | The full path where the downloaded file should be saved. Required if 'Save To File' is enabled. | Text       | No        | _(empty)_     |
| **Timeout Seconds** | Maximum time in seconds to wait before stopping the download due to a timeout.                  | Text       | No        | 60            |

## Expected Output Format

The output of this node depends on your configuration:

- If **Save To File** is **disabled**, the downloaded content is returned as a **string** (e.g., HTML or JSON text).
- If **Save To File** is **enabled**, the output is the **file path** where the content was saved.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Download from Web** node into your flow.

### Step 2

In the **URL** field, enter the web address (URL) of the content you want to download.

### Step 3

Decide whether you wish to save the content to a file:

- If **yes**, toggle the **Save To File** switch.
- If **no**, leave it as is.

### Step 4

If you selected **Save To File**, enter the complete path for where you want the file saved in the **File Path** field.

### Step 5

(Optional) Adjust the **Timeout Seconds** to set how long the system should wait for the download before timing out (default: 60 seconds).

### Step 6

Use the output (found as **Result**) in subsequent nodes or within your workflow as needed.

</Steps>

<Callout type="info" title="Tip">
  If you do not enable "Save To File," the "File Path" field will not be
  displayed.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                  | Solution                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------ |
| **File Path not saving** | Ensure **Save To File** is enabled and you've provided a valid file path.                              |
| **Download timing out**  | Increase the **Timeout Seconds** value if your connection is slow or the server takes time to respond. |
| **URL not entered**      | Double-check that the **URL** field is filled. It's critical for fetching content.                     |

## Real-World Use Cases

- **Data Aggregation**: Download JSON data from web services for real-time data analysis.
- **Web Monitoring**: Automatically fetch and save web pages or documents for archiving.
- **Content Updates**: Download the latest versions of web-based reports or databases for offline use.
- **Resource Sharing**: Fetch online resources and save them to a common directory for team access.
