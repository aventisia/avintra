# Append Row to Google Sheet

The **Append Row to Google Sheet** node enables you to add a single row of data to a Google Sheet automatically. This is particularly useful for updating spreadsheets with new information, such as incoming form submissions or daily data metrics, without manually opening the document.

For example:

- Adding new customer data into an existing Google Sheet to keep your records up-to-date.
- Logging daily sales figures into a spreadsheet for tracking sales performance.

## Configuration Options

| Field Name         | Description                                                                                                     | Input Type | Required? | Default Value |
| ------------------ | --------------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Sheets Service** | The authenticated SheetsService instance needed for Google Sheets operations. Obtainable from the related node. | Text       | Yes       | _(empty)_     |
| **Spreadsheet ID** | The unique identifier of the Google Spreadsheet. Found in the Google Sheets URL.                                | Text       | Yes       | _(empty)_     |
| **Sheet Name**     | Indicates the specific tab within the spreadsheet you want to append data to (e.g., `Sheet1`).                  | Text       | Yes       | _(empty)_     |
| **Range**          | (Optional) Specifies the column range for appending data. Default behavior appends a full row if not set.       | Text       | No        | _(empty)_     |
| **Row Values**     | A collection of values that form the row to be added (e.g., `['John', 'Doe', 'john@example.com']`).             | Text       | Yes       | _(empty)_     |
| **Run Delay (ms)** | (Optional) Adds a delay in milliseconds before performing the operation to mitigate potential rate limits.      | Text       | No        | 0             |

## Expected Output Format

The action does not produce a visible output within the node itself. However, after successful execution, the specified row of data will be appended to the chosen Google Sheet.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Append Row to Google Sheet** node to your flow.

### Step 2

In the **Sheets Service** field, enter or select the appropriate SheetsService instance to authenticate with Google Sheets.

### Step 3

Provide the **Spreadsheet ID** in the designated field. This is located in the Google Sheets URL.

### Step 4

Enter the **Sheet Name** to specify which tab in your spreadsheet you want to append the data to.

### Step 5

(Optional) Define a **Range** if you want the row to be appended to a specific section within the row.

### Step 6

Insert the **Row Values** field with the values you wish to add as a new row. Ensure they're formatted as a list, e.g., `['Value1', 'Value2']`.

### Step 7

(Optional) Specify a **Run Delay (ms)** to introduce additional wait time, which may help with rate limits.

### Step 8

Execute the node to append your data to the Google Sheet.

</Steps>

<Callout type="info" title="Note">
  Ensure your Google Sheets access and permissions are configured correctly with
  the SheetsService instance to enable data append functionality.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                       | Solution                                                                                           |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Authentication issues with Sheets Service** | Double-check your SheetsService setup to make sure you have the correct authentication parameters. |
| **Invalid Spreadsheet ID entered**            | Verify the Spreadsheet ID from the correct part of the Google Sheets URL.                          |
| **Misformatted Row Values**                   | Ensure your Row Values are in list form (e.g., `['value1', 'value2']`).                            |
| **Data not appearing in specified Range**     | Confirm that the Range is accurately set and corresponds with your expectations.                   |

## Real-World Use Cases

- **Customer Data Storage**: Automatically add customer form submissions to a Google Sheet without manual entry.
- **Expense Tracking**: Log daily expenses in your Google Sheet for easy monthly reconciliation.
- **Inventory Updates**: Append new stock entries directly into your inventory spreadsheet for real-time updates.
