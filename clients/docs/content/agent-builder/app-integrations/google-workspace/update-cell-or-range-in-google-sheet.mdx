# Update Cell or Range in Google Sheet

The **Update Cell or Range in Google Sheet** node allows you to update specific cells or ranges within a Google Sheet with new values. It's helpful when you want to programmatically insert data, such as automatically updating metrics, entering new entries in a database, or appending logs to an existing sheet.

## Configuration Options

| Field Name         | Description                                                                                                                                            | Input Type | Required? | Default Value |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- | --------- | ------------- |
| **Sheets Service** | The authenticated SheetsService instance (created using 'Create Google Sheets Service Instance').                                                      | Text       | Yes       | _(empty)_     |
| **Spreadsheet ID** | The unique identifier of the Google Spreadsheet, found in its URL.                                                                                     | Text       | Yes       | _(empty)_     |
| **Sheet Name**     | The name of the sheet tab you want to modify (e.g., `Sheet1`).                                                                                         | Text       | Yes       | _(empty)_     |
| **Range**          | The specific cell or range you wish to update (e.g., `A1`, `A1:B2`).                                                                                   | Text       | Yes       | _(empty)_     |
| **Values**         | The list of values you want to input in the selected range. For a single row, input like `['A1','B1']`; to update multiple rows, use a different node. | Text       | Yes       | _(empty)_     |
| **Run Delay (ms)** | Optional time delay in milliseconds before the update operation to help avoid rate limiting.                                                           | Text       | No        | 0             |

## Expected Output Format

There is no direct output from this node. Instead, it updates the specified cells within your Google Sheet.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Update Cell or Range in Google Sheet** node into your flow.

### Step 2

Ensure you have an authenticated SheetsService instance ready. This is typically generated using the 'Create Google Sheets Service Instance' node.

### Step 3

In the node configuration panel, enter the **Spreadsheet ID** which can be found in the URL of your Google Spreadsheet. For example, in `https://docs.google.com/spreadsheets/d/yourSpreadsheetId/edit`, `yourSpreadsheetId` is the ID.

### Step 4

Provide the **Sheet Name** of the sheet you want to update. This is typically displayed at the bottom of your spreadsheet, such as "Sheet1" or "Expenses".

### Step 5

Specify the **Range** you wish to update. Range format can be a single cell like `A1` or multiple cells like `A1:B2`.

### Step 6

Enter the new **Values** for the specified range. Ensure it matches the range format – for a single cell, you can simply input `["value"]`; for a range, ensure values are placed accordingly.

### Step 7

Optionally, enter a **Run Delay (ms)** if you wish to prevent hitting Google's execution rate limits.

</Steps>

<Callout type="info" title="Note">
  The node operates without direct output. Post-update, verify changes directly
  in your Google Sheet.
</Callout>

## Input/Output Examples

| Spreadsheet ID | Sheet Name | Range | Values    | Expected Result                                                           |
| -------------- | ---------- | ----- | --------- | ------------------------------------------------------------------------- |
| abc123         | Sheet1     | A1    | ["Test"]  | Cell A1 in "Sheet1" of spreadsheet abc123 updated to "Test".              |
| abc123         | Sheet2     | A1:B2 | ["A","B"] | Cells A1 to B2 in "Sheet2" of spreadsheet abc123 updated with new values. |

## Common Mistakes & Troubleshooting

| Problem                            | Solution                                                                                     |
| ---------------------------------- | -------------------------------------------------------------------------------------------- |
| **Invalid Spreadsheet ID**         | Confirm the Spreadsheet ID from the URL matches what you've entered.                         |
| **Incorrect Range Input**          | Make sure the range format is correct (e.g., `A1`, `A1:B2`).                                 |
| **Values Mismatch with Range**     | Ensure your provided values align with the number of cells in the range you specified.       |
| **Missing SheetsService Instance** | Create an instance of SheetsService through the appropriate activity before using this node. |

## Real-World Use Cases

- **Daily Metric Updates**: Automatically update specific metrics daily into a tracking Google Sheet.
- **Inventory Management**: Enter new inventory stocks into a shared sheet without manual data entry.
- **Attendance Logs**: Append daily attendance data into a central log file stored in Google Sheets.
