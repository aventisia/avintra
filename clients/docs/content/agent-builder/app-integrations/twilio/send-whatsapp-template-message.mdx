# Send WhatsApp Template Message

The **Send WhatsApp Template Message** node allows you to send personalized WhatsApp messages using ready-made templates via the Twilio service. This is ideal for businesses looking to automate communication with their clients over WhatsApp, such as sending order updates, alerts, or promotional offers.

For example:

- Send order confirmation messages.
- Notify customers about promotional offers.
- Update users about service outages or important alerts.

## Configuration Options

| Field Name                                      | Description                                                                                                 | Input Type         | Required? | Default Value |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------ | --------- | ------------- |
| **Twilio Credential**                           | The Twilio credential containing valid auth token and accountsId for API authentication.                    | Credentials Select | Yes       | _(none)_      |
| **Recipient Identification Method**             | Specify how to identify the recipient of the WhatsApp message: by phone number or by Messaging Service SID. | Select             | Yes       | PhoneNumber   |
| **Sender Phone Number / Messaging Service SID** | Enter the Twilio phone number or service identifier from which the message will be sent.                    | Text               | Yes       | _(none)_      |
| **Recipient Phone Number**                      | Enter the recipient's phone number (must be a valid Twilio-supported number).                               | Text               | Yes       | _(none)_      |
| **WhatsApp Template Identifier**                | Specify the unique identifier for the WhatsApp template that will be used to send the message.              | Text               | Yes       | _(none)_      |
| **Template Parameters**                         | Provide dynamic values to replace placeholders in the template (e.g., names, dates).                        | Text               | No        | _(none)_      |

## Expected Output Format

The output of this node is a **string** containing the response data from Twilio after sending the WhatsApp message.

Example output: a JSON string with status and message details.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Send WhatsApp Template Message** node into your flow.

### Step 2

Select your **Twilio Credential** from the dropdown to authenticate the message request.

### Step 3

Choose the **Recipient Identification Method**:

- **Phone Number**: Use if identifying by phone number.
- **Messaging Service SID**: Use for sending via a Messaging Service SID.

### Step 4

Enter the relevant value in **Sender Phone Number / Messaging Service SID** based on the selected identification method.

### Step 5

In the **Recipient Phone Number** field, enter the recipient's phone number.

### Step 6

Provide the **WhatsApp Template Identifier** to specify which template to use.

### Step 7

(Optional) Enter any **Template Parameters** to customize the message content.

### Step 8

The result of the message operation will be shown as **Result** for use in further processing.

</Steps>

<Callout type="info" title="Tip">
  Ensure that all phone numbers are in E.164 format (e.g., +14155552671) to
  avoid sending errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                         | Solution                                                                                                                                 |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Invalid phone number format** | Ensure the phone number is in E.164 format.                                                                                              |
| **Authentication error**        | Check that your Twilio credentials are correctly entered and valid.                                                                      |
| **Missing template parameters** | Ensure all necessary template placeholders are filled with corresponding parameters.                                                     |
| **Message delivery failure**    | Verify that the recipient number is a registered WhatsApp number and that the template is approved in your Twilio account configuration. |
