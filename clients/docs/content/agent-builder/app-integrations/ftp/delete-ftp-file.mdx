# Delete FTP File

The **Delete FTP File** node is designed to remove a specified file from an FTP server. This node is particularly useful when you want to automate the maintenance of your FTP server by ensuring that unnecessary or outdated files are deleted seamlessly.

This functionality is ideal for:

- Cleaning up old files and data that are no longer needed.
- Removing sensitive information after processing.
- Managing server storage space.

## Configuration Options

| Field Name         | Description                                                                              | Input Type | Required? | Default Value |
| ------------------ | ---------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **FTP Connection** | The FTP connection object that provides the details needed to connect to the FTP server. | Text       | Yes       | _(empty)_     |
| **File Name**      | The name of the file that you wish to delete from the FTP server.                        | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a message indicating the file that has been successfully deleted, with the name provided in the format: **DeletedFile** (Text).

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Delete FTP File** node into your flow.

### Step 2

In the **FTP Connection** field, input the details of the FTP connection object. Ensure that the connection credentials are correct to access the FTP server.

### Step 3

Enter the **File Name** of the file you wish to delete in the respective field. Make sure to include the correct file path if necessary.

### Step 4

After configuration, run the flow. The deleted file information will be available as **DeletedFile** in your node's outputs for verification or logging purposes.

</Steps>

<Callout type="warning" title="Warning">
  Ensure that the file specified in the **File Name** field is indeed meant to
  be deleted, as this process cannot be undone.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                     | Solution                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------- |
| **FTP Connection error**    | Verify that the FTP connection details are correct and that your network allows FTP access. |
| **File not found**          | Check for any typos in the file name or ensure the file path is specified correctly.        |
| **Permission denied error** | Ensure the FTP user credentials have the necessary permissions to delete files.             |

## Real-World Use Cases

- **Data Management**: Automate the cleanup of old logs or backup files to free up server space.
- **Security**: Automatically delete sensitive data files after they are processed to maintain privacy.
- **File Syncing**: Remove files that have been confirmed to be successfully transferred to another server or location.
