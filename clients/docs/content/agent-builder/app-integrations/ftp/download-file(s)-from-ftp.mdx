# Download File(s) from FTP

The **Download File(s) from FTP** node allows you to download one or more files from an FTP server directly into a specified local directory on your computer. This node is useful for regularly acquiring files from external sources such as reports, logs, or backups.

## Configuration Options

| Field Name                  | Description                                                                     | Input Type | Required?       | Default Value |
| --------------------------- | ------------------------------------------------------------------------------- | ---------- | --------------- | ------------- |
| **FTP Connection**          | The FTP connection object that includes server details and credentials.         | Text       | Yes             | _(empty)_     |
| **Download Multiple Files** | Toggle to choose if you want to download multiple files at once.                | Switch     | No              | False         |
| **File Name**               | The exact name of the file to download. Only used if downloading a single file. | Text       | Yes (if single) | _(empty)_     |
| **File Name List**          | The list of file names to download. Only appears if downloading multiple files. | Text       | No              | _(empty)_     |
| **Local Directory**         | Specifies where on your computer the files will be saved.                       | Text       | Yes             | _(empty)_     |
| **Transfer Type**           | Determines the method of file transfer: ASCII or Binary.                        | Select     | No              | Binary        |
| **If File Exists**          | Decide how to handle files if they already exist locally.                       | Select     | No              | Overwrite     |

## Expected Output Format

The node produces two outputs:

- **Downloaded Files Count**: Number of files successfully downloaded (integer).
- **Skipped Files**: A list of file names that weren't downloaded (string array).

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Download File(s) from FTP** node to your automation flow.

### Step 2

In the **FTP Connection** field, enter the details of your FTP connection, including server address and credentials.

### Step 3

Configure **Download Multiple Files** by toggling the switch:

- **Off**: Download a single file; you need to fill in the **File Name** field.
- **On**: Download multiple files; enter the list of file names in the **File Name List** field.

### Step 4

Specify the **Local Directory** where the files should be saved.

### Step 5

Choose the **Transfer Type** depending on your data requirements:

- **ASCII**: For text files.
- **Binary**: For all other files.

### Step 6

Decide what to do if files with the same name already exist in the local directory by setting the **If File Exists** option:

- **Overwrite**: Replace existing files.
- **Don't Download**: Skip files that already exist.
- **Download with Unique Name**: Save with a new, unique name.

### Step 7

The outputs will be available as **Downloaded Files Count** and **Skipped Files** for further use in the flow.

</Steps>

<Callout type="tip" title="Tip">
  Use the node's output, like **Downloaded Files Count**, to trigger subsequent
  actions in your automation if new files were downloaded.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                        | Solution                                                                                                                           |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| **FTP Connection Errors**      | Double-check the URL, username, and password for the FTP server. Ensure firewall or network settings allow FTP access.             |
| **Local Directory Not Found**  | Verify the path to the local directory is correct and accessible. Ensure no permission issues preventing write access.             |
| **Unexpected File Overwrites** | Review the **If File Exists** option. Choose **Don't Download** or **Download with Unique Name** to prevent accidental overwrites. |

## Real-World Use Cases

- **Daily Report Fetching**: Automate the download of daily sales or inventory reports from business partners.
- **System Backups**: Regularly retrieve backups from a remote server to maintain local backup copies.
- **Log File Collection**: Periodically download log files for analysis from servers to a central repository.
