# Get AWS Certificate Manager Certificate

The **Get AWS Certificate Manager Certificate** node allows you to access your AWS Certificate Manager (ACM) to retrieve certificates and chains securely. This node is used when you need to fetch the current certificate details for various uses, such as configuring web servers or managing secure communications.

For example:

- Obtain a certificate for SSL/TLS encryption on websites.
- Access a certificate chain required for deploying secure applications.
- Retrieve certificated information for validation checks or audits.

## Configuration Options

| Field Name                    | Description                                                                                  | Input Type | Required? | Default Value |
| ----------------------------- | -------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **AWS Credential (Vault ID)** | Choose the AWS credential for authentication (Stored Vault ID).                              | Text       | Yes       | _(empty)_     |
| **Certificate ARN**           | The Amazon Resource Name (ARN) of the certificate you want to retrieve from ACM.             | Text       | Yes       | _(empty)_     |
| **AWS Region**                | The AWS region where your certificate is stored (e.g., `us-east-1`). Default is `us-east-1`. | Text       | No        | _(empty)_     |

## Expected Output Format

The output from this node includes multiple pieces of data in specific formats:

- **Certificate Body**: The main certificate in PEM format. Suitable for SSL/TLS setups.
- **Certificate Chain**: The intermediate certificate chain in PEM format. Useful for validating the certificate.
- **API Response**: The raw JSON response, providing structured data and debug information.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Get AWS Certificate Manager Certificate** node to your workflow.

### Step 2

In the **AWS Credential (Vault ID)** field, select the credential you have configured to authenticate with AWS.

### Step 3

Enter the **Certificate ARN** of the certificate you need to retrieve.

### Step 4

(Optional) Specify the **AWS Region** where the certificate is stored. If not specified, the default region `us-east-1` is used.

### Step 5

Use the output fields **Certificate Body** and **Certificate Chain** in subsequent nodes to apply or further process your certificate data.

### Step 6

For detailed review or troubleshooting, refer to the **API Response** for complete transaction details.

</Steps>

<Callout type="info" title="Note">
  Ensure the AWS Credential (Vault ID) has required permissions to access AWS
  Certificate Manager and retrieve the specified certificate.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                              | Solution                                                                                                    |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **AWS Credential (Vault ID) is incorrect**           | Verify that you have selected the correct Vault ID with sufficient permissions to retrieve the certificate. |
| **Invalid or incorrectly formatted Certificate ARN** | Double-check the ARN format and ensure no typos when pasting into the configuration field.                  |
| **Certificate not found in specified AWS Region**    | Confirm the correct region is selected or specified where the certificate exists.                           |
| **Access Denied error in API Response**              | Check IAM policies and permissions associated with the AWS Credential (Vault ID) used.                      |
