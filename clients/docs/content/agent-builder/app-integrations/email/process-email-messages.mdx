# Process Email Messages

The **Process Email Messages** node allows you to manage your emails by performing operations like moving messages to a specific folder, marking them as unread, or deleting them entirely. This node is especially useful after retrieving emails, enabling you to organize or clean your inbox programmatically according to your needs.

For example:

- Deleting unwanted emails in bulk.
- Marking read emails as unread for follow-up.
- Moving specific emails to designated folders for better organization.

## Configuration Options

| Field Name                        | Description                                                                                           | Input Type | Required? | Default Value |
| --------------------------------- | ----------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Operation**                     | The action you want to perform – delete, mark as unread, or move to a folder.                         | Select     | Yes       | Delete        |
| **Email Messages to Process**     | Enter the IDs of the email messages that you want to manipulate.                                      | Text       | Yes       | _(empty)_     |
| **IMAP Server**                   | Provide the address of your email's IMAP server for accessing emails.                                 | Text       | No        | _(empty)_     |
| **Port**                          | Enter the port number for the IMAP server connection.                                                 | Text       | No        | _(empty)_     |
| **Enable SSL**                    | Toggle to secure the connection using SSL encryption.                                                 | Switch     | No        | Off           |
| **Username**                      | Your email account's username for server authentication.                                              | Text       | No        | _(empty)_     |
| **Password**                      | Your email account's password for server authentication.                                              | Password   | No        | _(empty)_     |
| **Accept Untrusted Certificates** | Toggle to accept SSL certificates that are not trusted.                                               | Switch     | No        | Off           |
| **Mail Folder**                   | Specify the folder to move emails to. This is required if the operation selected is "Move to Folder". | Text       | No        | _(empty)_     |

## Expected Output Format

The node doesn't directly output data; instead, it performs the specified operation on your emails. The results impact your email server or mailbox (e.g., emails are deleted from the server or moved to another folder).

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Process Email Messages** node to your automation flow.

### Step 2

In the **Operation** dropdown, select the action you wish to execute:

- **Delete**: Permanently removes selected emails.
- **Mark as Unread**: Changes the status of emails to unread.
- **Move to Mail Folder**: Transfers emails to a predefined folder.

### Step 3

Enter the IDs of the emails you want to manage in the **Email Messages to Process** field.

### Step 4

If using an IMAP email service, input the **IMAP Server** address, **Port**, and your **Username** and **Password** for authentication, if required.

### Step 5

Toggle **Enable SSL** if your connection requires SSL encryption, and **Accept Untrusted Certificates** if needed for server communication.

### Step 6

If you selected **Move to Mail Folder** in Step 2, specify the target folder in **Mail Folder**.

</Steps>

<Callout type="info" title="Note">
  Remember to input the correct email IDs and verify the operation you are
  choosing to perform to ensure intended results.
</Callout>

## Input/Output Examples

| Operation      | Email IDs | Mail Folder | Connection Settings                | Result                                          |
| -------------- | --------- | ----------- | ---------------------------------- | ----------------------------------------------- |
| Delete         | 123, 456  | _(n/a)_     | Server: mail.example.com, SSL: On  | Deletes emails 123 and 456 from the server.     |
| Mark as Unread | 789       | _(n/a)_     | Server: mail.example.com, SSL: Off | Marks email 789 as unread.                      |
| Move to Folder | 101, 102  | "Important" | Server: imap.example.com, SSL: On  | Moves emails 101 and 102 to "Important" folder. |

## Common Mistakes & Troubleshooting

| Problem                            | Solution                                                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Operation Not Applied**          | Double-check email IDs and verify connections (server, port, SSL). Ensure the correct operation is selected. |
| **Access Denied or Failed Login**  | Validate the entered username and password. Ensure SSL settings match server requirements.                   |
| **Mail Folder Missing**            | Make sure you specify the **Mail Folder** if the operation is set to move emails.                            |
| **Untrusted Certificate Warnings** | Consider enabling **Accept Untrusted Certificates** if the warning persists and security policies allow it.  |

## Real-World Use Cases

- **Spam Management**: Automatically delete spammy or unwanted emails using predefined rules.
- **Organization**: Streamline email folder organization by moving certain emails to designated folders for archiving or processing.
- **Workflow Automation**: Mark emails as unread to ensure they remain in the queue for future tasks or reminders.
