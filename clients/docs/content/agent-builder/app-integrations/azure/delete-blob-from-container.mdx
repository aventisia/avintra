# Delete Blob from Container

The **Delete Blob from Container** node allows you to remove a specific blob from an Azure Blob storage container. This node is particularly useful when you need to manage storage by removing outdated, unnecessary, or sensitive files, ensuring optimal use of your storage resources.

For example:

- Deleting old log files to save space.
- Removing sensitive information after it's no longer needed.
- Cleaning up data directories regularly as a part of a workflow.

## Configuration Options

| Field Name                | Description                                                                  | Input Type | Required? | Default Value |
| ------------------------- | ---------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Blob Container Client** | The instance that connects you to the blob container where the blob resides. | Text       | Yes       | _(empty)_     |
| **Blob Name**             | The specific blob's name that you wish to delete from the container.         | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **boolean value** indicating the success of the deletion process:

- **True** if the blob was successfully found and deleted.
- **False** if the blob couldn't be found or the deletion failed.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Delete Blob from Container** node to your flow.

### Step 2

In the **Blob Container Client** field, enter your blob container client connection details. This links you to the Azure Blob storage where your target blob is stored.

### Step 3

In the **Blob Name** field, specify the exact name of the blob you want to delete.

### Step 4

Once configured, run the node. The result will be available as **BlobWasDeleted** for use in subsequent nodes.

</Steps>

<Callout type="warning" title="Warning">
  Ensure that the Blob Name is correct before executing the node, as deletion
  cannot be undone once processed.
</Callout>

## Input/Output Examples

| Input: Blob Name  | Blob Container Client | Output: Blob Was Deleted |
| ----------------- | --------------------- | ------------------------ |
| "backup-2023.log" | MyStorageAccount      | True                     |
| "user-data"       | MyStorageAccount      | False                    |

- In the first example, the blob "backup-2023.log" was found and successfully deleted from "MyStorageAccount".
- In the second example, "user-data" was not found, hence the deletion was not successful.

## Common Mistakes & Troubleshooting

| Problem                                        | Solution                                                                                                                       |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Blob not found**                             | Verify the blob name is correctly specified and exists in the provided container. Make sure to use exact case sensitive names. |
| **Connection issues to Blob Container Client** | Check if your Blob Container Client details are correct and that there is a stable network connection to Azure services.       |
| **Unexpected false status**                    | If deletion is expected to succeed but returned false, ensure you have appropriate permissions on the Azure Blob storage.      |

## Real-World Use Cases

- **Data Lifecycle Management**: Regularly delete expired data files to maintain storage efficiency.
- **Security**: Remove files containing sensitive data after processing to minimize security risks.
- **Log Management**: Periodically delete older log files to only keep recent logs for analysis.
