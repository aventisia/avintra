# Write to Word Document

The **Write to Word Document** node allows you to seamlessly integrate Word processing into your workflow by writing or appending text to a Word document. This can be useful for automating report generation, adding dynamic content to templates, or appending information in an organized manner without manual intervention.

For example:

- Automatically adding a summary to the beginning or end of a document.
- Inserting specific entries at marked sections within your document.

## Configuration Options

| Field Name          | Description                                                                                         | Input Type | Required? | Default Value       |
| ------------------- | --------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------------- |
| **Word Instance**   | The specific Word instance in which you want to write.                                              | Text       | Yes       | _(empty)_           |
| **Text to Write**   | The text content that will be written to the specified Word document.                               | Text       | Yes       | _(empty)_           |
| **Append New Line** | Determines whether a new line should be appended after the text.                                    | Switch     | No        | true                |
| **Write Text To**   | Choose where in the document the text should be inserted: beginning, end, before or after bookmark. | Select     | No        | BeginningOfWordFile |
| **Bookmark Name**   | The name of the bookmark if writing before or after a bookmark is selected.                         | Text       | No        | _(empty)_           |

## Expected Output Format

There is no direct output from this node; instead, it interacts with a Word document and modifies it according to the configured settings. The changes are made to the Word document content itself.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Write to Word Document** node into your flow.

### Step 2

In the **Word Instance** field, specify which Word application instance should be targeted. This associates the node with the correct Word document.

### Step 3

Enter the desired text in the **Text to Write** field. This is the content that will be inserted into the Word document.

### Step 4

Use the **Append New Line** toggle to decide if a new line should be added after your text. This ensures a clean format within the document.

### Step 5

Select an option from the **Write Text To** dropdown to determine where in the document the text will be written:

- **Beginning of Word file**: Inserts text at the start.
- **End of Word file**: Appends text to the end.
- **Before Bookmark** or **After Bookmark**: Inserts content relative to a specified bookmark.

### Step 6

If you selected **Before Bookmark** or **After Bookmark**, provide the **Bookmark Name** to specify the location for text insertion.

</Steps>

<Callout type="info" title="Tip">
  When using bookmarks, ensure the bookmark names are correctly spelled and
  exist within the document to avoid errors.
</Callout>

## Input/Output Examples

| Write Text To   | Text to Write  | Append New Line | Bookmark Name | Effect on Document                        |
| --------------- | -------------- | --------------- | ------------- | ----------------------------------------- |
| Beginning       | "Summary text" | true            | _(n/a)_       | Inserts "Summary text" at document start. |
| End             | "Conclusion"   | false           | _(n/a)_       | Appends "Conclusion" at document end.     |
| Before Bookmark | "Insert point" | true            | "Section1"    | Inserts "Insert point" before "Section1". |
| After Bookmark  | "Notes"        | false           | "EndNote"     | Inserts "Notes" after "EndNote".          |

## Common Mistakes & Troubleshooting

| Problem                     | Solution                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------- |
| **Text not appearing**      | Ensure the Word instance is correctly identified and the open document is the one intended. |
| **Bookmark-related issues** | Confirm bookmark names exist and match exactly as referenced in your settings.              |
| **Spurious formatting**     | Adjust the **Append New Line** toggle to manage text formatting within paragraphs.          |

## Real-World Use Cases

- **Report Compilation**: Automatically add intros and conclusions to reports without manual edits.
- **Project Documentation**: Quickly append meeting notes to project documents at specific sections.
- **Template Fillers**: Insert dynamic data into predefined templates, such as contracts or mail merges.
