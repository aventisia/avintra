# Lookup Range In Excel Worksheet

The **Lookup Range In Excel Worksheet** node allows you to access and retrieve specific data from an Excel worksheet stored in OneDrive or SharePoint. This node is particularly useful when you need to automate workflows that involve reading data from predefined ranges in Excel files.

## Configuration Options

| Field Name                | Description                                                                                                                                     | Input Type         | Required? | Default Value |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ | --------- | ------------- |
| **M365 Excel Credential** | The credential that contains necessary authentication details (tenant ID, client ID, client secret) for accessing Microsoft 365 Excel services. | Credentials Select | Yes       | _(empty)_     |
| **Drive and Item ID**     | The unique combination of Drive ID and Item ID that identifies your Excel file on OneDrive or SharePoint. Use the format: driveId/items/itemId. | Text               | Yes       | _(empty)_     |
| **Worksheet Name**        | The name of the worksheet in which you want to perform the range lookup.                                                                        | Text               | Yes       | Sheet1        |
| **Range Address**         | The specific cell range (such as A1:B10) in the Excel worksheet you wish to retrieve data from.                                                 | Text               | Yes       | A1            |

## Expected Output Format

The output is labelled **Result** and will provide the details of the specified range within the Excel worksheet. The output will be in a structured format consistent with how data is stored in Excel cells (usually as text or numbers).

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Lookup Range In Excel Worksheet** node into your workflow.

### Step 2

In the **M365 Excel Credential** field, select or enter the appropriate credentials containing your Microsoft 365 tenant ID, client ID, and client secret.

### Step 3

Enter the Excel file's **Drive and Item ID**. Ensure you follow the format: `driveId/items/itemId`.

### Step 4

Provide the **Worksheet Name** to specify which sheet you want to access. The default is **Sheet1**; change it if your data is in another worksheet.

### Step 5

Set the **Range Address** to indicate the specific range of cells you wish to look up, such as **A1:B10**. Default starts from **A1**.

### Step 6

Once configured, the node will retrieve and display the data from the specified range in the Excel worksheet.

</Steps>

<Callout type="info" title="Note">
  Make sure your credentials have the necessary permissions to read the Excel
  file in OneDrive or SharePoint.
</Callout>

## Input/Output Examples

| Sample Worksheet Name | Sample Range Address | Result Output                                | Output Description                           |
| --------------------- | -------------------- | -------------------------------------------- | -------------------------------------------- |
| **DataSheet**         | A1:A5                | `{"A1": "Value1", "A2": "Value2", etc.}`     | Displays data for cells A1 through A5.       |
| **Summary**           | B2:D4                | `{"B2": "Sum", "C2": "Mean", "D2": "Count"}` | Provides analysis data from specified range. |

## Common Mistakes & Troubleshooting

| Problem                       | Solution                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------ |
| **Invalid Credentials Error** | Double-check the tenant ID, client ID, and client secret in your M365 Excel Credential.    |
| **File Not Found**            | Verify and correct the Drive and Item ID to ensure they match your Excel file's location.  |
| **Range Out of Bounds**       | Check that the Range Address corresponds to a valid region within the specified worksheet. |

## Real-World Use Cases

- **Financial Analysis**: Quickly extract specific data ranges for financial reports or dashboards.
- **Data Validation**: Automate reading from Excel sheets for validation processes without manual file access.
- **Sales Tracking**: Retrieve sales data recorded in Excel for generating automated reports or summaries.
