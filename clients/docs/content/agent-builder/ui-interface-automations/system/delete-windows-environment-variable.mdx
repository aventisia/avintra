# Delete Windows Environment Variable

The **Delete Windows Environment Variable** node is designed to remove specific environment variables from your Windows system. This feature is useful when you need to clean up or reset specific system or user settings that are stored in these variables. By deleting unnecessary environment variables, you can help maintain optimal system performance and avoid potential conflicts in your automation processes.

## Configuration Options

| Field Name                    | Description                                                                                            | Input Type | Required? | Default Value |
| ----------------------------- | ------------------------------------------------------------------------------------------------------ | ---------- | --------- | ------------- |
| **Environment Variable Name** | Select the environment variable you wish to delete from your system or user profile.                   | Select     | No        | None          |
| **Scope**                     | Choose whether the deletion should occur in the User's environment variables or System-wide variables. | Select     | No        | User          |

## Expected Output Format

There is no direct output value from this node. The primary function is the action of deleting an environment variable, which does not produce a numeric or textual output. The expectation is an absence of the specified variable from the chosen scope.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Delete Windows Environment Variable** node into your workflow.

### Step 2

In the **Environment Variable Name** dropdown, select the variable you want to delete. Options include common variables like **Path**, **TMP**, **OneDrive**, etc.

### Step 3

Select the **Scope** for the deletion action:

- **User**: Deletes the environment variable from the current user's profile.
- **System**: Deletes the environment variable from the entire system.

### Step 4

Confirm your selection and execute the node to perform the deletion.

</Steps>

<Callout type="warning" title="Caution">
  Deleting system environment variables can affect application performance and
  system functionality. Ensure you know the purpose of the variable before
  removal.
</Callout>

## Input/Output Examples

| Environment Variable Name | Scope  | Action Outcome                                          |
| ------------------------- | ------ | ------------------------------------------------------- |
| `TEMP`                    | User   | Removes user-specific temporary directory setting       |
| `PATH`                    | System | System path variable is deleted; may break applications |

## Common Mistakes & Troubleshooting

| Problem                                      | Solution                                                                                            |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Variable not deleted**                     | Ensure the correct scope (User/System) is selected. Check if you have the necessary permissions.    |
| **Accidentally deleted a critical variable** | Restore the variable manually by creating it in the system settings or contact IT support.          |
| **Node execution error**                     | Check that the selected variable exists in the current scope. Verify system permissions and rights. |

## Real-World Use Cases

- **Clean-up Automation**: Automatically remove obsolete environment variables after uninstalling software.
- **System Preparation**: Reset environment variables to default in preparation for new software installations.
- **User Profile Management**: Customize user environments by removing unnecessary user-specific variables.
