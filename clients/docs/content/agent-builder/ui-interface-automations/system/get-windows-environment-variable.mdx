# Get Windows Environment Variable

The **Get Windows Environment Variable** node allows you to retrieve the value of specific environment variables on your Windows desktop. Environment variables store system-related values such as the number of processors, the operating system version, or user-specific paths like OneDrive. This node is useful for automating tasks that depend on these system configurations.

For instance, you can retrieve the current user's username or find out where temporary files are stored.

## Configuration Options

| Field Name                            | Description                                                                   | Input Type | Required? | Default Value |
| ------------------------------------- | ----------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Environment Variable Name**         | The name of the environment variable to retrieve.                             | Select     | Yes       | USERNAME      |
| **Search for variable only in scope** | Indicates whether to search for the variable only within the specified scope. | Switch     | No        | _(empty)_     |
| **Scope**                             | Specifies the scope (User or System) for searching the environment variable.  | Select     | No        | User          |

## Expected Output Format

The output of the **Get Windows Environment Variable** node is a **string** value that represents the retrieved environment variable.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Get Windows Environment Variable** node into your flow.

### Step 2

In the **Environment Variable Name** dropdown, select the environment variable you wish to retrieve. Examples include "Number of Processors", "Operating System", "Path", etc.

### Step 3

If needed, toggle the **Search for variable only in scope** switch on to limit the search to a specific scope.

### Step 4

If the switch is enabled, choose the **Scope** from the dropdown (User or System) to define where to look for the variable.

### Step 5

The retrieved value will be available as **Environment Variable Value** for use in subsequent nodes.

</Steps>

<Callout type="info" title="Tip">
  The **Scope** option only appears if "Search for variable only in scope" is
  enabled.
</Callout>

## Input/Output Examples

| Environment Variable Name | Search in Scope | Scope  | Output Value         | Output Type |
| ------------------------- | --------------- | ------ | -------------------- | ----------- |
| USERNAME                  | No              | N/A    | johndoe              | String      |
| PATH                      | Yes             | User   | C:\Users\johndoe\bin | String      |
| OS                        | Yes             | System | Windows_NT           | String      |

## Common Mistakes & Troubleshooting

| Problem                  | Solution                                                                                                                                        |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Variable not found**   | Ensure the correct environment variable name is selected from the dropdown.                                                                     |
| **Scope not applicable** | The **Scope** field is active only when "Search for variable only in scope" is enabled. Verify this setting if you can't find the Scope option. |
| **Empty result**         | Check if the environment variable exists in the selected scope (User/System) or if it's enabled anymore.                                        |

## Real-World Use Cases

- **System Audits**: Retrieve information about the OS or processor architecture for auditing tasks.
- **Directory Setup**: Access system paths to dynamically set up directory-based operations in automation flows.
- **Custom User Scripts**: Use environment variables like the current user's directory for personalized script execution.
