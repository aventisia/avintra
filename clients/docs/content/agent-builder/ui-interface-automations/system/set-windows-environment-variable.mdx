# Set Windows Environment Variable

The **Set Windows Environment Variable** node allows you to change or assign a value to a specific environment variable on your Windows system. This is useful for configuring system and user-specific settings that many applications rely on, such as system paths or user preferences.

By setting environment variables, you can:

- Modify how applications interact with the system.
- Customize paths for temporary files or application directories.
- Adjust system-level settings for different user scenarios.

## Configuration Options

| Field Name                         | Description                                                                          | Input Type | Required? | Default Value |
| ---------------------------------- | ------------------------------------------------------------------------------------ | ---------- | --------- | ------------- |
| **Environment Variable Name**      | Select which environment variable you wish to modify.                                | Select     | Yes       | _(empty)_     |
| **New Environment Variable Value** | Specify the new value for the selected environment variable.                         | Text       | Yes       | _(empty)_     |
| **Type**                           | Choose whether to set the variable at the User level or System level (machine-wide). | Select     | No        | User          |

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Set Windows Environment Variable** node to your flow.

### Step 2

In the **Environment Variable Name** dropdown, choose the variable you want to set. Options include common variables like **Path**, **Username**, and **Operating System**.

### Step 3

Enter the desired value in the **New Environment Variable Value** field. This will be the new value assigned to your chosen environment variable.

### Step 4

Select the **Type** from the dropdown to specify if you want the change to affect the current user or the whole system. Default is set to User.

### Step 5

The updated environment variable can now be accessed by other system processes or tools.

</Steps>

<Callout type="info" title="Caution">
  Changes to system environment variables can affect applications globally. Use
  the "System" type only if necessary and you have appropriate permissions.
</Callout>

## Expected Output Format

This node does not produce a visible output as it operates by changing system settings. However, other nodes can access the updated environment variable values after this operation.

## Common Mistakes & Troubleshooting

| Problem                                            | Solution                                                                                           |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Environment variable no effect**                 | Ensure the correct variable is selected and the value is properly entered.                         |
| **Permissions error when setting System variable** | You may need administrative privileges to modify system-level environment variables.               |
| **Changes not recognized by applications**         | Restarting your application or logging off and back into Windows may be required to apply changes. |

## Real-World Use Cases

- **Custom Software Configuration**: Developers can use environment variables to switch between development and production configurations.
- **Adjust System Utilities**: Modify system path for specific utility tools involving file management or systems/tools monitoring.
- **User-Specific Settings**: Set user preferences for programs without directly altering application configurations files.
