# Write XML to File

The **Write XML to File** node is used to save XML data into a file on your computer. This is particularly useful for creating backups, logging information, or sharing data between systems.

For example:

- Save XML data received from another node to a file for record-keeping.
- Export custom XML configurations that you need to maintain outside the application.
- Generate XML files that other applications can read as input.

## Configuration Options

| Field Name                | Description                                                       | Input Type | Required? | Default Value |
| ------------------------- | ----------------------------------------------------------------- | ---------- | --------- | ------------- |
| **File Path**             | The path to the file where the XML will be written.               | Text       | Yes       | _(empty)_     |
| **XML To Write**          | The XML string to write into the file.                            | Text       | Yes       | _(empty)_     |
| **Encoding Type**         | The character encoding to use when writing the file.              | Select     | No        | SystemDefault |
| **Format XML**            | Whether to format (indent) the XML output for better readability. | Switch     | No        | _(empty)_     |
| **Indentation Per Level** | Number of spaces to use for indentation if formatting is enabled. | Text       | No        | _(empty)_     |

## Expected Output Format

This node writes an **XML file** with the specified data at the given file path.

- The output file will have XML content formatted based on your configuration (encoding and indentation).

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Write XML to File** node to your workflow.

### Step 2

In the **File Path** field, enter the complete path where you want the XML file to be saved (e.g., `C:\Documents\output.xml`).

### Step 3

Enter the XML content you want to write in the **XML To Write** field.

### Step 4

Select the desired **Encoding Type** from the dropdown menu. If unsure, leave it as the default (System Default).

- Options include UTF-8, UTF-16, ASCII, etc.

### Step 5

If you want formatted (indented) XML, toggle the **Format XML** switch to “On.”

### Step 6

If formatting is enabled, specify the **Indentation Per Level** with your preferred number of spaces. This will be used to indent each level of the XML structure.

</Steps>

<Callout type="info" title="Tip">
  Ensure that the file path you enter is accessible and that you have write
  permissions for the file location.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                          | Solution                                                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **File Not Saved**               | Double-check the file path for errors. Ensure it is a valid path and you have permissions to write to that directory.     |
| **Encoding Issues**              | If the file can't be read correctly, try changing the encoding type to match what your application expects (e.g., UTF-8). |
| **XML Formatting Doesn't Apply** | Make sure **Format XML** is enabled, and that you've specified an indentation value if required.                          |
| **File Path Is Incorrect**       | Verify that the path includes the file name and extension, e.g., `output.xml`.                                            |

## Real-World Use Cases

- **Data Backups**: Automatically save received XML data into files for backup.
- **Inter-application Communication**: Export XML data to share with other applications that require XML input.
- **Configuration Management**: Write out XML configurations for easy editing and version control outside the tool.
