# Read XML from File

The **Read XML from File** node is designed to load the contents of an XML file into a variable. This functionality is essential for situations where you want to process or analyze XML data stored in external files, such as configuration settings, data exports, or integration records.

## Configuration Options

| Field Name        | Description                                                  | Input Type | Required? | Default Value  |
| ----------------- | ------------------------------------------------------------ | ---------- | --------- | -------------- |
| **File Path**     | The location of the XML file you wish to read.               | Text       | Yes       | _(empty)_      |
| **Encoding Type** | The character encoding standard to use for reading the file. | Select     | No        | System Default |

## Expected Output Format

The node outputs an **XML Document Loaded** variable which is a parsed XmlDocument object. This can be used in subsequent nodes for data manipulation or extraction.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Read XML from File** node into your workspace.

### Step 2

In the **File Path** field, input the full path to your desired XML file.

### Step 3

If necessary, choose the **Encoding Type** from the dropdown menu according to the file's encoding needs:

- **System Default**: Utilizes your system's native encoding setting.
- **UTF-8**: Common encoding for a wide range of applications.
- **Unicode (UTF-16)**: If your XML file requires UTF-16 encoding.
- **Big Endian Unicode**: Use if the file is encoded in UTF-16 without a BOM.
- **UTF-8 (No BOM)**: For UTF-8 files without a Byte Order Mark.
- **ASCII**: For files with simple characters, limited to ASCII.

### Step 4

After setting the fields, the XML document will be read and loaded into the **XmlDocument** variable available for further processing.

</Steps>

<Callout type="info" title="Tip">
  If unsure, try using "System Default" for **Encoding Type** first. This option
  will automatically handle the typical scenarios for file reading.
</Callout>

## Input/Output Examples

| File Path           | Encoding Type | Output Variable | Output Type        |
| ------------------- | ------------- | --------------- | ------------------ |
| `/path/to/file.xml` | UTF-8         | XmlDocument     | XmlDocument Object |

## Common Mistakes & Troubleshooting

| Problem                         | Solution                                                                                   |
| ------------------------------- | ------------------------------------------------------------------------------------------ |
| **File Not Found Error**        | Ensure the **File Path** is correct and the file is accessible.                            |
| **Incorrect Encoding**          | Double-check the **Encoding Type** if you face issues with character display errors.       |
| **Failed to Load XML Document** | Ensure the XML file is not corrupted and is a valid XML format.                            |
| **Encoding Type Field Missing** | The field is optional. It will not appear if you do not select an alternate encoding type. |

## Real-World Use Cases

- **Configuration Management**: Use to read system settings from configuration XML files.
- **Data Integration**: Load and process XML data exported from different systems.
- **XML Data Analysis**: Import XML files containing data logs or reports for further analysis.
