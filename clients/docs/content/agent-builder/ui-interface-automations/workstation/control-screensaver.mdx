# Control Screensaver

The **Control Screensaver** node lets you manage your desktop screensaver settings directly from your automation flow. With this node, you can:

- Enable or disable the screensaver.
- Start or stop the screensaver immediately.

This node is useful if you want to automate screensaver behavior for instance, ensuring it starts or stops based on certain activities or time triggers.

## Configuration Options

| Field Name           | Description                                                                                | Input Type | Required? | Default Value |
| -------------------- | ------------------------------------------------------------------------------------------ | ---------- | --------- | ------------- |
| **Action**           | The action to take on the screensaver: Enable, Disable, Start, or Stop.                    | Select     | Yes       | _(empty)_     |
| **Time Out Seconds** | Specify the time in seconds before the screensaver activates. Only relevant when enabling. | Text       | No        | _(empty)_     |

## Expected Output Format

The output of this node indicates the success or failure of the requested action with a simple status message such as "Screensaver Enabled" or "Screensaver Start Failed".

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Control Screensaver** node into your flow.

### Step 2

In the **Action** dropdown menu, choose what you want to do with the screensaver:

- **Enable**: Turns on the screensaver function.
- **Disable**: Turns off the screensaver function.
- **Start**: Immediately begins the screensaver.
- **Stop**: Immediately stops the screensaver if running.

### Step 3

If you selected **Enable** for the action, you can optionally enter a value in **Time Out Seconds** to define the time before the screensaver activates.

### Step 4

Review your settings and proceed. The node will execute the chosen screensaver command.

</Steps>

<Callout type="info" title="Note">
  The **Time Out Seconds** field only applies when you want to set a timeout
  duration for enabling the screensaver.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                  | Solution                                                                                      |
| ---------------------------------------- | --------------------------------------------------------------------------------------------- |
| **Failed Action Execution**              | Ensure that your desktop environment supports screensaver commands.                           |
| **Unintended Screensaver Timeout**       | Double-check the **Time Out Seconds** value for accuracy. Avoid leaving it blank if required. |
| **No Reaction to Start or Stop Command** | Confirm screensaver settings on your desktop aren't locked or controlled by another policy.   |

## Real-World Use Cases

- **Office Automation**: Automatically start the screensaver when an employee leaves their workstation.
- **Security Compliance**: Disable screensaver during specific work hours to prevent disruptions.
- **Presentations**: Ensure screensaver does not interrupt during a presentation by disabling it temporarily.
