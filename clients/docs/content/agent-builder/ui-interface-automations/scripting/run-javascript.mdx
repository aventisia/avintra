# Run JavaScript

The **Run JavaScript** node enables you to write and execute custom JavaScript code within your process. This is particularly useful when you need to perform calculations, manipulate data, or apply logic that isn't directly available through standard nodes.

You might use the Run JavaScript node for:

- Executing complex calculations.
- Transforming data according to specific rules.
- Integrating logic that reacts dynamically based on input values.

## Configuration Options

| Field Name          | Description                       | Input Type | Required? | Default Value |
| ------------------- | --------------------------------- | ---------- | --------- | ------------- |
| **JavaScript Code** | The JavaScript code to execute.   | Text       | Yes       | _(empty)_     |
| **Script Output**   | Returns the output of the script. | Text       | No        | ScriptOutput  |

## Expected Output Format

The output of this node is dependent on the script you provide. It will be in the data type and format generated by the executed JavaScript code.

- Output could be a number, text, object, array, or any valid JavaScript datatype based on your script.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Run JavaScript** node into your flow.

### Step 2

In the **JavaScript Code** field, enter the script you want to run. Ensure it's valid JavaScript syntax.

### Step 3

Connect nodes as needed to supply any input variables your script may require.

### Step 4

After execution, the result or output of your script will be available under **ScriptOutput** for use in further processing or nodes.

</Steps>

<Callout type="warning" title="Warning">
  Ensure that your JavaScript code does not contain any syntax errors or
  unsupported operations. Such errors may cause the node to fail or produce
  unexpected results.
</Callout>

## Input/Output Examples

| JavaScript Code            | Output Example     | Output Type      |
| -------------------------- | ------------------ | ---------------- |
| `return 5 + 3;`            | 8                  | Number (Integer) |
| `return 'Hello, ' + name;` | 'Hello, John'      | String           |
| `return { key: 'value' };` | `{ key: 'value' }` | Object           |

## Common Mistakes & Troubleshooting

| Problem                      | Solution                                                                                             |
| ---------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Unclear script output**    | Review your script for correct logic and use `console.log` for debugging within the platform tools.  |
| **Script does not execute**  | Ensure there are no syntax errors in your JavaScript code. Check for missing brackets or semicolons. |
| **Unexpected output format** | Validate that your script is returning the output in the format you expect (e.g., number, string).   |

## Real-World Use Cases

- **Automating Calculations**: Perform compound interest calculations based on user input values.
- **Dynamic Data Transformation**: Format dates, currencies, or strings dynamically as needed by your business logic.
- **Complex Business Logic**: Implement specific business rules, such as tiered pricing or customer feedback aggregation.
