# Get Temporary File

The **Get Temporary File** node allows you to create an empty temporary file that is uniquely named on your computer's disk. This is useful when you need a temporary space to store data that will not persist permanently, such as when processing files temporarily before a task is complete.

To elaborate:

- Create a short-lived storage file for temporary data processing.
- Ensure file names are unique to prevent any overwriting or conflicts.

## Configuration Options

| Field Name         | Description                                                          | Input Type | Required? | Default Value |
| ------------------ | -------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Temporary File** | The FileInfo object representing the temporary file created on disk. | Output     | No        | TempFile      |

## Expected Output Format

The output of this node is a **FileInfo object**, representing the temporary file created. This is expected to include:

- File path: The full path to the temporary file on disk.
- File name: The name of the temporary file, unique to prevent conflicts.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Get Temporary File** node into your flow.

### Step 2

This node automatically creates a temporary file. No additional input configuration is required.

### Step 3

The generated temporary file's information will be available as **TempFile** and can be used in other nodes for further processing.

</Steps>

<Callout type="info" title="Note">
  The **temporary file** created by this node is not meant to be permanent. It
  is ideal for short-term usage within the flow and may be automatically deleted
  after the process is complete or upon application closure.
</Callout>

## Input/Output Examples

| Description         | Output Value  | Output Type          |
| ------------------- | ------------- | -------------------- |
| Temporary file path | `/tmp/tmp123` | FileInfo (File Path) |
| Temporary file name | `tmp123`      | FileInfo (File Name) |

## Common Mistakes & Troubleshooting

| Problem                            | Solution                                                                                                                   |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **File not found error**           | Ensure the temporary file is being used immediately after creation, as it may be deleted post-operation or upon app close. |
| **Output not connecting properly** | Verify that the **TempFile** output is properly routed to subsequent nodes requiring a file.                               |

## Real-World Use Cases

- **Data Processing**: Use a temporary file to store data briefly as it is modified or transformed by other nodes.
- **Temporary Document Storage**: Create temporary documents during dynamic report generation, which are later finalized or deleted.
- **Batch Processing**: Store intermediary results temporarily in a flow processing batches of data or files.
