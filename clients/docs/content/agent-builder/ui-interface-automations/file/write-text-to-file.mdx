# Write Text to File

The **Write Text to File** node allows you to save textual information to a specific file on your desktop. You can choose to either add the new text to the end of a file or replace the entire content of that file with the new text. This node is particularly useful for tasks that involve updating reports, logs, or documents with new information dynamically.

## Configuration Options

| Field Name        | Description                                                    | Input Type | Required? | Default Value |
| ----------------- | -------------------------------------------------------------- | ---------- | --------- | ------------- |
| **File Path**     | The full file path where the text should be written.           | Text       | Yes       | _(empty)_     |
| **Text to Write** | The text content you want to save into the file.               | Text       | Yes       | _(empty)_     |
| **Write Mode**    | Specifies how the text should be written: Append or Overwrite. | Select     | No        | Append        |

## Expected Output Format

There is no direct output from this node. Instead, it performs the action of writing the specified text to a file at the given path.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Write Text to File** node into your flow.

### Step 2

In the **File Path** field, enter the full file path where you want the text to be saved. Ensure it includes the file name and extension (e.g., `C:\Documents\example.txt`).

### Step 3

In the **Text to Write** field, type or paste the content you wish to save to the file.

### Step 4

Select your preferred option from the **Write Mode** dropdown:

- **Append**: Adds the new text to the end of the file.
- **Overwrite**: Replaces everything in the file with the new text.

### Step 5

Run the node to write the text to the specified file path.

</Steps>

<Callout type="warning" title="Warning">
  Ensure the file path is correct and accessible. Mistakes in the path can cause
  the file operation to fail.
</Callout>

## Input/Output Examples

| File Path                | Text to Write  | Write Mode         | Result                                                                 |
| ------------------------ | -------------- | ------------------ | ---------------------------------------------------------------------- |
| `C:\Documents\log.txt`   | "New entry"    | Append             | Adds "New entry" to the end of `log.txt`.                              |
| `C:\Reports\summary.txt` | "Final report" | Overwrite          | Replaces all content in `summary.txt` with "Final report".             |
| `D:\Backups\notes.txt`   | "Backup data"  | _(default)_ Append | Adds "Backup data" to the file `notes.txt`, as append mode is default. |

## Common Mistakes & Troubleshooting

| Problem                        | Solution                                                              |
| ------------------------------ | --------------------------------------------------------------------- |
| **Incorrect file path format** | Double-check the path and file extension to ensure accuracy.          |
| **Text not saving properly**   | Check that the **Write Mode** is set correctly and the path is valid. |
| **Access denied error**        | Ensure that you have permission to write to the specified location.   |

## Real-World Use Cases

- **Log File Updates**: Keep appending new log entries to an existing log file for tracking actions over time.
- **Dynamic Content Updates**: Overwrite template files with dynamic content for report generation or document updates.
- **Backup Management**: Append backup notifications or details to a centralized log or summary file.
