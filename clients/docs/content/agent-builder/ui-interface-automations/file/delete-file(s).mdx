# Delete File(s)

The **Delete File(s)** node is designed to help you clean up your local storage by removing one or more files from your system. It is especially useful for automating the deletion of temporary or obsolete files without manual intervention. You can specify exact file paths or use wildcards for multiple file types, simplifying file management processes and helping maintain a clutter-free digital workspace.

## Configuration Options

| Field Name            | Description                                                                             | Input Type | Required? | Default Value |
| --------------------- | --------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **File(s) to delete** | The path(s) of the file(s) you want to delete. You can also use wildcards like `*.txt`. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **confirmation of file deletion** which indicates whether the designated files have been successfully removed. This is typically a success notice or an error message if the files weren't found or couldn't be deleted.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Delete File(s)** node into your flow.

### Step 2

In the **File(s) to delete** field, enter the full path(s) of the file(s) you wish to delete.

- For specific files, write their full path: `C:\Users\Example\file1.txt`.
- To delete multiple files of the same type, use a wildcard: `C:\Users\Example\*.txt` to remove all `.txt` files in that directory.

### Step 3

Ensure the file paths are correct and accessible by checking permissions and path accuracy to avoid errors.

### Step 4

Execute the process to delete the specified files. Confirmation of deletion will be returned.

</Steps>

<Callout type="warning" title="Caution">
  Ensure you double-check the paths entered for deletion to avoid accidentally
  removing important files.
</Callout>

## Input/Output Examples

| Input File Paths            | Output                            |
| --------------------------- | --------------------------------- |
| `C:\Users\Example\temp.txt` | File deleted successfully.        |
| `C:\Users\Example\*.log`    | 5 files matching `*.log` deleted. |

## Common Mistakes & Troubleshooting

| Problem                                  | Solution                                                                                            |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Path not found or incorrect**          | Verify you have entered the correct file path and that the file exists in that location.            |
| **Permission denied error**              | Ensure you have the necessary permissions to delete the file(s) in the specified directory.         |
| **Wildcard not functioning as expected** | Check for mistakes in the wildcard syntax and ensure the path is pointing to the correct directory. |

## Real-World Use Cases

- **Log Management**: Automatically delete old log files (\*.log) that are no longer needed to save storage space.
- **Cleanup Processes**: Remove temporary files generated by software to keep your computer tidy and efficient.
- **File Maintenance**: Regularly clear out files in a download folder to manage disk space effectively.
