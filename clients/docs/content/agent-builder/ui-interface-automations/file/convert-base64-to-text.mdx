# Convert Base64 to Text

The **Convert Base64 to Text** node is designed to decode a Base64-encoded string, transforming it back into its original plain text format. This is particularly useful when dealing with data that has been encoded for storage or transmission. Use this node whenever you encounter Base64 data that needs to be read in a human-friendly format.

## Configuration Options

| Field Name        | Description                                   | Input Type | Required? | Default Value |
| ----------------- | --------------------------------------------- | ---------- | --------- | ------------- |
| **Base64 String** | The Base64-encoded string you wish to decode. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **plain text string** converted from the Base64 input. The format will be readable, standard text without any encoding.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Convert Base64 to Text** node to your flow.

### Step 2

In the **Base64 String** field, input the encoded string you want to convert to plain text.

### Step 3

The decoded text will be available as **PlainText** for use in subsequent nodes.

</Steps>

<Callout type="warning" title="Ensure Valid Input">
  Make sure that the string entered in the **Base64 String** field is correctly
  Base64-encoded. Any invalid input may result in errors.
</Callout>

## Input/Output Examples

| Example Input (Base64 String) | Example Output (Plain Text) |
| ----------------------------- | --------------------------- |
| SGVsbG8sIFdvcmxkIQ==          | Hello, World!               |
| U29sdXRpb24=                  | Solution                    |

## Common Mistakes & Troubleshooting

| Problem                       | Solution                                                                                                       |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Invalid Base64 Input**      | Double-check the input string for proper Base64 encoding. Ensure there are no stray characters or symbols.     |
| **Blank Output**              | Ensure that the **Base64 String** field is not empty and contains a valid Base64 string.                       |
| **Unrecognizable Characters** | This may indicate an encoding issue. Verify that the text was originally encoded using Base64 before decoding. |

## Real-World Use Cases

- **File Data Recovery**: Decode Base64 data for files automatically transmitted or stored in encoded format.
- **Email Processing**: Convert encoded email attachments or parts to plain text for easier reading and analysis.
- **Data Processing**: Simplify analysis and processing by converting Base64 data common in web APIs back to original format.
