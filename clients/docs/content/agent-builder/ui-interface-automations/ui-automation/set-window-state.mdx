# Set Window State

The **Set Window State** node allows you to control the appearance of a window on your desktop by setting it to either a normal, maximized, or minimized state. This functionality is helpful when you want to manage your workspace efficiently, ensuring windows are sized and positioned according to your needs.

For example:

- Opening an application in a full screen for better visibility.
- Minimizing distractions by minimizing unused windows.
- Bringing a window back to its normal size to view multiple windows simultaneously.

## Configuration Options

| Field Name                               | Description                                                              | Input Type | Required? | Default Value        |
| ---------------------------------------- | ------------------------------------------------------------------------ | ---------- | --------- | -------------------- |
| **Window**                               | Select the window you want to change.                                    | Text       | Yes       | _(empty)_            |
| **Window State**                         | Choose how you want the window to appear (Normal, Maximized, Minimized). | Select     | Yes       | Normal               |
| **Is Window State Changed Successfully** | Indicates whether the window state was changed successfully.             | Output     | No        | IsWindowStateChanged |

## Expected Output Format

The output of this node is an **indicator of success**. This means it will inform you if the window state has changed successfully, rather than providing a numeric or textual result.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Set Window State** node into your flow.

### Step 2

In the **Window** field, specify the window you want to adjust. This can be the title or the identifier of the window.

### Step 3

Select the desired state for the window from the **Window State** dropdown:

- **Normal**: Restores the window to its default size and position.
- **Maximized**: Expands the window to fill the screen.
- **Minimized**: Reduces the window to the taskbar or dock.

### Step 4

The node will automatically execute the change. The result can be verified by the **Is Window State Changed Successfully** output.

</Steps>

<Callout type="info" title="Tip">
  Ensure you select the correct window name in the **Window** field to avoid
  changing the wrong window's state.
</Callout>

## Input/Output Examples

| Window  | Window State | Is Window State Changed Successfully | Description                                     |
| ------- | ------------ | ------------------------------------ | ----------------------------------------------- |
| Browser | Maximized    | True                                 | The browser window was successfully maximized.  |
| Editor  | Minimized    | True                                 | The editor window was successfully minimized.   |
| Player  | Normal       | True                                 | The media player window was restored to normal. |

## Common Mistakes & Troubleshooting

| Problem                             | Solution                                                                                                      |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Incorrect Window Name**           | Ensure you entered the correct window identifier or title in the **Window** field to target the right window. |
| **Window Not Visible After Change** | After minimizing, you can restore the window from the taskbar or dock if it disappears from view.             |
| **Output Indicator Always False**   | Double-check your window and state selections to ensure they are correctly set before executing the change.   |

## Real-World Use Cases

- **Presentation Setup**: Maximize a presentation window before starting a meeting for better visibility.
- **Workflow Optimization**: Minimize chats or notifications to reduce interruptions while working.
- **Screen Management**: Quickly adjust multiple application windows to normal state for side-by-side comparison.
