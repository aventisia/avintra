# Populate Text Field in Window

The **Populate Text Field in Window** node allows you to automatically fill a text box or an editable field within a desktop application window. This is especially helpful when you need to automate repetitive data entry tasks, such as filling out forms or entering predefined data into software applications.

For example:

- Entering a username or password into a login prompt automatically.
- Populating a search field with specific terms.
- Filling out forms with recurring information, minimizing manual input.

## Configuration Options

| Field Name                  | Description                                                                       | Input Type | Required? | Default Value |
| --------------------------- | --------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **UI Element**              | The UI element for the text box or editable field you want to fill.               | Text       | Yes       | _(empty)_     |
| **Text to Enter**           | The text that you wish to input into the specified field.                         | Text       | Yes       | _(empty)_     |
| **Fill Method**             | Choose either to type, paste, or set the text directly into the field.            | Select     | No        | Typing        |
| **Max Wait Time (seconds)** | The maximum duration to wait for the UI element to become available (in seconds). | Text       | No        | 5             |

## Expected Output Format

The output of this node is a **boolean value** indicating whether the text was filled successfully, known as **IsTextFilled**.

- The value will be `true` if the text entry is successful.
- The value will be `false` if the text could not be entered due to an error or timeout.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Populate Text Field in Window** node into your automation flow.

### Step 2

In the **UI Element** field, specify the identifier for the text box or field you wish to fill. Make sure it precisely locates the correct field on the target window.

### Step 3

Enter the desired content in the **Text to Enter** field. This is the text that will appear in the UI element.

### Step 4

Choose a **Fill Method** option:

- **Type**: Physically types each character into the field.
- **Paste**: Pastes the full text as if using a clipboard.
- **Set Value**: Directly sets the value of the field, if the technology allows.

### Step 5

Specify the **Max Wait Time (seconds)** if required. This defines how long to wait for the UI element to be ready. The default is 5 seconds.

### Step 6

Once setup, the node will attempt to fill the text field, and the result will be available as **IsTextFilled**.

</Steps>

<Callout type="tip" title="Note">
  If you're not sure which Fill Method to use, start with "Type" for more
  compatibility across different applications.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                                    | Solution                                                                                                                                                   |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Field not found error despite correct UI Element input** | Check if the application's window is active and visible. The tool may not locate hidden elements.                                                          |
| **Unexpected failure of text input**                       | Ensure that the field selector correctly targets editable fields. Test alternative Fill Method options for compatibility.                                  |
| **Timeout before locating UI element**                     | Increase the **Max Wait Time** to provide additional time for the application to load or respond, especially on systems with high latency or resource use. |

- **Repeatable Data Entry Tasks**: Populating insurance forms, survey fields, or customer information forms with ease.
