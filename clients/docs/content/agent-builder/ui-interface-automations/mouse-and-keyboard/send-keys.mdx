# Send Keys

The **Send Keys** node is designed to automate keyboard input by sending text or key commands to a specified target on your desktop. This is particularly helpful when you need to automate data entry tasks, control applications, or simulate user input in different applications seamlessly.

Common scenarios include:

- Entering data into application forms automatically.
- Triggering keyboard shortcuts in automation workflows.
- Simulating user interactions for testing and validation.

## Configuration Options

| Field Name                     | Description                                                                                          | Input Type | Required? | Default Value |
| ------------------------------ | ---------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Send Keys To**               | Destination target for the keys (e.g., active window, specific elements, or windows by title/class). | Select     | Yes       | _(empty)_     |
| **UI Element**                 | The specific UI element where keys should be sent. Appears if target is selected as "UI element."    | Text       | No        | _(empty)_     |
| **Window Handle**              | The unique handle of the window for sending keys. Applicable if target is "Window instance/handle."  | Text       | No        | _(empty)_     |
| **Window Title**               | The title of the window to target keys. Relevant when "Title and/or class" is chosen as target.      | Text       | No        | _(empty)_     |
| **Window Class**               | The class name of the window used for sending keys if "Title and/or class" is selected.              | Text       | No        | _(empty)_     |
| **Text to Send**               | The actual text or special keys (e.g., shortcuts) to be sent to the target.                          | Text       | Yes       | _(empty)_     |
| **Delay Between Keystrokes**   | Time in milliseconds to pause between each keystroke for smoother operation.                         | Text       | No        | 0             |
| **Send Text as Hardware Keys** | Switch for sending keys as hardware inputs rather than virtual key codes.                            | Switch     | No        | false         |

## Expected Output Format

This node does not produce a typical output in terms of data return. Instead, its effect is seen in the action it performs on the designated target (e.g., entered text or executed keyboard shortcut).

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Send Keys** node into your flow.

### Step 2

In the **Send Keys To** dropdown, select where you want to send the keys:

- **Foreground window**: Targets the currently active window.
- **UI element**: Requires specifying the UI element in the next step.
- **Window instance/handle**: Provide the window handle in the corresponding field.
- **Title and/or class**: Supply the window title and/or class name as needed.

### Step 3

If you've selected **UI element**, **Window instance/handle**, or **Title and/or class**, fill in the relevant fields (e.g., **UI Element**, **Window Handle**, **Window Title**, **Window Class**).

### Step 4

Enter the specific text or keys you wish to send in the **Text to Send** field.

### Step 5

Optionally, specify any **Delay Between Keystrokes** in milliseconds to control the pace of sending.

### Step 6

Toggle **Send Text as Hardware Keys** on or off based on whether you need hardware key simulation.

### Step 7

Save the configuration and activate the process. The text will be sent to the specified target upon execution.

</Steps>

<Callout type="info" title="Tip">
  Use the **Delay Between Keystrokes** to avoid overwhelming applications with
  fast keystrokes, which might cause input errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                   | Solution                                                                                                    |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Keys sent to wrong window**             | Ensure the correct target is selected, and application windows are active or accessible.                    |
| **Unexpected characters entered**         | Check for any additional spaces or incorrect special keys specified in **Text to Send**.                    |
| **No text appearing in the target field** | Confirm that any required window fields such as **UI Element** or **Window Title** are correctly specified. |
| **Delay not functioning as intended**     | Verify the delay is set correctly in milliseconds; using very small delays may not be visibly effective.    |

## Real-World Use Cases

- **Customer Support Automation**: Automate the entry of customer information into CRM systems.
- **Software Testing**: Simulate user input to test form processing or shortcut operation in applications.
- **Documentation and Reporting**: Quickly fill templates by sending repetitive text patterns to word processors or email clients.
