# Move Mouse to Image

The **Move Mouse to Image** node helps you automate the mouse cursor movement by locating an image on your screen and moving the cursor to its center. This node is particularly useful for automating repetitive tasks where manual mouse movement to specific screen elements (represented by images) is required, such as clicking buttons or opening files.

For example, you might want to:

- Navigate automatically to a button by matching its image rather than manual searching.
- Ensure that the cursor is moved to a specific image element when performing a presentation or demonstration.

## Configuration Options

| Field Name                          | Description                                                                                       | Input Type | Required? | Default Value |
| ----------------------------------- | ------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Image to Move Mouse To**          | The path to the image file to locate.                                                             | Text       | Yes       | _(empty)_     |
| **Similarity Threshold**            | The similarity threshold for image matching (0.0 to 1.0).                                         | Text       | No        | 0.9           |
| **Search Area**                     | The search area specified by coordinates (Left, Top, Right, Bottom). Leave empty for full screen. | Text       | No        | _(empty)_     |
| **Mouse Movement Style**            | Specifies how the mouse should move to the target position.                                       | Select     | No        | Instant       |
| **Occurrence**                      | Which occurrence of the image to find (1-based index).                                            | Text       | No        | 1             |
| **Send a Click After Moving Mouse** | If enabled, sends a click after moving the mouse cursor.                                          | Switch     | No        | _(empty)_     |
| **Click Type**                      | Type of click to perform after moving the mouse.                                                  | Select     | No        | LeftClick     |
| **Wait for Image to Appear**        | If enabled, waits for the image to become visible before moving the mouse.                        | Switch     | No        | _(empty)_     |
| **Fail Timeout**                    | Maximum time (in seconds) to wait for the image to appear.                                        | Text       | No        | 5             |
| **Offset X**                        | Horizontal offset from the center of the image.                                                   | Text       | No        | 0             |
| **Offset Y**                        | Vertical offset from the center of the image.                                                     | Text       | No        | 0             |
| **Tolerance**                       | Tolerance level for image matching (as a percentage from 0 to 100).                               | Text       | No        | 10            |
| **Search Mode**                     | Specifies if the search is on the entire screen or a subregion.                                   | Select     | No        | EntireScreen  |
| **Search Subregion**                | Coordinates of the subregion to search (X1, Y1, X2, Y2). Only used if Search Mode is "Subregion". | Text       | No        | _(empty)_     |

## Expected Output Format

The output of this node consists of:

- **Is Found**: A boolean value (`true` or `false`) indicating if the image was found and the mouse was moved.
- **Found Position**: The position (X, Y coordinates) where the image was located.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Move Mouse to Image** node into your flow.

### Step 2

In the **Image to Move Mouse To** field, enter the path to the image file that you want the mouse to move to.

### Step 3

Optionally, adjust the **Similarity Threshold** to modify how exact the image match needs to be.

### Step 4

If desired, define a **Search Area** to limit the screen region where the image will be searched. Leave empty for a full-screen search.

### Step 5

Choose a **Mouse Movement Style** to dictate how the mouse travels to the image's center:

- **Instant**: Moves the mouse immediately.
- **With Animation**: Available with low, normal, and high-speed animation options.

### Step 6

If you're searching for the image more than once, set the **Occurrence** field to specify which instance of the image to target.

### Step 7

Enable **Send a Click After Moving Mouse** if you want to press the mouse button after reaching the image.

### Step 8

Choose a **Click Type** from the dropdown if you enabled the click option.

### Step 9

Activate **Wait for Image to Appear** and set a **Fail Timeout** if the image might not be immediately present.

### Step 10

Set **Offset X** and **Offset Y** if you need to adjust where the mouse lands relative to the image's center.

### Step 11

Adjust **Tolerance** to manage how lenient the system is with image matches.

### Step 12

Decide on a **Search Mode** and fill out **Search Subregion** if you're focusing on a specific screen area.

</Steps>

<Callout type="warning" title="Important Note">
  Ensure the image's path is accessible and matches expected file format
  requirements.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                            | Solution                                                                                                              |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Image not being found**          | Check if the image path is correct and visible on the screen. Increase Similarity Threshold or change the clock type. |
| **Mouse doesn't move as expected** | Ensure the image is in a visible area of the current screen or adjust the Search Region/Mode settings.                |
| **Unexpected click behavior**      | Verify that **Send a Click After Moving Mouse** and the correct **Click Type** have been selected.                    |

## Real-World Use Cases

- **Presentation Setup**: Automatically navigate to key presentation elements without manual mouse usage.
- **Game Automation**: Quickly locate in-game items or buttons for repetitive actions.
