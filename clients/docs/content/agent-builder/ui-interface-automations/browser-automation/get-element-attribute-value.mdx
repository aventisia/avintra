# Get Element Attribute Value

The **Get Element Attribute Value** node allows you to extract the attribute value of a specified element on a webpage. This is particularly useful when you need to interact with web elements programmatically and require specific data, such as getting an image source, link, or other HTML element attributes for further processing.

## Configuration Options

| Field Name               | Description                                                                        | Input Type | Required? | Default Value |
| ------------------------ | ---------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Web Browser Instance** | The existing web browser instance (e.g., IWebDriver) to interact with.             | Text       | Yes       | _(empty)_     |
| **Find Type**            | Specifies how to find the element (e.g., ID, XPath, CssSelector).                  | Select     | Yes       | XPath         |
| **Value To Find**        | The value used to locate the element (e.g., 'username', '//input[@id='email']').   | Text       | Yes       | _(empty)_     |
| **Attribute Name**       | The name of the attribute whose value should be retrieved (e.g., 'value', 'href'). | Text       | Yes       | _(empty)_     |
| **Wait For Element**     | If true, waits for the element to appear before retrieving the attribute value.    | Switch     | No        | _(empty)_     |
| **Timeout Seconds**      | Maximum time in seconds to wait for the element before failing.                    | Text       | No        | 60            |

## Expected Output Format

The result of the node is the **value of the specified attribute** as a text. It will be available under the name **Result** for use in subsequent nodes.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Get Element Attribute Value** node into your process flow.

### Step 2

Enter the existing **Web Browser Instance** that you want to use for extracting the attribute.

### Step 3

Select **Find Type** from the dropdown menu. This option defines how the element will be located on the webpage. Choose from options such as:

- **XPath**: Use an XPath expression.
- **Id**: Use the element's ID.
- **Css Selector**: Use a CSS selector.
- ... [additional options in the dropdown]

### Step 4

In **Value To Find**, input the value based on your selected Find Type, e.g., an ID name like `username` or an XPath like `//input[@id='email']`.

### Step 5

Specify the **Attribute Name** you wish to retrieve, such as `href`, `src`, `value`, depending on your needs.

### Step 6

(optional) Enable **Wait For Element** if you want to delay the process until the element appears on the page.

### Step 7

Enter the **Timeout Seconds** you wish to wait before the operation times out. If not specified, the default is 60 seconds.

### Step 8

The attribute value will be output as **Result** and can be used for further operations within your workflow.

</Steps>

<Callout type="info" title="Tip">
  Enabling "Wait For Element" can be particularly useful when dealing with
  dynamic content that takes time to load.
</Callout>

## Input/Output Examples

| Find Type   | Value To Find       | Attribute Name | Result Example                 |
| ----------- | ------------------- | -------------- | ------------------------------ |
| XPath       | `//img[@id='logo']` | `src`          | `https://example.com/logo.png` |
| Id          | `submitBtn`         | `class`        | `btn btn-primary`              |
| CssSelector | `.nav-link.active`  | `href`         | `/home`                        |

## Common Mistakes & Troubleshooting

| Problem                                           | Solution                                                                                                                       |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Element cannot be found**                       | Double-check the **Find Type** and **Value To Find** for correctness and ensure they refer to an existing element on the page. |
| **Attribute value is empty (or not as expected)** | Ensure the **Attribute Name** is spelled correctly and matches exactly as used in the HTML document.                           |
| **Timeout error**                                 | Check your internet connection, and ensure there's enough time set in **Timeout Seconds** for content-heavy pages to load.     |

## Real-World Use Cases

- **Dynamic Web Scraping**: Accessing and collecting image URLs, link paths, and button states from dynamically loaded web content.
- **Form Data Extraction**: Retrieve attribute data such as placeholders, values, and labels for automated form processing.
- **Content Validation**: Verify that certain attributes like `class` or `src` match criteria on webpage load to ensure webpage integrity.
