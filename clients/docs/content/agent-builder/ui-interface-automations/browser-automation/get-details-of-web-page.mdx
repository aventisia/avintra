# Get Details of Web Page

The **Get Details of Web Page** node enables you to retrieve specific information from a web page, such as the title, description, URL, source code, and more. This can be particularly useful for tasks like data extraction, web scraping, or simply obtaining web page metadata for further analysis.

For example:

- Extracting a page's title and description for SEO analysis.
- Retrieving visible text content for content analysis.
- Getting the current URL to verify navigation.

## Configuration Options

| Field Name               | Description                                                                       | Input Type | Required? | Default Value |
| ------------------------ | --------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Web Browser Instance** | Enter or choose the variable that contains the web browser instance to work with. | Text       | Yes       | _(empty)_     |
| **Detail Type**          | Specifies which detail to retrieve from the web page.                             | Select     | Yes       | WebPageTitle  |

## Expected Output Format

The output of this node is the **specific web page information** you selected, provided as a text string.

- If retrieving the title: a plain text string (e.g., "Welcome to My Site").
- If retrieving the description or metadata: a short text or multiple strings (e.g., "This is a tech blog.").
- If retrieving the source code: a large string of HTML content.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Get Details of Web Page** node into your flow.

### Step 2

In the **Web Browser Instance** field, provide the variable that identifies the specific web browser instance you're working with.

### Step 3

In the **Detail Type** dropdown, select the type of detail you wish to retrieve:

- **Web Page Description**: Gets the meta description of the web page.
- **Web Page Meta Keywords**: Obtains the meta keywords.
- **Web Page Title**: Retrieves the web page's title.
- **Web Page Text**: Extracts the visible text content.
- **Web Page Source**: Acquires the full HTML source.
- **Current URL Address**: Gets the current browser URL.

### Step 4

The retrieved detail will be available as **OWebPagePropertyOutput** which can be used in further nodes or processes.

</Steps>

<Callout type="info" title="Tip">
  Always make sure your web browser instance is active and correctly referenced
  when using this node to avoid errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                 | Solution                                                                     |
| --------------------------------------- | ---------------------------------------------------------------------------- |
| **Web Browser Instance not recognized** | Ensure that the instance variable is correctly set and active.               |
| **No Detail Returned**                  | Check if the correct "Detail Type" is selected.                              |
| **Fetching Data Results in Error**      | Verify the web page is accessible and the browser instance is valid for use. |

## Real-World Use Cases

- **SEO Auditing**: Collect page titles and meta descriptions for analysis.
- **Content Scraping**: Gather visible text from pages for research purposes.
- **Web Navigation Tracking**: Retrieve URLs to confirm correct page loading.
- **HTML Analysis**: Obtain full page source code for debugging or development.
