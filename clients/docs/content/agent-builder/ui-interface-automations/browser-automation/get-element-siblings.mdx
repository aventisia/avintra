# Get Element Siblings

The **Get Element Siblings** node is designed to help you find and list all sibling elements of a specified web element. This can be particularly useful when you need to process or analyze elements that are at the same hierarchical level within a web document, such as siblings under the same parent tag.

For example, you might want to list all buttons within the same container to ensure consistent styling or behavior attributes.

## Configuration Options

| Field Name               | Description                                                                       | Input Type | Required? | Default Value |
| ------------------------ | --------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Web Browser Instance** | Enter or choose the variable that contains the web browser instance to work with. | Text       | Yes       | _(empty)_     |
| **Find Type**            | Specifies how to find the element (e.g., ID, XPath, CssSelector).                 | Select     | Yes       | XPath         |
| **Value To Find**        | The value used to locate the element (e.g., 'username', '//input[@id='email']').  | Text       | Yes       | _(empty)_     |
| **Wait For Element**     | If true, waits for the element to appear before retrieving its siblings.          | Switch     | No        | _(empty)_     |
| **Timeout Seconds**      | Maximum time in seconds to wait for the element before failing.                   | Text       | No        | 60            |

## Expected Output Format

The output of this node is a **collection of web elements**, specifically the siblings of the located element.

- The output is represented as `SiblingElements`, which provides access to each sibling element for further processing or interaction.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Get Element Siblings** node into your flow.

### Step 2

In the **Web Browser Instance** field, enter the variable name of the web browser instance.

### Step 3

From the **Find Type** dropdown, choose how you wish to locate the element, such as using XPath, ID, or Css Selector.

### Step 4

In the **Value To Find** field, input the specific identifier or expression that corresponds to the element you are looking for.

### Step 5

(Optional) Switch on **Wait For Element** if you want the node to wait for the specified element to appear before retrieving the siblings.

### Step 6

(Optional) Adjust **Timeout Seconds** if you need to set a different maximum wait time for the element to be found.

### Step 7

The sibling elements will be available for use under **SiblingElements** for further actions in your workflow.

</Steps>

<Callout type="info" title="Tip">
  Use **Wait For Element** when dealing with dynamic content where the targeted
  elements might take some time to load.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                        | Solution                                                                                                                                        |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **No elements found**                          | Ensure the correct Find Type and Value To Find are selected and correctly inputted.                                                             |
| **Wait Timer expired without finding element** | Increase **Timeout Seconds** or make sure the **Web Browser Instance** is properly initialized before this node attempts to locate the element. |
| **Misidentified elements**                     | Validate the **Find Type** and detailed **Value To Find** for potential mismatches or errors.                                                   |

## Real-World Use Cases

- **UI Testing**: Quickly gather properties of sibling elements to verify uniformity across similar UI components.
- **Web Scraping**: Extract sibling data points from structured web content to analyze data sets.
- **Automation of Repetitive Tasks**: Identify and interact with sets of sibling buttons or links for bulk actions.
