# If Web Page Contains

The **If Web Page Contains** node checks if a specific element or text exists on a web page. You can use this to verify the presence or absence of elements or text, and optionally check if an element is enabled or disabled. This node is helpful for validating web page content and ensuring that necessary elements or information are accessible during automation processes.

You might use this node to:

- Confirm a button or label is present before interacting with it.
- Ensure a specific error message or text appears on a web page.
- Validate that dynamic elements load correctly on a page.

## Configuration Options

| Field Name                 | Description                                                                       | Input Type | Required? | Default Value   |
| -------------------------- | --------------------------------------------------------------------------------- | ---------- | --------- | --------------- |
| **Web Browser Instance**   | Enter or choose the variable that contains the web browser instance to work with. | Text       | Yes       | _(empty)_       |
| **Check Condition**        | Specifies what condition to check, such as if an element or text is contained.    | Select     | Yes       | ContainsElement |
| **Find Type**              | Specifies how to locate the element (e.g., ID, XPath, CSS Selector).              | Select     | No        | XPath           |
| **Value To Find**          | The value used to locate the element (e.g., 'username', '//input[@id='email']').  | Text       | No        | _(empty)_       |
| **Check UI Element State** | If true, checks if the found element is enabled or disabled.                      | Switch     | No        | False           |
| **State**                  | Specifies the expected state of the element (enabled or disabled).                | Select     | No        | Enabled         |
| **Text To Search**         | The text to search for in the web page body or title.                             | Text       | No        | _(empty)_       |
| **Search Location**        | Specifies where to search for the text (e.g., Body, Title).                       | Select     | No        | Body            |

## Expected Output Format

The output from this node is a **boolean value**:

- **true**: The specified condition on the web page is met.
- **false**: The specified condition on the web page is not met.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **If Web Page Contains** node into your flow.

### Step 2

In the **Web Browser Instance** field, enter or select the variable referencing the web browser you want to use.

### Step 3

Select the condition to check in the **Check Condition** dropdown:

- **Contains Element** or **Doesn't Contain Element** if you want to check for an element.
- **Contains Text** or **Doesn't Contain Text** if you want to check for specific text.

### Step 4

If your condition involves elements, use the **Find Type** dropdown to specify how to locate the element and provide the applicable **Value To Find**.

### Step 5

If checking an element's state, toggle **Check UI Element State** and select the desired **State** (Enabled or Disabled).

### Step 6

For text conditions, enter the text in **Text To Search** and choose the **Search Location** where the text is looked for (Body or Title).

### Step 7

The outcome will be shown as **Result**, returning true if the condition is satisfied.

</Steps>

<Callout type="info" title="Tip">
  Ensure the web browser instance is correctly provided; otherwise, the node
  will not work as expected.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                | Solution                                                                                               |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Incorrect Web Browser Instance**     | Verify that the browser instance variable is correctly set and accessible.                             |
| **Element not found**                  | Make sure the **Find Type** and **Value To Find** are correct and match an actual element on the page. |
| **Unexpected text search result**      | Double-check the text and **Search Location** to ensure they match what appears on the page.           |
| **Check UI Element State not showing** | Enable the **Check UI Element State** toggle to use the state-checking feature.                        |

## Real-World Use Cases

- **Pre-interaction Check**: Ensure a 'Submit' button is visible before attempting to click it.
- **Validation Error Detection**: Confirm if a dynamic error message appears after form submission.
- **Content Verification**: Verify that certain content, like a customer's name or greeting, is displayed on a user's dashboard after login.
- **Automated Testing**: Use as part of test scripts to verify web application UI changes.
