# Get Account Password from Credential Manager

The **Get Account Password from Credential Manager** node helps you to automatically retrieve passwords that are securely stored in the Windows Credential Manager. This is especially useful for automating tasks that require access to secure services without manually entering passwords each time.

For example:

- Accessing password-protected accounts or services without manual input.
- Automating processes that interact with secure network resources.

## Configuration Options

| Field Name      | Description                                                      | Input Type | Required? | Default Value |
| --------------- | ---------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Target Name** | The name of the credential target used to retrieve the password. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **string value** representing the password retrieved from the Windows Credential Manager.

- If successful, the output will be the password associated with the specified Target Name.
- If the credential is not found, the output might be empty or an error may be shown in the process.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Get Account Password from Credential Manager** node into your workflow.

### Step 2

In the **Target Name** field, enter the exact name of the credential target as it appears in Windows Credential Manager. This name must match the stored credential to successfully retrieve the password.

### Step 3

Once configured, the node will automatically retrieve the password and make it available for use in subsequent nodes as **Password**.

</Steps>

<Callout type="info" title="Tip">
  Ensure that the Target Name exactly matches the name used in your Windows
  Credential Manager; otherwise, the password retrieval will fail.
</Callout>

## Input/Output Examples

| Target Name      | Output (Password) | Output Type |
| ---------------- | ----------------- | ----------- |
| MyNetworkService | passw0rd!123      | String      |
| OtherCredential  | P@ssw0rd          | String      |

## Common Mistakes & Troubleshooting

| Problem                      | Solution                                                                                                                      |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **Incorrect Target Name**    | Double-check the spelling and casing of the Target Name. It must exactly match the credential in Credential Manager.          |
| **No Password Retrieved**    | Ensure that a credential exists for the given Target Name in Windows Credential Manager. Check the output for error messages. |
| **Permission Denied Errors** | Make sure your application or script has the necessary permissions to access the Windows Credential Manager.                  |

## Real-World Use Cases

- **Automated Logins**: Retrieve and use stored passwords for logging into accounts via scripts.
- **Secure Automation**: Use stored credentials for authenticating automated processes that access sensitive data.
- **Password Management**: Centralize password access without manually entering sensitive information in scripts.
