# Get Credential Manager Credentials

The **Get Credential Manager Credentials** node allows you to retrieve stored usernames and passwords from the Windows Credential Manager. This node is useful when you need to automate processes that require authenticated access to a system or service by fetching the necessary credentials automatically.

For example:

- Accessing databases, networks, or applications that require login credentials.
- Automating tasks that involve multiple systems where manual credential entry is repetitive or error-prone.
- Ensuring scripts have access to updated credentials without hardcoding sensitive details.

## Configuration Options

| Field Name      | Description                                                            | Input Type | Required? | Default Value |
| --------------- | ---------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Target Name** | The name of the credential target to retrieve from Credential Manager. | Text       | Yes       | (empty)       |

## Expected Output Format

The output of this node consists of two fields:

- **Account Name**: The username linked to the credential, output as a string.
- **Secure Password**: The password for the credential, output as a SecureString to maintain security.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Get Credential Manager Credentials** node into your flow.

### Step 2

In the **Target Name** field, enter the exact name of the credential you wish to obtain from the Credential Manager.

### Step 3

After executing the node, the outputs **Account Name** and **Secure Password** will be available for use in subsequent nodes. Ensure the target name is correct to avoid retrieval errors.

</Steps>

<Callout type="info" title="Tip">
  Ensure the Target Name provided matches the exact entry in the Windows
  Credential Manager to successfully retrieve credentials.
</Callout>

## Input/Output Examples

| Example Scenario              | Target Name Input | Expected Account Name | Expected Secure Password           |
| ----------------------------- | ----------------- | --------------------- | ---------------------------------- |
| Retrieve Database Credentials | DatabaseLogin     | dbUser                | (SecureString PasswordPlaceholder) |
| Obtain Email Service Access   | EmailServiceCreds | myEmail@example.com   | (SecureString PasswordPlaceholder) |

(Note: Outputs such as passwords are returned in a secure format.)

## Common Mistakes & Troubleshooting

| Problem                                   | Solution                                                                                    |
| ----------------------------------------- | ------------------------------------------------------------------------------------------- |
| **Credentials not retrieved**             | Ensure the Target Name matches the one listed in Credential Manager.                        |
| **Incorrect username or password output** | Double-check the Credential Manager entry to ensure the correct details are stored.         |
| **Secure Password not useable**           | Remember that the password is a SecureString. Treat it carefully to prevent security risks. |

## Real-World Use Cases

- **Automated Login**: Streamlining automatic login processes for applications without exposing passwords in scripts.
- **Scheduled Tasks**: Running scheduled tasks with necessary access to secured resources.
- **DevOps Automation**: Fetching credentials for CI/CD pipelines to deploy applications requiring authentication.
