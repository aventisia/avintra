# Save Credential Manager Credentials

The **Save Credential Manager Credentials** node allows you to securely store user credentials (username and password) into the Windows Credential Manager. Use this node when you need to automate processes that require accessing systems or software securely by saving login details without manually entering them each time.

This feature is particularly useful for:

- Automating login tasks.
- Ensuring sensitive information like passwords are kept secure.
- Managing access credentials in an organized way.

## Configuration Options

| Field Name       | Description                                                            | Input Type | Required? | Default Value |
| ---------------- | ---------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Target Name**  | The name of the credential target used to store in Credential Manager. | Text       | Yes       | _(empty)_     |
| **Account Name** | The username to be saved in the Credential Manager.                    | Text       | Yes       | _(empty)_     |
| **Password**     | The password associated with the account to be stored securely.        | Password   | Yes       | _(empty)_     |

## Expected Output Format

This node does not have a visible output value for users, as it operates by securely storing the credentials directly into the Windows Credential Manager. Therefore, the primary "output" is the successful storage of provided credentials for later use by other processes or applications needing authentication.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Save Credential Manager Credentials** node into your automation flow.

### Step 2

In the **Target Name** field, enter the specific name you want to give to this credential entry. This is how you will reference it later.

### Step 3

In the **Account Name** field, input the username that should be saved for future access.

### Step 4

In the **Password** field, carefully enter the corresponding password. Be sure it's correct to avoid issues during automation.

### Step 5

Once all fields are correctly filled, the credentials will be saved into the Windows Credential Manager.

</Steps>

<Callout type="warning" title="Caution">
  Ensure that the credentials are correctly entered before saving, as incorrect
  details will lead to authentication errors during automated tasks.
</Callout>

## Input/Output Examples

There is no direct output example for this node, as it functions by storing the inputted data securely instead of providing a visible output value in the workflow.

## Common Mistakes & Troubleshooting

| Problem                                      | Solution                                                                                                                                    |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Credentials not saving**                   | Double-check that all fields, especially `Target Name`, `Account Name`, and `Password`, are filled out and correctly inputted.              |
| **Authentication fails in later tasks**      | Confirm that the `Account Name` and `Password` saved are correct and match the credentials required by the target application or service.   |
| **Unable to locate saved credentials later** | Ensure the `Target Name` used is unique and memorable to easily retrieve and use the credentials when configuring other nodes or processes. |

## Real-World Use Cases

- **Automated Software Logins**: Storing login credentials for applications that frequently need access, ensuring smooth running of automated scripts.
- **Data Access Tasks**: Securely maintaining credentials needed for accessing databases or servers automatically, reducing manual input.
- **Regular Credential Updates**: Easily update stored credentials in Credential Manager when account details change, ensuring your automations run without interruptions.
