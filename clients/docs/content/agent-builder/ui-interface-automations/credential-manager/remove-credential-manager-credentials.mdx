# Remove Credential Manager Credentials

The **Remove Credential Manager Credentials** node is used to delete stored credentials from the Windows Credential Manager. This functionality is useful when you need to clean up or manage credentials for specific applications or network locations on a Windows machine.

For instance:

- Removing outdated or unused credentials to ensure security.
- Managing credentials for different environments or users.

## Configuration Options

| Field Name      | Description                                                                         | Input Type | Required? | Default Value |
| --------------- | ----------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Target Name** | The exact name of the credential target you wish to remove from Credential Manager. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The **Remove Credential Manager Credentials** node does not produce an output value. Instead, it performs an action of removing a specified credential.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Remove Credential Manager Credentials** node to your workflow.

### Step 2

Enter the **Target Name** for the credential you wish to remove. Make sure this matches the credential's stored name in Credential Manager.

### Step 3

Execute the workflow. The action will be performed, and the specified credential will be removed.

</Steps>

<Callout type="warning" title="Important">
  Ensure accuracy in the **Target Name** to avoid removing unintended
  credentials. The process cannot be undone.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                    | Solution                                                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Incorrect Target Name**  | Double-check the spelling and case of the target credential name to ensure it matches exactly with Credential Manager. |
| **Credential Not Removed** | Confirm that the credential actually exists in the Credential Manager and re-enter the correct target name.            |

## Real-World Use Cases

- **Security Maintenance**: Regularly clear old credentials from a shared or public computer to prevent unauthorized access.
- **Environment Switching**: Remove credentials before switching to test or development environments on the same machine.
- **User Management**: For administrators managing multiple users, remove credentials related to users who no longer have access permissions.
