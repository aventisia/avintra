# Update Account Password in Credential Manager

The **Update Account Password in Credential Manager** node allows you to update the password for an existing credential stored in the Windows Credential Manager. This is useful when you need to keep your passwords current for security reasons or update them due to expiry or policy changes.

## Configuration Options

| Field Name       | Description                                                      | Input Type | Required? | Default Value |
| ---------------- | ---------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Target Name**  | The name of the credential target whose password needs updating. | Text       | Yes       | _(empty)_     |
| **New Password** | The new password to apply to the credential.                     | Password   | Yes       | _(empty)_     |

## Expected Output Format

The output of this node does not generate a visible data value or type. It performs an action of updating the stored password and does not return a data output.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Update Account Password in Credential Manager** node into your workflow.

### Step 2

In the **Target Name** field, enter the exact name of the credential you wish to update. This name should match the target name stored in the Windows Credential Manager.

### Step 3

In the **New Password** field, enter the new password you want to assign to the credential.

### Step 4

Proceed by adding more nodes or processes if further actions are needed after updating the credential.

</Steps>

<Callout type="info" title="Important Note">
  Ensure the **Target Name** correctly matches the credential name in Windows
  Credential Manager; otherwise, the update will not succeed.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                            | Solution                                                                                                                                     |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Target Name does not match existing credential** | Verify that the spelling and capitalization of the Target Name exactly match the credential entries in the Windows Credential Manager.       |
| **Password not updated**                           | Check for any restrictions or security policies that may prevent changes and ensure you have necessary permissions to modify the credential. |

## Real-World Use Cases

- **Password Policy Compliance**: Regularly update service account passwords to comply with security policies.
- **Post-Expiry Updates**: Automatically update passwords that are near expiry and avoid account lockouts.
- **Batch Credential Management**: Update multiple account passwords in Windows Credentials Manager as part of regular maintenance tasks.
