# Move Folder

The **Move Folder** node lets you relocate an existing folder to another location on your system. This is particularly useful for organizing files, creating backups, or preparing folders for specific tasks or processes where the folder structure impacts workflow.

For example:

- Moving project folders to an archive directory after completion.
- Organizing data directories for better accessibility.
- Transferring folders between departments or workstations.

## Configuration Options

| Field Name             | Description                                                                         | Input Type | Required? | Default Value |
| ---------------------- | ----------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Folder to Move**     | Specifies the path of the folder that needs to be moved.                            | Text       | No        | _(empty)_     |
| **Destination Folder** | Specifies the path of the destination folder where the source folder will be moved. | Text       | No        | _(empty)_     |

## Expected Output Format

The output of this node is the **path of the moved folder**. It provides a string indicating the new location of the folder on your system. For instance, after a successful move, you might see: `"C:\Documents\Project\Archive\"`.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Move Folder** node into your flow.

### Step 2

In the **Folder to Move** field, enter the complete path of the folder you want to relocate.

### Step 3

In the **Destination Folder** field, specify the destination path where the folder should be moved.

### Step 4

The path of the newly moved folder will be available as **MovedFolderPath** for use in other nodes.

</Steps>

<Callout type="info" title="Tip">
  Ensure that both source and destination paths are correctly specified to avoid
  errors during the move.
</Callout>

## Input/Output Examples

| Folder to Move              | Destination Folder           | Moved Folder Path                     |
| --------------------------- | ---------------------------- | ------------------------------------- |
| `C:\User\Documents\Report`  | `C:\Archives\2023\Reports`   | `C:\Archives\2023\Reports\Report`     |
| `D:\Data\Projects\ProjectX` | `D:\Data\Completed\Projects` | `D:\Data\Completed\Projects\ProjectX` |

## Common Mistakes & Troubleshooting

| Problem                        | Solution                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| **Incorrect Source Path**      | Check that the path in **Folder to Move** correctly points to an existing folder.           |
| **Destination Path Not Found** | Ensure the **Destination Folder** path exists or create it before proceeding with the move. |
| **Permissions Errors**         | Confirm you have the necessary permissions to move the folder to the specified location.    |

## Real-World Use Cases

- **Project Completion**: Move completed project folders to an archive directory to keep active workspaces clear.
- **Departmental Data Transfer**: When departments share resources, move folders to a shared network drive.
- **Automated Backup Process**: Regularly move active folders to a backup location for data preservation.
