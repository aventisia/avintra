# Find File in Folder

The **Find File in Folder** node lets you automate the search for a single file within a specified folder, with options to extend the search to subfolders. You can identify files based on criteria such as size, date of modification, date of creation, or alphabetical arrangement. This node is beneficial when you need to quickly locate specific files from a large collection.

## Configuration Options

| Field Name             | Description                                                                           | Input Type | Required? | Default Value |
| ---------------------- | ------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Folder Path**        | The path to the folder you want to search through.                                    | Text       | Yes       | _(empty)_     |
| **Search Option**      | Choose the criteria to find the file: Largest, Smallest, Newest, Oldest, etc.         | Select     | Yes       | Largest       |
| **File Filter**        | Apply file type filters like '_.txt' or '_.jpg;\*.png' to narrow down search results. | Text       | No        | \*            |
| **Include Subfolders** | Option to include files from subfolders in the search process.                        | Switch     | No        | true          |

## Expected Output Format

The output is a **file path** string indicating the location of the found file within the folder structure.

- If a file is found: output will be the full file path (e.g., `C:\Documents\file.txt`).
- If no file matches the criteria: output will be an empty string.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Find File in Folder** node to your flow.

### Step 2

In the **Folder Path** field, enter the path to the folder where you want to start the search.

### Step 3

In the **Search Option** dropdown, choose the criteria based on which you would like to find the file. Options include:

- **Largest**: Finds the biggest file.
- **Smallest**: Finds the smallest file.
- **Newest Modified**: Finds the most recently modified file.
- **Oldest Modified**: Finds the least recently modified file.
- **Newest Created**: Finds the most recently created file.
- **Oldest Created**: Finds the least recently created file.
- **First Alphabetical**: Finds the first file alphabetically.
- **Last Alphabetical**: Finds the last file alphabetically.

### Step 4

(Optional) Specify a **File Filter** to limit your search to specific file types, such as `*.txt`.

### Step 5

(Optional) Toggle **Include Subfolders** if you want the search to include files in subfolders.

### Step 6

The file matching your criteria will be available as **ResultFilePath** for further use in your automation process.

</Steps>

<Callout type="info" title="Tip">
  By default, the search includes subfolders. To exclude them, switch **Include
  Subfolders** to false.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                             | Solution                                                                                       |
| ----------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Invalid Folder Path**             | Ensure the directory path is correct and the folder is accessible from your system.            |
| **Criteria Doesn't Match Any File** | Try using different search criteria or check if files matching filters exist in the directory. |
| **No File Filter Applied**          | If no file filter is specified, all file types will be considered in the search.               |

## Real-World Use Cases

- **Data Cleanup**: Find and archive the largest files in a directory to manage storage space effectively.
- **Version Control**: Automatically fetch the newest version of a document in a shared directory.
- **Report Generation**: Select the oldest modified files to prioritize updates in a weekly data summary.
- **Photo Sorting**: Identify the first or last image alphabetically for automatic labeling and processing routines.
