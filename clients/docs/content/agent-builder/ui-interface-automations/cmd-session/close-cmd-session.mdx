# Close CMD Session

The **Close CMD Session** node is designed to terminate an active Command Prompt (CMD) session on your desktop. You will find this useful when you want to ensure that any command-line tasks are properly ended, thus freeing up system resources or concluding processes that are no longer needed.

Common scenarios for using this node include:

- Closing a CMD session after executing system commands to release resources.
- Ensuring no background CMD sessions remain running unused.

## Configuration Options

| Field Name      | Description                                             | Input Type | Required? | Default Value |
| --------------- | ------------------------------------------------------- | ---------- | --------- | ------------- |
| **CMD Session** | The process representing the open CMD session to close. | Text       | Yes       | _(empty)_     |

## Expected Output Format

There is no direct output (such as a text or number) generated by this node. However, the successful execution means that the specified CMD session has been closed.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Close CMD Session** node into your flow where you want to terminate a CMD session.

### Step 2

In the **CMD Session** field, input the process identifier for the open CMD session you want to close. Ensure this corresponds to a valid, active session.

### Step 3

After configuration, execute the flow to close the CMD session as needed.

</Steps>

<Callout type="warning" title="Important">
  Make sure the **CMD Session** input is correct and corresponds to an active
  CMD process. Incorrect or invalid entries can result in the node failing to
  close any session.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                      | Solution                                                                                                                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Incorrect CMD Session ID** | Double-check that the CMD Session field contains the correct identifier for the open session you wish to close. An incorrect ID will prevent the node from performing its task. |

## Real-World Use Cases

- **Task Automation**: Use this node at the end of automated processes to clean up CMD sessions and reduce system load.
- **Resource Management**: Ensure idle CMD sessions aren't using unnecessary resources on a desktop setup by closing them after specific routines.
