# Read from CMD Session

The **Read from CMD Session** node allows you to capture the output from a Command Prompt (CMD) session running on your desktop. This node can be useful for monitoring process results, logging command outputs, or capturing errors during the execution of command-line operations.

## Configuration Options

| Field Name                     | Description                                                                             | Input Type | Required? | Default Value |
| ------------------------------ | --------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **CMD Session**                | The process representing the CMD session you want to read from.                         | Text       | Yes       | _(empty)_     |
| **Separate Output from Error** | Indicates if the CMD session's standard output should be separated from standard error. | Switch     | No        | True          |

## Expected Output Format

The outputs from this node are displayed as text:

- **CmdOutput**: This contains the standard output produced by the CMD session.
- **CmdError**: If the "Separate Output from Error" option is enabled, this contains the standard error output.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Read from CMD Session** node to your workflow.

### Step 2

In the **CMD Session** field, enter the identifier or process name of the CMD session you are targeting.

### Step 3

If required, toggle **Separate Output from Error** to decide whether to separate the standard output from the error output.

### Step 4

Once configured, the node will capture the output which you can utilize in subsequent nodes. The captured outputs are **CmdOutput** and, optionally, **CmdError** if separated.

</Steps>

<Callout type="info" title="Tip">
  If you enable the "Separate Output from Error" option, ensure that your
  workflow accounts for handling both outputs separately.
</Callout>

## Input/Output Examples

| CMD Command  | Separate Output? | CmdOutput | CmdError                       |
| ------------ | ---------------- | --------- | ------------------------------ |
| `echo Hello` | Yes              | Hello     | _(none)_                       |
| `badcommand` | Yes              | _(none)_  | 'badcommand' is not recognized |
| `echo Hello` | No               | Hello     | _(none)_                       |

## Common Mistakes & Troubleshooting

| Problem                                 | Solution                                                                                              |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **CMD Session not found**               | Ensure you have correctly specified the CMD session identifier.                                       |
| **No output captured**                  | Verify that the CMD session is running and is producing output.                                       |
| **Unexpected error messages in output** | If "Separate Output from Error" is not enabled, both standard output and error might appear together. |

## Real-World Use Cases

- **Automated Log Collection**: Automatically collect and analyze logs generated by CMD scripts.
- **Error Monitoring**: Detect and handle errors during batch processing.
- **Verification of Command Execution**: Ensure commands are successfully executed in automated scripts.
