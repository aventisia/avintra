# Convert JSON to Custom Object

The **Convert JSON to Custom Object** node is used to transform a JSON string into a specific, well-defined custom object. This can be particularly useful when working with data received in JSON format that needs to be structured for use within specific applications or processes.

For example:

- Parsing JSON data from a web API into an object you can use in your business workflow.
- Converting configuration or setting files in JSON format into structured data formats within your desktop automation tasks.

## Configuration Options

| Field Name    | Description                                                | Input Type | Required? | Default Value |
| ------------- | ---------------------------------------------------------- | ---------- | --------- | ------------- |
| **JSON Data** | The JSON string that will be converted to a custom object. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **Custom Object**. This object is structured according to the JSON you provide and suitable for direct use in other processes or nodes within the platform.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Convert JSON to Custom Object** node into your flow.

### Step 2

In the **JSON Data** field, enter the JSON string that you wish to convert.

### Step 3

After the conversion process, the output **Custom Object** will be available for use and will be referenced as **CustomObject** in subsequent nodes or operations.

</Steps>

<Callout type="info" title="Tip">
  Ensure your JSON string is well-formed and valid, as malformed JSON will
  prevent the node from successfully converting it into an object.
</Callout>

## Input/Output Examples

| Input JSON                  | Output Value | Output Type       |
| --------------------------- | ------------ | ----------------- |
| `{"name":"John", "age":30}` | CustomObject | Structured Object |

## Common Mistakes & Troubleshooting

| Problem                              | Solution                                                                                   |
| ------------------------------------ | ------------------------------------------------------------------------------------------ |
| **Input is not a valid JSON string** | Verify that your JSON syntax is correct, including proper use of brackets and commas.      |
| **Output object not appearing**      | Ensure the JSON string provided is valid and correctly entered in the **JSON Data** field. |

## Real-World Use Cases

- **API Data Handling**: Convert user profiles received in JSON format from APIs into custom objects for processing within your business workflow.
- **Configuration Reading**: Transform JSON configuration files into structured objects for programs requiring fixed object types.
