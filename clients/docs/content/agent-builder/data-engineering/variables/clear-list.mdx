# Clear List

The **Clear List** node is used to remove all elements from a specified list. This can be incredibly useful when you need to ensure that a list variable is empty before repopulating it or using it in further operations, preventing any unintended data from being processed.

For example, this node is handy when you are preparing for a new batch of data processing or when you need to reset lists in a recurring workflow.

## Configuration Options

| Field Name        | Description                                       | Input Type | Required? | Default Value |
| ----------------- | ------------------------------------------------- | ---------- | --------- | ------------- |
| **List to Clear** | The list variable whose elements will be removed. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is an **empty list**. After processing, the specified list will contain no elements.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Clear List** node into your flow.

### Step 2

In the **List to Clear** field, enter the name of the list variable from which you want to remove all elements.

### Step 3

Once the node runs, the specified list will be cleared, removing all current elements.

</Steps>

<Callout type="warning" title="Note">
  Once a list is cleared, the removed elements cannot be recovered from the
  node. Ensure you do not need the current data before clearing.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                       | Solution                                                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Non-existent list entered** | Ensure the list variable entered in **List to Clear** exists; check for typos in the name.                                |
| **List not getting cleared**  | Verify that the node correctly receives the list variable name and that there's no subsequent operation re-populating it. |

## Real-World Use Cases

- **Data Preparation**: Clear lists before loading new data sets during ETL processes.
- **Session Resets**: Use at the start or end of user sessions to clear temporary data caches.
- **Recurring Reports**: Reset lists that gather data for weekly or monthly reports, ensuring fresh inputs.
