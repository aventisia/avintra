# Parse Fragmented JSON List

The **Parse Fragmented JSON List** node helps you convert a list of fragmented JSON strings into a list of well-structured JSON objects. This is especially useful if you have a sequence of JSON text fragments that need consolidation into complete JSON objects for further processing or sorting. This node is essential when you accumulate JSON fragments, for example, through adding items to a list individually but need to work with complete objects later.

## Configuration Options

| Field Name          | Description                                                                  | Input Type | Required? | Default Value |
| ------------------- | ---------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Fragmented List** | The list that contains JSON fragments. Example format: `"{"prop":"value"}"`. | Text       | Yes       | _(empty)_     |
| **Parsed List**     | The output, a list of complete JSON objects ready for use or sorting.        | Output     | No        | ParsedList    |

## Expected Output Format

The output of this node is a **list of JSON objects**. Each object will be a reconstructed JSON entity derived from the fragmented input strings. This output can then be utilized in subsequent data processes, allowing for operations that require formal JSON objects.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Parse Fragmented JSON List** node into your workflow.

### Step 2

In the **Fragmented List** field, provide the sequence of JSON fragments you need to consolidate. Make sure each fragment resembles a JSON structure like `{"key": "value"}`.

### Step 3

Allow the node to process the input list. The node will transform your fragmented inputs into well-structured JSON objects automatically.

### Step 4

The finalized list of JSON objects will become available as **ParsedList**. You can employ this list in other nodes to perform functions that require structured JSON.

</Steps>

<Callout type="info" title="Tip">
  Ensure that each JSON fragment in the **Fragmented List** is correctly
  formatted with proper opening and closing braces as they align into complete
  objects.
</Callout>

## Input/Output Examples

| Fragmented List Input                             | Parsed List Output                        |
| ------------------------------------------------- | ----------------------------------------- |
| `["{\"name\":\"John\"}", "{\"age\":30}"]`         | `[{"name": "John"}, {"age": 30}]`         |
| `["{\"product\":\"book\"}", "{\"price\":15.99}"]` | `[{"product": "book"}, {"price": 15.99}]` |

## Common Mistakes & Troubleshooting

| Problem                              | Solution                                                                                                                                                                |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Empty or Invalid Fragmented List** | The input must include correctly formatted JSON fragments. Ensure there is no missing `}` or misplaced characters in each fragment.                                     |
| **Unexpected Output Format**         | Check the input fragments for consistency and correct JSON syntax. All fragments should be appropriately formed to ensure accurate parsing into a list of JSON objects. |

## Real-World Use Cases

- **Inventory Management**: Convert fragmented inventory updates into structured entries for better database management.
- **User Data Compilation**: Assemble user profile fragments into complete user objects for profiling and personalization tasks.
