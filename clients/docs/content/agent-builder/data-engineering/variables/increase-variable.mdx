# Increase Variable

The **Increase Variable** node allows you to increment a numeric variable by a specified value. This functionality is helpful when you need to adjust a number dynamically, such as increasing a count, adjusting a total, or modifying variables in a workflow for calculations or decision-making.

## Configuration Options

| Field Name               | Description                                                                                       | Input Type | Required? | Default Value |
| ------------------------ | ------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Variable To Increase** | The numeric variable you wish to increment.                                                       | Text       | Yes       | _(empty)_     |
| **Value To Add**         | The amount to add to the variable, which can be a number or another variable containing a number. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **single number value**, specifically the result after the specified increase. This value is available as **Result** for use by subsequent nodes.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Increase Variable** node to your flow.

### Step 2

In the **Variable To Increase** field, enter the numeric variable you want to modify.

### Step 3

In the **Value To Add** field, specify the amount you want to add to the variable. This could be a static number or another numeric variable.

### Step 4

The increased number will be produced as **Result** and can be used in other nodes within your automation flow.

</Steps>

<Callout type="info" title="Tip">
  You can use another variable's value as the **Value To Add** if you need to
  reference a changing or dynamic amount.
</Callout>

## Input/Output Examples

| Variable To Increase | Value To Add | Output Value | Output Type      |
| -------------------- | ------------ | ------------ | ---------------- |
| 10                   | 5            | 15           | Number (Integer) |
| 100                  | 20.5         | 120.5        | Number (Decimal) |
| VariableX (30)       | 10           | 40           | Number (Integer) |

## Common Mistakes & Troubleshooting

| Problem               | Solution                                                                                                                           |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Empty fields**      | Both fields are required. Ensure you've entered a value in both **Variable To Increase** and **Value To Add** fields.              |
| **Non-numeric input** | Ensure that both inputs are valid numbers. If using variables, they must contain numeric values.                                   |
| **Incorrect output**  | Recheck the inputs to ensure the correct variable and value are being used. Verify that the **Value To Add** is what you intended. |

## Real-World Use Cases

- **Inventory Management**: Increase product count dynamically in a warehouse system.
- **Financial Calculations**: Adjust a financial total by adding interest or fees.
- **Progress Updates**: Increment a progress tracker or counter based on task completions.
- **Gaming Applications**: Increase score or resources dynamically in a game.
