# Create Data Table

The **Create Data Table** node allows you to generate a new data table or clone an existing one, providing a flexible solution for managing tabular data. This can be particularly useful for organizing data that needs to be structured into tables before further processing or analysis.

For example:

- Cloning an existing data table to maintain its structure and content.
- Creating a new table with specified initial columns and empty rows for future data entry.

## Configuration Options

| Field Name          | Description                                                                                               | Input Type | Required? | Default Value |
| ------------------- | --------------------------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Data Table**      | An existing data table to clone. Leave empty to create a new table from scratch.                          | Text       | No        | _(empty)_     |
| **Initial Columns** | Toggle to add initial columns to the new table.                                                           | Switch     | No        | _(off)_       |
| **Columns**         | Specify columns for the new table (comma-separated if more than one). Appears when Initial Columns is ON. | Text       | No        | _(empty)_     |
| **Empty Rows**      | Toggle to add empty rows to the new table for future data entry.                                          | Switch     | No        | _(off)_       |
| **Data Table Rows** | Enter the number of empty rows to be added. Appears when Empty Rows is ON.                                | Text       | No        | _(empty)_     |

## Expected Output Format

The node outputs a **newly created or cloned data table**, which can then be utilized in subsequent operations within your workflow.

- Output is structured in a tabular format.
- The output value is accessible as **NewDataTable**.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Create Data Table** node into your workflow.

### Step 2

(Optional) In **Data Table**, enter the name of the existing data table you wish to clone. If left blank, a new data table is created.

### Step 3

(Optional) To add initial columns, switch **Initial Columns** to ON. Enter the column names in **Columns** as comma-separated values (e.g., `Name, Age, City`).

### Step 4

(Optional) To add initial empty rows, switch **Empty Rows** to ON. Specify the number of rows in the **Data Table Rows** field.

### Step 5

The new or cloned table will be available as **NewDataTable** for use in downstream processes.

</Steps>

<Callout type="info" title="Note">
  The fields **Columns** and **Data Table Rows** will only be visible and active
  if you've set **Initial Columns** and **Empty Rows** to ON, respectively.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                      | Solution                                                                                                                                                         |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Columns or Data Table Rows not appearing** | Ensure that **Initial Columns** or **Empty Rows** are switched ON to reveal these fields.                                                                        |
| **Incorrect Comma-Separated Values**         | Verify that column names in **Columns** are separated by commas without spaces unless part of the column name.                                                   |
| **Empty Table Generated**                    | Check that you have either specified columns or rows or provided a data table to clone. Avoid leaving all options unselected or empty when creating a new table. |

## Real-World Use Cases

- **Data Import Templates**: Predefine tables with headers for importing structured data, ensuring consistency in data processing.
- **Draft Data Structures**: Prepare tables with defined columns and empty rows for data collection during surveys or experiments.
- **Data Analysis**: Set up temporary tables to organize data prior to analysis, facilitating efficient data manipulation.
