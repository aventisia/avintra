# Delete Duplicate Rows From Data Table

The **Delete Duplicate Rows From Data Table** node is designed to simplify data cleaning by identifying and removing duplicated rows from a given data table. This function is crucial for ensuring data integrity and quality, especially in data analysis and reporting tasks where unique data entries are required.

Here's when you might use this node:

- To maintain a clean dataset by removing duplicate entries.
- Prior to performing data analysis where duplicates might skew results.
- Before sharing data reports to ensure accuracy and relevance.

## Configuration Options

| Field Name                  | Description                                                                            | Input Type | Required? | Default Value |
| --------------------------- | -------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Data Table**              | The data table you want to process for duplicate removal.                              | Text       | Yes       | _(empty)_     |
| **Compare Mode**            | Determines whether to compare all columns or only specific columns to find duplicates. | Select     | No        | AllColumns    |
| **Column Names To Compare** | Specifies which columns to compare if "Compare Mode" is set to "Selected Columns".     | Text       | No        | _(empty)_     |

## Expected Output Format

The output of this node is a **modified data table** (without duplicate rows). The resultant data will match the structure of your input data table but without repeated entries.

The output data field you can use in subsequent nodes:

- **ModifiedDataTable**: Data table with duplicates removed.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Delete Duplicate Rows From Data Table** node to your workflow.

### Step 2

In the **Data Table** field, enter or select the data table from which you want to remove duplicates.

### Step 3

Choose your **Compare Mode**:

- **All Columns** will compare all columns of each row to determine duplicates.
- **Selected Columns** lets you specify which columns to use for comparison.

### Step 4

If you selected **Selected Columns** in the Compare Mode, a new field will appear:

- **Column Names To Compare**: Enter the column names you wish to compare, separated by commas (e.g., "Name, Date").

### Step 5

The cleaned data table will be available as **ModifiedDataTable** for further use in your workflow.

</Steps>

<Callout type="info" title="Note">
  When selecting "Selected Columns" for **Compare Mode**, ensure that all
  specified columns exist in the data table to avoid errors.
</Callout>

## Input/Output Examples

| Compare Mode     | Input Data Table                              | Column Names To Compare | Output Data Table                                          |
| ---------------- | --------------------------------------------- | ----------------------- | ---------------------------------------------------------- |
| All Columns      | Table with duplicate rows in all columns      | _(n/a)_                 | Table with all duplicate rows removed                      |
| Selected Columns | Table with duplicates based on select columns | "Name, Date"            | Table with duplicates in "Name" and "Date" columns removed |

## Common Mistakes & Troubleshooting

| Problem                                               | Solution                                                                                                              |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Empty Data Table output**                           | Ensure that the input **Data Table** is correctly specified and not empty.                                            |
| **Comparison Columns field not appearing**            | This field only appears when you set **Compare Mode** to **"Selected Columns"**.                                      |
| **Incorrect column names in Column Names To Compare** | Double-check the spelling and existence of column names entered to avoid missing out intended duplicates for removal. |

## Real-World Use Cases

- **Customer Data Management**: Keep customer databases clean by removing duplicate records that may have been entered multiple times.
- **Financial Data Reporting**: Ensure transaction reports do not count duplicate entries, providing more accurate financial insights.
- **Database Preparation for Machine Learning**: Clean datasets by eliminating duplicates to avoid bias in model training.
