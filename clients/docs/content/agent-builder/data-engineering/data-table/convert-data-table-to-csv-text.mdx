# Convert Data Table to CSV Text

The **Convert Data Table to CSV Text** node transforms a data table into its CSV (Comma-Separated Values) text format. This is useful when you need to share, export, or process data in a tabular structure via text format that is easily readable by spreadsheet applications or other tools.

There are several scenarios in which this conversion is beneficial:

- Preparing data for export to spreadsheet programs like Microsoft Excel.
- Sharing structured data in a text-based format for interoperability across platforms.
- Storing table data efficiently in logs or for auditing purposes.

## Configuration Options

| Field Name                       | Description                                                                                     | Input Type | Required? | Default Value  |
| -------------------------------- | ----------------------------------------------------------------------------------------------- | ---------- | --------- | -------------- |
| **Data Table**                   | The data table variable you wish to convert to CSV text.                                        | Text       | Yes       | _(empty)_      |
| **Include Column Names**         | Specify whether to include column names as the first row in the CSV (defaults to 'Yes').        | Switch     | No        | Yes            |
| **Use Custom Columns Separator** | Choose whether to use a custom separator instead of a predefined one (defaults to 'No').        | Switch     | No        | No             |
| **Separator**                    | Select the column separator for the CSV text (only if you don't use a custom separator).        | Select     | No        | System Default |
| **Custom Columns Separator**     | A custom string for separating columns in the CSV format (appears if custom separator is used). | Text       | No        | _(empty)_      |

## Expected Output Format

The expected result from this node is a **CSV text string**, where:

- Columns in the data table are separated by the defined separator.
- Rows in the table are represented as separate lines.
- The CSV format allows for an optional header row when column names are included.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Convert Data Table to CSV Text** node to your flow.

### Step 2

In the **Data Table** field, enter or choose the data table to convert.

### Step 3

Toggle the **Include Column Names** switch if you want the CSV to include the column headers as the first row.

### Step 4

If you prefer a predefined separator (like comma, semicolon, or tab), ensure **Use Custom Columns Separator** is off. Otherwise, toggle it on to specify your custom separator.

### Step 5

If **Use Custom Columns Separator** is off, select the desired separator from the **Separator** dropdown.

### Step 6

Enter a custom separator in the **Custom Columns Separator** field if you've opted to use one.

### Step 7

Your CSV formatted text will be available in **CSV Text Output** for easy access and use in subsequent nodes.

</Steps>

<Callout type="info" title="Tip">
  The "Custom Columns Separator" field is only visible when the "Use Custom
  Columns Separator" option is enabled.
</Callout>

## Input/Output Examples

| Data Table Example                           | Include Column Names | Separator | Custom Separator | CSV Text Output                       |
| -------------------------------------------- | -------------------- | --------- | ---------------- | ------------------------------------- |
| Name, Age<br/>, Alice, 30<br/>, Bob, 25      | Yes                  | Comma     | _(n/a)_          | Name,Age \nAlice,30 \nBob,25          |

| City,Population<br/>, NY,8M<br/>, LA,4M      | Yes                  | _(n/a)_   | " - "            | City - Population \nNY - 8M \nLA - 4M |

## Common Mistakes & Troubleshooting

| Problem                                 | Solution                                                                                                       |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Not seeing expected column names**    | Verify that **Include Column Names** is set to 'On' if you wish to include them in the first row.              |
| **Unintended separators in CSV output** | Check if **Use Custom Columns Separator** is enabled inadvertently. Specify the desired separator accordingly. |
| **Missing separator selections**        | Ensure that **Use Custom Columns Separator** is not enabled if you want to use predefined separators.          |

## Real-World Use Cases

- **Data Reporting**: Convert data gathered from inventories or surveys to CSV for easy inclusion in reports.
- **Data Exporting**: Export data for analysis or archival purposes in universally accepted CSV format.
- **Data Sharing**: Facilitate the movement of table data between different software applications that support CSV formats.
