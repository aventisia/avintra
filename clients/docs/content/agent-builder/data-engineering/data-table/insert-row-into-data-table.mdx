# Insert Row Into Data Table

The **Insert Row Into Data Table** node is designed to add a new row to an existing data table at a specified location. This can be useful for updating datasets, adding new entries, or rearranging data dynamically without manually editing the table, thereby enhancing workflow efficiency.

For example:

- Adding new records to a customer database.
- Inserting missing data entries within specific indexes.
- Appending new data automatically at the end of a list.

## Configuration Options

| Field Name          | Description                                                                                                                      | Input Type | Required? | Default Value     |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------- | --------- | ----------------- |
| **Data Table**      | The data table where the new row will be added. Ensure the table structure matches the new row's values.                         | Text       | Yes       | _(empty)_         |
| **Row Values**      | An array of values to add as a new row. Ensure these values match the table's column count and types. Example: `[1, 'John', 30]` | Text       | Yes       | _(empty)_         |
| **Insert Location** | Choose whether to append the row at the end or insert it before a specific row index.                                            | Select     | No        | End of Data Table |
| **Row Index**       | The zero-based index before which to insert the new row (only applicable if "Insert Location" is set to "Before Row Index").     | Text       | No        | _(empty)_         |

## Expected Output Format

The output from this node is the **Modified Data Table**, which reflects the newly added row. The format remains consistent with the original data table.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Insert Row Into Data Table** node into your flow.

### Step 2

In the **Data Table** field, specify the table where you want to add the new row.

### Step 3

Enter the **Row Values** you wish to insert. Ensure these match your table's structure in terms of count and data types.

### Step 4

Select an option from the **Insert Location** dropdown:

- **Before Row Index**: Insert the row before the designated index. You will need to specify the index in the **Row Index** field.
- **End of Data Table**: Append the row to the end of the table.

### Step 5

If you chose **Before Row Index**, enter the index in the **Row Index** field, indicating where to insert the new row.

### Step 6

The updated data table, now with the new row, will be available as **ModifiedDataTable** for use in subsequent nodes.

</Steps>

<Callout type="info" title="Tip">
  Use "End of Data Table" for continuous data additions like logging or growing
  datasets to always append new entries at the end.
</Callout>

## Input/Output Examples

| Insert Location   | Input Row Values  | Row Index | Modified Data Table Output                             | Output Description                                      |
| ----------------- | ----------------- | --------- | ------------------------------------------------------ | ------------------------------------------------------- |
| Before Row Index  | `[2, 'Jane', 25]` | 1         | Updated table with Jane's data inserted before index 1 | Jane's row appears as the second row in the data table. |
| End of Data Table | `[3, 'Doe', 40]`  | _(n/a)_   | Table with new row for Doe added to the end            | Doe's data is appended at the bottom of the data table. |

## Common Mistakes & Troubleshooting

| Problem                           | Solution                                                                                                                 |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Missing Row Values**            | Ensure you provide all required values matching the column count and types of the data table.                            |
| **Row Index field not appearing** | This field only appears if "Insert Location" is set to "Before Row Index". Select it first to configure the index value. |
| **Incorrect Insert Location**     | Verify if you wish to append or insert at a specific index to avoid unexpected data arrangement.                         |
| **Non-numeric Row Index**         | Ensure the Row Index is a valid number reflecting a position within the table.                                           |

## Real-World Use Cases

- **Customer Management**: Add new customers to a database, ensuring their data is appended at the end or inserted alphabetically.
- **Inventory Tracking**: Insert new inventory items at specific positions in a data table.
- **Project Progress Update**: Add progress entries into a timeline data table at appropriate points.
