# Recognize Entities in Text

The **Recognize Entities in Text** node is designed to detect and list specific entities within a given text, such as dates, numbers, emails, URLs, and more, across many languages. This is particularly useful when you need to extract structured information from unstructured text for tasks like data analysis, reporting, or automation.

For example:

- Extracting dates from a body of text for timeline analysis.
- Identifying currency or numerical data for financial evaluations.
- Capturing email addresses from text for contact information compilation.

## Configuration Options

| Field Name          | Description                                                               | Input Type | Required? | Default Value |
| ------------------- | ------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Text To Analyze** | The text from which entities will be recognized.                          | Text       | Yes       | _(empty)_     |
| **Entity Type**     | Specifies the type of entities to recognize (e.g., Date, Number, Email).  | Select     | Yes       | _(empty)_     |
| **Language**        | The language of the text. Optional, but can improve recognition accuracy. | Select     | No        | _(empty)_     |

## Expected Output Format

The output of this node is a **list of recognized entities**. Each recognized entity will be returned in a format relevant to its type (e.g., a date will appear as a date string, an email as a text string, etc.).

- The output is best used directly with nodes that handle list-type inputs.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Recognize Entities in Text** node to your flow.

### Step 2

In the **Text To Analyze** field, enter the text from which you want to identify entities.

### Step 3

From the **Entity Type** dropdown, select the type of entity you wish to recognize:

- Date, Number, Email, URL, etc.

### Step 4

Optionally, select a **Language** from the dropdown to specify the language of the text. This can enhance recognition accuracy if known.

### Step 5

Once configured, the node will produce a list of entities under **Recognized Entities**, ready for further processing in your automation flow.

</Steps>

<Callout type="info" title="Tip">
  Specifying the correct text language can significantly enhance entity
  recognition accuracy. If the language is unknown or mixed, leaving the
  language option blank may achieve general results.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                           | Solution                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **No entities recognized**                        | Ensure the correct **Entity Type** is selected and the input text includes expected entities.     |
| **Incorrect entity type selected**                | Double-check that the **Entity Type** matches the entities present in the text.                   |
| **Unexpected results when language is ambiguous** | Specify the **Language** when dealing with multilingual texts or unexpected recognition outcomes. |

## Real-World Use Cases

- **Social Media Monitoring**: Extract hashtags and mentions from posts for sentiment analysis.
- **Data Entry Automation**: Automate data collection by recognizing emails or phone numbers for CRM updates.
- **Content Management**: Detect and categorize URLs and mentions in user-generated content.
