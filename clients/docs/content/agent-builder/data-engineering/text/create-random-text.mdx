# Create Random Text

The **Create Random Text** node allows you to generate a string of random characters within a specified length. This can be useful when you need a placeholder text or when you want to simulate a random data entry. You can customize the text to include uppercase, lowercase, digits, and even symbols based on your requirements.

## Configuration Options

| Field Name                | Description                                           | Input Type                | Required? | Default Value |
| ------------------------- | ----------------------------------------------------- | ------------------------- | --------- | ------------- | ----- |
| **Minimum Length**        | The minimum number of characters for the random text. | Text                      | Yes       | _(empty)_     |
| **Maximum Length**        | The maximum number of characters for the random text. | Text                      | Yes       | _(empty)_     |
| **Use Uppercase Letters** | Determines if uppercase letters (A-Z) are included.   | Switch                    | No        | True          |
| **Use Lowercase Letters** | Determines if lowercase letters (a-z) are included.   | Switch                    | No        | True          |
| **Use Digits**            | Determines if digits (0-9) are included.              | Switch                    | No        | True          |
| **Use Symbols**           | Determines if symbols (!@#$%^&\*()\_+-=[]{}           | ;:,&lt;>? ) are included. | Switch    | No            | False |

## Expected Output Format

The output of this node is a **string of random characters** that may contain a mix of uppercase letters, lowercase letters, digits, and symbols, depending on your settings.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Create Random Text** node into your flow.

### Step 2

Enter the desired length range by providing values in the **Minimum Length** and **Maximum Length** fields. Ensure that both fields have numeric values and that the maximum length is greater than or equal to the minimum length.

### Step 3

Decide on the character set for the text:

- Toggle **Use Uppercase Letters** if you want A-Z included.
- Toggle **Use Lowercase Letters** if you want a-z included.
- Toggle **Use Digits** if you want 0-9 included.
- Toggle **Use Symbols** if you want special characters included.

### Step 4

The generated random text will be available as **Random Text** for use in other nodes.

</Steps>

<Callout type="info" title="Tip">
  Ensure the minimum and maximum lengths are valid numbers and that the maximum
  length is not less than the minimum length to prevent errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                     | Solution                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **Non-numeric value in length fields**      | Ensure both **Minimum Length** and **Maximum Length** contain valid numbers only.          |
| **Maximum Length less than Minimum Length** | Verify that the **Maximum Length** is not smaller than the **Minimum Length**.             |
| **No characters in output**                 | Ensure at least one character type (uppercase, lowercase, digits, or symbols) is selected. |

## Real-World Use Cases

- **Password Generation**: Create random passwords for account security.
- **Unique Identifiers**: Generate unique strings as IDs for user sessions or transactions.
- **Testing Input Fields**: Use random text to test form inputs or fields that require text entries.
- **Mock Data for Applications**: Fill database records or applications with random placeholder data.
