# Subtract Lists

The **Subtract Lists** node is designed to compare two lists and remove items from the first list that also exist in the second list. This is useful when you need to filter out unwanted or duplicate values from a collection of data.

For example:

- Exclude certain items from a shopping list based on another list of items you already have.
- Remove processed entries from a task list, keeping only the unprocessed tasks.

## Configuration Options

| Field Name      | Description                                                                            | Input Type | Required? | Default Value |
| --------------- | -------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **First List**  | The variable that holds the first list to compare.                                     | Text       | Yes       | _(empty)_     |
| **Second List** | The variable that contains the second list used to subtract items from the first list. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output of this node is a **list** containing items that are present in the first list but not in the second list. This output is labeled as **ListDifferenceOutput**.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Subtract Lists** node into your flow.

### Step 2

In the **First List** field, enter or select the variable that holds the first list of items you wish to modify.

### Step 3

In the **Second List** field, enter or select the variable for the list of items you want to subtract from the first list.

### Step 4

Once configured, the resulting list after subtraction will be available as **ListDifferenceOutput** for use in other nodes.

</Steps>

<Callout type="info" title="Note">
  Ensure both **First List** and **Second List** are properly formatted as lists
  before using this node.
</Callout>

## Input/Output Examples

| First List              | Second List     | Output Value    | Output Type |
| ----------------------- | --------------- | --------------- | ----------- |
| [apple, banana, cherry] | [banana, grape] | [apple, cherry] | List        |
| [1, 2, 3, 4]            | [2, 4]          | [1, 3]          | List        |
| [item1, item2]          | [item3, item4]  | [item1, item2]  | List        |

## Common Mistakes & Troubleshooting

| Problem                                     | Solution                                                                                       |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Lists are not being properly subtracted** | Verify that both lists are correctly defined and formatted as text inputs recognized as lists. |
| **Unexpected output of ListDifference**     | Double-check the contents of your lists to ensure they contain the items in expected formats.  |

## Real-World Use Cases

- **Shopping Optimization**: Automatically remove items from a purchase list that have been bought in previous transactions.
- **Task Dependency Management**: Keep track of tasks remaining after certain dependencies have been completed or checked off.
- **Inventory Management**: Maintain a list of out-of-stock items by subtracting the items that were restocked.
