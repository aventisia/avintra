# Generate Random Number

The **Generate Random Number** node allows you to create a random number or multiple random numbers within a specific range. This is useful for tasks that require randomness, such as simulating data, testing systems, or selecting random samples.

For example:

- Generate a single random number between 1 and 100.
- Create a list of random numbers for batch testing.
- Use random numbers in games or simulations for unpredictability.

## Configuration Options

| Field Name                    | Description                                                       | Input Type | Required? | Default Value |
| ----------------------------- | ----------------------------------------------------------------- | ---------- | --------- | ------------- |
| **Minimum Value**             | The lower boundary for the random number(s) to generate.          | Text       | Yes       | _(empty)_     |
| **Maximum Value**             | The upper boundary for the random number(s) to generate.          | Text       | Yes       | _(empty)_     |
| **Generate Multiple Numbers** | Specify whether to generate a single number or multiple numbers.  | Switch     | No        | false         |
| **How Many Numbers**          | Specify how many random numbers to generate.                      | Text       | No        | _(empty)_     |
| **Allow Duplicates**          | Specify whether to permit duplicate values in the generated list. | Switch     | No        | false         |

## Expected Output Format

The output of this node varies depending on your configuration:

- If generating a single number: output will be a single numeric value labeled as **RandomNumber** (e.g., `42`).
- If generating multiple numbers: output will be a list of numbers labeled as **RandomNumbers** (e.g., `[3, 16, 25]`).

## Step-by-Step Guide

<Steps>
### Step 1

Add a **Generate Random Number** node to your flow.

### Step 2

In the **Minimum Value** field, enter the smallest number in your desired range.

### Step 3

In the **Maximum Value** field, enter the largest number in your desired range.

### Step 4

Decide if you want multiple numbers:

- Toggle **Generate Multiple Numbers** switch if you need more than one number.

### Step 5

If generating multiple numbers, additional fields appear:

- **How Many Numbers**: Enter how many numbers you want.
- **Allow Duplicates**: Toggle this switch if duplicate numbers are acceptable.

### Step 6

The generated number or numbers will be available as **RandomNumber** (single) or **RandomNumbers** (multiple) for use in other nodes.

</Steps>

<Callout type="info" title="Tip">
  Ensure all numeric input values are correctly set, and the minimum value is
  less than the maximum value to avoid errors.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                      | Solution                                                                            |
| -------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Non-numeric value entered in fields**      | Ensure that all entries in **Minimum Value** and **Maximum Value** are numbers.     |
| **Minimum Value greater than Maximum Value** | Verify the range and ensure the minimum is less than the maximum.                   |
| **Duplicate restriction ignored**            | Double-check the **Allow Duplicates** setting to ensure your desired configuration. |
| **Unexpected number of results**             | Confirm the **How Many Numbers** value if generating multiple numbers.              |
