# Add Item to List

The **Add Item to List** node lets you add new elements to an existing list. It's particularly useful when you want to dynamically update a list with new data items, whether single elements or several items at once.

This functionality is helpful in scenarios such as:

- Accumulating data from various sources into a single list.
- Building dynamic lists for further processing or analysis.
- Simplifying data management by updating lists on-the-go.

## Configuration Options

| Field Name         | Description                                                          | Input Type | Required? | Default Value |
| ------------------ | -------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **List To Modify** | The list variable that you want to update with new items.            | Text       | Yes       | _(empty)_     |
| **Item To Add**    | The item(s) to add; can be a single element or comma-separated list. | Text       | Yes       | _(empty)_     |

## Expected Output Format

The output from this node is an **updated list** that includes the newly added items. The type of items in the list should remain consistent to prevent errors in subsequent processing tasks.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Add Item to List** node into your flow.

### Step 2

In the **List To Modify** field, specify the list variable you wish to update. This could be an existing list name you've been using in your flow.

### Step 3

In the **Item To Add** field, enter the item(s) you wish to add to the list. You can add a single item or multiple items separated by commas.

### Step 4

Once configured, the node will process and output the list as **ModifiedList**, which will include the newly added items.

</Steps>

<Callout type="info" title="Note">
  Ensure that the list and items you're handling are of compatible data types to
  avoid output issues.
</Callout>

## Input/Output Examples

| List To Modify | Item To Add        | Output Value                    | Output Type    |
| -------------- | ------------------ | ------------------------------- | -------------- |
| `[1, 2, 3]`    | `4`                | `[1, 2, 3, 4]`                  | List (Numeric) |
| `['apple']`    | `'banana, orange'` | `['apple', 'banana', 'orange']` | List (String)  |
| `[]`           | `'item1, item2'`   | `['item1', 'item2']`            | List (String)  |

## Common Mistakes & Troubleshooting

| Problem                   | Solution                                                        |
| ------------------------- | --------------------------------------------------------------- |
| **No output generated**   | Ensure both fields aren't empty and contain valid inputs.       |
| **Type mismatch error**   | Confirm that item types match the list type.                    |
| **Unexpected list order** | Items are added at the end; check the order in input operation. |

## Real-World Use Cases

- **Shopping Cart Systems**: Dynamically add selected products to a user's shopping cart list.
- **Batch Processing**: Gather data gradually and update a list for bulk processing later.
- **Contact Management**: Append new contacts to an existing contact list dynamically.
