# Sort List

The **Sort List** node enables you to organize the elements of a list according to specified conditions. You can sort a list in ascending or descending order, with the option to sort by the properties of objects, making it a versatile tool for managing complex data collections.

This node is particularly useful when you need to systematically arrange data like a list of files by name or date, ensuring easier data handling and processing.

## Configuration Options

| Field Name                     | Description                                                                                            | Input Type | Required? | Default Value |
| ------------------------------ | ------------------------------------------------------------------------------------------------------ | ---------- | --------- | ------------- |
| **List to Sort**               | The variable that holds the list to sort.                                                              | Text       | Yes       | _(empty)_     |
| **Sort By Properties**         | Enable this if sorting based on object properties (e.g., files, folders).                              | Switch     | No        | False         |
| **First Property to Sort By**  | The name of the first property to define the sort. _Appears only if "Sort By Properties" is enabled._  | Text       | No        | _(empty)_     |
| **First Sort Direction**       | Determines whether to sort the first property in ascending or descending order.                        | Select     | No        | Ascending     |
| **Second Property to Sort By** | The name of the second property to define the sort. _Appears only if "Sort By Properties" is enabled._ | Text       | No        | _(empty)_     |
| **Second Sort Direction**      | Determines whether to sort the second property in ascending or descending order.                       | Select     | No        | Ascending     |
| **Third Property to Sort By**  | The name of the third property to define the sort. _Appears only if "Sort By Properties" is enabled._  | Text       | No        | _(empty)_     |
| **Third Sort Direction**       | Determines whether to sort the third property in ascending or descending order.                        | Select     | No        | Ascending     |

## Expected Output Format

The output of this node is the **Sorted List**, which retains the structure of the original list but reorganized according to the specified sorting criteria (e.g., ascending order of properties).

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Sort List** node into your flow.

### Step 2

In the **List to Sort** field, enter the name of the variable containing your list.

### Step 3

If you want to sort by specific properties (e.g., sorting a list of files by date), enable **Sort By Properties**.

### Step 4

If **Sort By Properties** is enabled, define the properties to sort by:

- Enter the **First Property to Sort By**.
- Choose the **First Sort Direction** (Ascending or Descending).

### Step 5

(Optional) Define additional properties if necessary:

- Enter the **Second Property to Sort By** and select **Second Sort Direction**.
- Enter the **Third Property to Sort By** and select **Third Sort Direction**.

### Step 6

The sorted list will be available as **SortedList** for further use in subsequent operations.

</Steps>

<Callout type="info" title="Note">
  Enabling "Sort By Properties" and setting properties correctly is crucial if
  you are sorting complex data objects like files or records.
</Callout>

## Input/Output Examples

| List Type | Input Example                                  | Output Example                                 |
| --------- | ---------------------------------------------- | ---------------------------------------------- |
| Simple    | `[3, 1, 2]`                                    | `[1, 2, 3]`                                    |
| By Name   | `[{name: 'b'}, {name: 'a'}, {name: 'c'}]`      | `[{name: 'a'}, {name: 'b'}, {name: 'c'}]`      |
| By Date   | `[{date: '2023-10-10'}, {date: '2023-01-01'}]` | `[{date: '2023-01-01'}, {date: '2023-10-10'}]` |

## Common Mistakes & Troubleshooting

| Problem                                | Solution                                                                       |
| -------------------------------------- | ------------------------------------------------------------------------------ |
| **Properties not appearing for input** | Ensure **Sort By Properties** is enabled and input is structured correctly.    |
| **Unexpected sort order**              | Check if you have correctly set the sort direction to Ascending or Descending. |
| **Empty output list**                  | Verify that the input list is populated and the variable name is correct.      |

## Real-World Use Cases

- **File Organization**: Sort a list of files by their creation dates or file sizes.
- **Task Prioritization**: Arrange tasks by priority levels or due dates.
- **Data Analytics**: Prepare datasets by arranging them in logical order for analysis.
