# Reverse List

The **Reverse List** node allows you to change the order of items in a list, flipping them from the last item to the first and vice versa. This might be needed in situations where the sequence of items matters or if you require a reversed order for further processing or display.

For example, if you have a list in the order `[A, B, C]`, reversing it would output `[C, B, A]`.

## Configuration Options

| Field Name          | Description                                              | Input Type | Required? | Default Value |
| ------------------- | -------------------------------------------------------- | ---------- | --------- | ------------- |
| **List to Reverse** | The list whose item order will be reversed.              | Text       | Yes       | _(empty)_     |
| **Reversed List**   | Returns the list after reversing the order of its items. | Output     | No        | ReversedList  |

## Expected Output Format

The output of this node is a **list** with the order of items reversed. For example: if the input is `[1, 2, 3]`, the output will be `[3, 2, 1]`.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Reverse List** node into your flow.

### Step 2

In the **List to Reverse** field, enter or select the list you want to reverse the order of.

### Step 3

The system will automatically generate the reversed list and make it available under **Reversed List** for use in subsequent nodes.

</Steps>

<Callout type="info" title="Tip">
  Ensure that the input list is properly formatted to avoid errors. Each item
  should be separated by a comma in a text string.
</Callout>

## Input/Output Examples

| Input List          | Output List         |
| ------------------- | ------------------- |
| [1, 2, 3]           | [3, 2, 1]           |
| [A, B, C]           | [C, B, A]           |
| [True, False, True] | [True, False, True] |

## Common Mistakes & Troubleshooting

| Problem                            | Solution                                                                                     |
| ---------------------------------- | -------------------------------------------------------------------------------------------- |
| **List to Reverse field is empty** | Ensure to input a list in the **List to Reverse** field as it is required for the operation. |
| **Incorrect List Format**          | Make sure your list entries are separated by commas and enclosed in brackets if needed.      |
| **Unexpected Output**              | Double-check the structure and format of your input list to ensure accuracy.                 |

## Real-World Use Cases

- **Task Prioritization**: Reverse a list of tasks to adjust their processing order.
- **History Logs**: Display most recent activities first by reversing the log order.
- **Data Reordering**: Alter the order of datasets for comparative analysis or other operational necessities.
