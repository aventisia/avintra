# Read From CSV Text

The **Read From CSV Text** node is designed to transform plain CSV text into a usable data table format. This can be incredibly useful when you have raw CSV data and need to organize it into a structured format for further processing or analysis in your workflows.

For example:

- Converting data from a CSV-formatted email attachment into a table.
- Preparing CSV exported data from external systems for processing.
- Simplifying data manipulation by structuring CSV text into a table.

## Configuration Options

| Field Name                           | Description                                                                              | Input Type | Required? | Default Value |
| ------------------------------------ | ---------------------------------------------------------------------------------------- | ---------- | --------- | ------------- |
| **CSV Text**                         | The CSV text to parse into a structured data table.                                      | Text       | Yes       | _(empty)_     |
| **Trim Fields**                      | Trims whitespace from the fields if set to true.                                         | Switch     | No        | _(empty)_     |
| **First Line Contains Column Names** | Treats the first line as column headers if set to true.                                  | Switch     | No        | _(empty)_     |
| **Get CSV Fields as Text**           | Converts all fields to text if enabled.                                                  | Switch     | No        | _(empty)_     |
| **Columns Separator**                | Specifies the method for column separation.                                              | Select     | No        | Predefined    |
| **Custom Separator**                 | The custom separator to be used when the 'Columns Separator' is set to 'Custom'.         | Text       | No        | _(empty)_     |
| **Fixed Column Widths**              | The specific widths to be used when 'Columns Separator' is set to 'Fixed Column Widths'. | Text       | No        | _(empty)_     |

## Expected Output Format

The output of this node is a **structured data table** containing rows and columns determined by the CSV text.

- When column names are included, the output will map these names to the corresponding values in each row.
- If no headers are specified, columns will be indexed numerically.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Read From CSV Text** node to your workflow.

### Step 2

In the **CSV Text** field, paste or enter your CSV-formatted text.

### Step 3

Decide if you want to **Trim Fields** by toggling the switch on or off.

### Step 4

If your CSV's first line contains column names, enable **First Line Contains Column Names**.

### Step 5

Choose **Get CSV Fields as Text** if you want to ensure all fields are treated as text.

### Step 6

Select the **Columns Separator** that matches your CSV format:

- **Predefined**: Uses the system's default separator (comma).
- **Custom**: Enter a custom separator in the **Custom Separator** field.
- **Fixed Column Widths**: Specify widths in **Fixed Column Widths**.

### Step 7

Use the output data table **ResultDataTable** in connecting nodes for further operations.

</Steps>

<Callout type="info" title="Tip">
  The "Custom Separator" and "Fixed Column Widths" fields will only appear based
  on your selection in the "Columns Separator".
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                     | Solution                                                                                                     |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **CSV text is not parsed correctly**        | Ensure the **Columns Separator** matches the separator used in your CSV file.                                |
| **Fields are not trimmed**                  | Check that the **Trim Fields** option is enabled if you want whitespace removed.                             |
| **Column names not recognized**             | Verify that **First Line Contains Column Names** is enabled when your CSV's first row contains headers.      |
| **Custom Separator field not displayed**    | Make sure to choose "Custom" in the **Columns Separator** dropdown to reveal the **Custom Separator** field. |
| **Fixed Column Widths input not available** | Choose "Fixed Column Widths" in **Columns Separator** to make the **Fixed Column Widths** field accessible.  |
