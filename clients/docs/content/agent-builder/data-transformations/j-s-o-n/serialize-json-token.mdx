# Serialize JSON Token

The **Serialize JSON Token** node is designed to convert an object or JToken into two main formats: a JSON string and a JToken. This is particularly useful when you need to transform or transfer structured data within your workflows, ensuring the data can be easily read, edited, or exchanged between different platforms or components.

**Use cases include:**

- Converting data objects for API data exchange.
- Preparing data for storage or logging.
- Transforming complex data structures for display or reporting.

## Configuration Options

| Field Name           | Description                                                                         | Input Type         | Required? | Default Value   |
| -------------------- | ----------------------------------------------------------------------------------- | ------------------ | --------- | --------------- |
| **Input Token**      | The JToken or object you wish to convert into JSON text and JToken.                 | Text               | Yes       | _(empty)_       |
| **Serialized JSON**  | The resulting JSON string from serialization. Returns null if serialization failed. | Automatic (Output) | No        | SerializedJson  |
| **Serialized Token** | The resulting JToken from serialization. Returns null if serialization failed.      | Automatic (Output) | No        | SerializedToken |

## Expected Output Format

This node will produce two outputs optionally, if serialization is successful:

- **Serialized JSON**: A JSON string (e.g., `{"key":"value"}`).
- **Serialized Token**: A JToken object representing the structure of the data.

## Step-by-Step Guide

<Steps>

### Step 1

Add the **Serialize JSON Token** node into your workflow.

### Step 2

In the **Input Token** field, enter the JToken or object you want to serialize to JSON.

### Step 3

The outputs **Serialized JSON** and **Serialized Token** will automatically generate the converted data.

### Step 4

You can now use these outputs in subsequent nodes as needed in your workflow.

</Steps>

<Callout type="info" title="Tip">
  Double-check your input for any unsupported formats. Ensure your input data is
  properly structured to avoid serialization failures.
</Callout>

## Input/Output Examples

| Input Token           | Serialized JSON       | Serialized Token                             |
| --------------------- | --------------------- | -------------------------------------------- |
| `{"name":"John"}`     | `{"name":"John"}`     | JToken object (`{name: "John"}` structure)   |
| `["apple", "banana"]` | `["apple", "banana"]` | JToken array containing "apple" and "banana" |

## Common Mistakes & Troubleshooting

| Problem                   | Solution                                                                                                  |
| ------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Serialization failure** | Ensure the input data is a valid structure or object. Double-check for any syntax issues in the input.    |
| **Missing output values** | Check that the input token is correctly entered. Serialized outputs will be null if the input is invalid. |
| **Unexpected result**     | Verify the input value and its format to ensure it's serialized as expected.                              |

## Real-World Use Cases

- **API Integration**: Convert response data into JSON string for further processing.
- **Data Storage**: Serialize objects before saving them to databases or files.
- **Logging**: Create readable JSON format logs from internal data structures for monitoring or debugging purposes.
