# Vision Model

The **Vision Model** node is designed to create an AI vision agent that processes images and generates insightful outputs using the selected AI model. You can use this node when you need to analyze visual content, such as detecting objects, recognizing locations, or extracting information from images.

## Configuration Options

| Field Name            | Description                                                                                     | Input Type         | Required? | Default Value                                                  |
| --------------------- | ----------------------------------------------------------------------------------------------- | ------------------ | --------- | -------------------------------------------------------------- |
| **Model Configuration** | Select the AI model configuration settings such as provider and model specifications.          | Model Config Select | No        | Provider: `openai`, Model: `gpt-4o-mini`, is_JSON_output: `true` |
| **Files**             | Specify the files (images) you want the vision model to analyze.                               | Text               | No        | _(empty)_                                                      |
| **Prompt**            | Provide a prompt to guide the AI vision model's analysis of the images.                        | Prompt Input       | No        | _(empty)_                                                      |

## Expected Output Format

The output of this node, labeled **Result**, is the AI Model Result, a processed output based on the input files and prompt:

- **Type**: Config Panel Output
- **Format**: A structured result indicating the analysis and insights from the AI model. 

## Step-by-Step Guide

<Steps>
### Step 1

Add **Vision Model** node into your flow.

### Step 2

In the **Model Configuration** field, select the desired AI model settings. Adjust the settings as required to fit your analysis needs.

### Step 3

In the **Files** field, enter or upload the image files that you want the AI vision model to analyze.

### Step 4

Enter a **Prompt** to detail what kind of analysis you expect from the model. Include specifics if necessary, like focusing on certain objects or patterns.

### Step 5

Check the output labeled **Result** for the insights and analysis provided by the AI model.

</Steps>

<Callout type="info" title="Tip">
  Make sure your images are clear and relevant to the analysis you want. An accurate prompt can significantly improve the quality of the AI's output.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                      | Solution                                                                                                                                                  |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Input files are not processed**            | Ensure you have added valid image file paths in the **Files** field.                                                                                      |
| **Output is not as expected**                | Re-evaluate the **Prompt** to ensure it is clear and specific enough for the task you require.                                                             |
| **Model configuration issues**               | Double-check the model settings under **Model Configuration** to confirm the correct model and configurations are applied.                                 |
