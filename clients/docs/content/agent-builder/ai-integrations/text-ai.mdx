# Text AI

The **Text AI** node allows you to interact with AI models, enabling you to input a prompt and receive processed output from the model. This node is particularly useful for generating text, answering questions, or making predictions based on provided data. By configuring various options, you can customize the model's behavior to suit your specific needs.

For example:

- Generating creative writing pieces.
- Answering complex questions with context from a knowledge base.
- Providing structured, machine-readable JSON outputs.

## Configuration Options

| Field Name                   | Description                                                                                   | Input Type     | Required? | Default Value                                                                             |
| ---------------------------- | --------------------------------------------------------------------------------------------- | -------------- | --------- | ----------------------------------------------------------------------------------------- |
| **Prompt**                   | Enter the text prompt you wish to provide to the AI model for processing.                     | Text           | No        | _(empty)_                                                                                 |
| **Model Configuration**      | Select and configure the desired AI model and its parameters.                                 | Model Select   | No        | OpenAI GPT-4o-mini, Temperature: 1, Top P: 1, JSON Output: true                           |
| **Files**                    | Attach any files the model might need for reference or processing.                            | Text           | No        | _(empty)_                                                                                 |
| **Knowledge Base**           | Configure to use specific knowledge for generating more accurate and informed responses.      | Knowledge Base | No        | Retrieval: Basic, Source Threshold: 1, Number of Chunks: 10                               |
| **Memory Configuration**     | Define memory settings to control storage and retrieval capacities during the session.        | Memory Config  | No        | Provider: "Memory Provider 1", Max Data Stored: 4                                         |
| **Tool Definitions**         | Define tools or functions the model can call using JSON schema.                               | JSON Editor    | No        | _(empty)_                                                                                 |
| **Tool Invocation Strategy** | Choose how the model should interact with the tools: automatically, as required, or not at all.| Select         | No        | Auto                                                                                      |
| **Enable Structured Output** | Toggle to force the model to return responses in a predefined JSON structure.                  | Switch         | No        | False                                                                                     |
| **Schema Name**              | Assign a name to the JSON schema if structured output is enabled.                             | Text           | No        | _(empty)_                                                                                 |
| **Output Schema (JSON)**     | Define the expected output structure using JSON Schema. This ensures the AI output is predictable. | JSON Editor    | No        | _(empty)_                                                                                 |

## Expected Output Format

The output of this node is a structured response from the AI model, defined by your configurations. The primary output is labeled as **Result**, which contains the text or data generated by the AI.

- The output data type will depend on your configuration.
- If JSON schema is enabled, the output will conform to the predefined structure.

## Step-by-Step Guide

<Steps>
### Step 1

Add **Text AI** node into your flow.

### Step 2

In the **Prompt** field, enter the text or question you want the AI model to process.

### Step 3

Configure **Model Configuration** settings based on the AI model and parameters you wish to use.

### Step 4

(Optional) Attach any necessary **Files** for context or additional information.

### Step 5

Configure **Knowledge Base** settings if you want the AI to reference specific knowledge or databases.

### Step 6

Set up **Memory Configuration** to manage session storage options.

### Step 7

Define any **Tool Definitions** if the AI model needs to interact with external tools or functions.

### Step 8

Select a **Tool Invocation Strategy** to control how tools are used in the inference process.

### Step 9

Toggle **Enable Structured Output** if you need the AI to return output in a specified JSON format.

### Step 10

Assign a **Schema Name** and define the **Output Schema (JSON)** only if structured outputs are enabled.

### Step 11

The generated response will be available as **Result** for use in subsequent workflow nodes.

</Steps>

<Callout type="info" title="Tip">
  Use the **Knowledge Base** to enhance the AI's understanding and contextual relevance in responses.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                               | Solution                                                                                                             |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **No response from model**                            | Ensure the prompt is provided and the model configuration is valid.                                                  |
| **JSON Schema issues**                                | Make sure your JSON schema is correctly defined and matches the required structure.                                  |
| **Tool not invoked**                                  | Check the Tool Invocation Strategy settings to ensure tools are called as expected.                                  |
| **Output not structured as expected**                 | Verify that the structured output option is enabled and properly configured, including schema name and detail.       |
