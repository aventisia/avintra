# Speech To Text Model

The **Speech To Text Model** node converts spoken language into written text using advanced AI technology. It is particularly useful for generating transcripts of audio files, enabling easy reading, editing, and further processing of spoken content. This can help in areas such as meeting minutes, content creation, accessibility, and more.

## Configuration Options

| Field Name                   | Description                                                                                             | Input Type         | Required? | Default Value                                                                                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------ | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Model Configuration**      | Select the AI model configuration for converting speech to text. This includes provider settings.         | Model Config Select | No        | Provider: `openai`; Model: `gpt-4o-mini`; Temperature: `1`; Top P: `1`; Max Output Tokens: `50`; Is JSON Output: `true`                                                            |
| **Files**                    | File(s) containing the audio or speech you wish to convert into text.                                     | Text               | No        | _None_                                                                                                                                                                              |
| **Prompt**                   | Additional input or instruction to guide the AI's understanding of the task – particularly useful refined customization. | Prompt Input       | No        | _None_                                                                                                                                                                              |

## Expected Output Format

The output of this node is a **textual transcription** of the provided audio file. It represents the spoken language in written form, ready for reading or further processing.

## Step-by-Step Guide

<Steps>
### Step 1

Add the **Speech To Text Model** node into your flow.

### Step 2

Select the appropriate **Model Configuration** to specify the AI model that will perform the transcription. You can usually stick with the default settings but adjust them based on your need for refinement.

### Step 3

In the **Files** field, input or select the file containing the audio or speech you want to transcribe.

### Step 4

Optionally, enter a **Prompt** if you need to give specific instructions or context to the AI for more accurate transcription.

### Step 5

Run the node. Your transcription will be generated and available in the **AIModelResult** as a written text output.

</Steps>

<Callout type="info" title="Tip">
  Ensure that your audio files are of good quality for the best transcription accuracy.
</Callout>

## Common Mistakes & Troubleshooting

| Problem                                               | Solution                                                                                                                                                       |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No transcription output**                           | Ensure that the audio file is correctly uploaded and readable. Double-check file compatibility and format.                                                      |
| **Poor transcription accuracy**                       | Improve audio quality if possible, or provide a more detailed **Prompt** for better context understanding.                                                      |
| **Output not saving**                                 | Check your flow configuration to ensure outputs are being correctly directed and stored.                                                                        |

## Real-World Use Cases

- **Transcription Services**: Record and convert meeting discussions into text for reports and record-keeping.
- **Content Creation**: Turn spoken ideas or interviews into written content quickly and easily.
- **Accessibility Enhancements**: Provide written versions of spoken content for the hearing impaired.
- **Language Learning**: Convert and analyze language practice audio recordings into text for study and comments.
