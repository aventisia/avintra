# Updates

## Desktop App

The Avintra Desktop App updates itself automatically through its built-in updater. When a new
version is available you will be notified in the app and prompted to install it.

## Runner App

- If you installed the runner **via the Desktop App**, it is updated automatically and
  independently of the app itself.
- If you installed a **standalone** runner, download the latest zip from the Download page and
  replace your existing executor folder.
