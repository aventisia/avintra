# Runner App

The Runner App is the core worker that executes automation flows on your machine. It runs
autonomously, connects to the Avintra backend, executes the flow graph, and reports progress and
logs.

## When do I need it?

- You run automation flows that target your local machine (Excel, Word, UI automation, and other
  local integrations).
- You use a dedicated workstation as an Orchestrator machine.

## How it is installed

- **Recommended:** Install the Avintra Desktop App. It downloads and keeps the executor updated
  for you.
- **Standalone:** Download the executor zip from the Download page, extract it, and optionally
  register it as a Windows Service (see [Installation](./installation)).
