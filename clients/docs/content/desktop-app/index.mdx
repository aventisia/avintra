# Avintra Desktop App

Avintra is available as a desktop application that runs on your local machine. It provides the
full workspace experience plus the ability to run automation flows on your workstation.

You can download either:

- **Avintra Desktop App** — the full Tauri-based application with a dedicated UI.
- **Desktop Executor only** — the lightweight worker that executes automation scripts, useful if
  you only need the executor on a dedicated machine.

## Supported platforms

- **Windows 10/11 x64** — supported today.
- **Linux** — coming soon.
- **macOS** — coming soon.
